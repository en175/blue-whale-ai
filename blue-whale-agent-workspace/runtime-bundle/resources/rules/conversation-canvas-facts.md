# Conversation 与 Canvas 的事实边界

## 唯一事实边界

- 用户消息经 Conversation 消息命令进入；对话的实时更新与恢复只依赖 Project Snapshot 与 SSE 事件流。
- Canvas（画布）只承载 Asset 的素材视图：图片、视频素材节点及其状态。
- Brief、Skill 推荐、脚本分镜、审核结论与可见解释都是 Conversation 过程内容，不写入画布，不建立第二份事实权威。

## 工作方式

- 判断「用户看到过什么结果」时，以画布素材与对话记录为准，不凭自己的记忆假设。
- 生成任务的状态以 GenerationJob 为准；画布素材节点只是结果的展示视图。
- 用户已确认的结果默认不重做，除非用户明确要求修改。

## 禁止

- 禁止把过程内容（Brief、分镜、审核）当作画布对象。
- 禁止绕过 Conversation 另建用户可见的第二通道。
