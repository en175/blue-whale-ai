# Image Prompt Contract

本文件定义生图提示词的输出格式和质量标准。

## 适用范围

- 文生图
- 图生图
- 产品图
- 商品广告图
- 视频关键帧
- 风格参考图
- 场景参考图
- 角色参考图

## 基础公式

```text
主体 + 场景 + 构图 + 光影 + 风格 + 商业用途 + 必须保留 + 必须避免
```

## 产品图提示词

必须包含：

- 产品是什么
- 产品外观
- 产品材质
- 背景/场景
- 构图
- 光影
- 商业用途
- 不要生成文字、Logo、水印，除非用户明确要求

示例：

```text
一只哑光黑色保温杯，带有户外露营主题图案，产品居中放置在清晨露营桌面上，旁边有折叠椅、咖啡壶和柔和晨光。商业广告摄影风格，浅景深，产品边缘清晰，材质真实，画面干净高级。保持杯身颜色、轮廓和图案一致，不要生成额外品牌 Logo，不要生成水印，不要生成无关文字。
```

## 图生图提示词

必须明确：

- 参考哪张图
- 保持哪些元素不变
- 可以改变哪些元素
- 输出目标

示例：

```text
参考 @图片1 中的保温杯产品，保持杯身轮廓、哑光黑色材质、户外主题图案和整体比例一致。将背景改为清晨露营桌面场景，加入柔和自然光、木质桌面、咖啡壶和户外氛围。商业产品摄影风格，产品居中清晰，背景轻微虚化。不要改变产品形状，不要生成额外 Logo，不要生成水印或无关文字。
```

## 关键帧提示词

必须包含：

- 所属镜头
- 画面动作瞬间
- 主体位置
- 情绪或视觉重点
- 是否作为视频首帧/尾帧

## 负面约束

默认加入：

```text
不要生成水印，不要生成 Logo，不要生成无关文字，不要改变产品主体结构，不要让主体变形，不要出现多余手指或重复产品。
```

如果是美妆、健康、食品等高风险类目，不得生成未经确认的效果对比、医疗功效、认证或夸张承诺。

## 输出格式

```text
图片提示词
- 任务类型：
- 参考资产：
- 主体：
- 场景：
- 构图：
- 光影：
- 风格：
- 必须保留：
- 必须避免：
- 最终提示词：
```

## 禁止

- 不把视频时间线语言直接用于静态图片。
- 不凭空添加品牌 Logo、认证、价格、文字。
- 不改变用户要求保留的产品外观。
- 不用抽象形容词替代具体画面描述。
