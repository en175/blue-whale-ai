## 4. 给后端的接入建议

1. **主键**：用 `cnXX` 编号（如 `cn02`）做关联键，不要用文件名全名或 Skill name——Skill name 含空格、大小写混合，且库升级时可能调整。
2. **字段建议**：Skill 元数据增加 `cover_image` 字段，存图片 URL/对象存储 key；前端展示时按此字段取图。
3. **占位兜底**：108 个 Skill 中仅 33 个有封面，无封面的展示默认占位图，不要报错。
4. **入库校验**：图片文件名与本文件第 3 节映射表逐行比对，33 张全部对上后再入库。
