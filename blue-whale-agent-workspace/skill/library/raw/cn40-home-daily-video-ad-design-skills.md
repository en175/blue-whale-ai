# 家居日用品视频提示词

## 目的

使用此技能来撰写家居及日用品的AI视频提示词，使实用价值可视化。优先使用物理证明，而非模糊的便利性宣称：如污渍清除、安装过程、吸力展示、水流效果、收纳逻辑、紧凑性、表面变化、厨房操作以及整洁的最终状态。

不要将提示词锁定在固定的时长、模型、宽高比、外部资源标签或技术输出模式上。遵循用户要求的格式。如果未指定格式，则用自然语言编写一个清晰、完整的提示词，以便宿主代理（host agent）能适应其自身的渲染器。

## 类别范围

适用于清洁工具、吸尘器、刷子、喷雾剂、厨房小工具、饮水器具、收纳用品、卫浴洁具、床上用品、智能锁、制冷设备、户外家居工具、害虫防治工具、整理器、照明设备、小型家电以及日常实用产品。

## 创意角度

- **可见的脏乱救援**：先展示脏乱，使用工具，然后在同一画面中展示清洁后的结果。
- **安装-测试-回报**：对齐、卡入、安装、锁定、解锁、喷洒或开启，然后立即测试。
- **表面变化的前后对比**：从脏到净、从杂乱到有序、从褶皱到平整、从湿到干。
- **材料挑战**：水、热、污垢、压力、重量、碎屑、宠物毛发或污渍，证明产品的承诺。
- **令人满足的重复**：一个动作重复进行，每次操作都显示出改善。
- **空间逻辑揭示**：混乱的物品变得分类清晰、贴有标签、堆叠整齐、易于折叠或方便拿取。
- **单手实用性**：产品在另一只手忙碌时解决一个实际任务。
- **安静的奢华日常**：简单的物品、美丽的光线、触感动作、平静的最终构图。

## 灵活的节奏逻辑

构建一个灵活的电商叙事弧线，以适应用户要求的长度和平台：

- **开场钩子**：展示烦恼、脏乱、杂乱、结果预告、产品机制、房间环境或引人注目的细节。
- **产品证明**：清晰地展示工具、电器、材料、附件、手柄、喷雾、锁、容器或固定装置。
- **动作证明**：擦拭、喷洒、冲洗、吸尘、卡入、安装、抚平、折叠、倾倒、切碎、锁定、解锁、擦洗或堆叠。
- **回报**：展示干净的表面、整理好的抽屉、更轻松的烹饪、更好的收纳、干燥的浴室、贴合好的床铺或更宁静的房间。
- **结束画面**：回到产品、改造后的空间、手持前后对比、包装，或在需要时展示行动号召（CTA）。

## 让产品证明可见

始终描述观众能看到的证明：

- **清洁**：灰尘堆、碎屑、泡沫附着、脏水、刷子接触、擦拭痕迹、分离揭示。
- **安装**：撕开胶贴、拧紧螺丝、按压指纹、卡入模块、对齐喷嘴、锁定与解锁。
- **厨房**：切碎、搅拌、滋滋作响、倾倒、蒸汽、计时器、温度提示、摆盘或整理好的结果。
- **床上用品与浴室**：弹性张力、边角贴合、抚平褶皱、水流、排水、毛巾或皮肤安全环境。
- **日常实用**：抽屉贴合、无线移动、紧凑收纳、手柄握持、承重能力以及最终的整洁状态。

不要只说“有用”或“方便”。要展示让买家信服的物理原因。

## 逆向工程指南

当提供了源视频、排名条目、产品页面或封面时，在撰写新提示词之前，先提取可复用的销售模式：

- 捕捉产品类型、家居环境、开场钩子、屏幕文字创意、旁白或音频提示、产品动作、证明时刻、对比、反应、行动号召（CTA）以及买家的顾虑或渴望。
- 优先理解完整视频，而非仅凭封面推断。如果只有封面可用，请保持推断的保守性。
- 在必要时保留有效的工作顺序。不要将一个令人满意的演示扁平化为一个通用的家居生活方式广告。
- 用类别变量替换表面细节，例如：手持吸尘器、硅胶排水工具、智能锁、床上用品夹、厨房切碎器、整理器或清洁喷雾。
- 保留最强的证明时刻。如果源视频通过擦拭痕迹来销售，就保留擦拭痕迹。如果通过收纳改造来销售，就保留整理前后的对比。
- 每次只添加一个主要的变异：房间、钩子、家庭角色、产品变体、脏乱类型或视觉风格。

## 输出指南

- 提供完整的提示词，而不仅仅是提纲。
- 遵循用户要求的结构和格式。除非用户要求，否则不要将最终提示词包裹在代码块中。
- 不要提及不支持的参考文件、资源标签或特定模型的语法。
- 除非用户明确要求，否则不要指定具体的视频模型。
- 确保产品在核心证明时刻保持可见。
- 在有用时包含触觉或音频提示：喷雾、吸尘、卡入、擦洗、水流、抽屉滑动、切碎、锁的提示音、织物抚平或房间氛围。
- 如果用户未提供品牌，请使用中性占位符，如 `[品牌/产品名称]`，而不是虚构一个真实品牌。
- 避免不可能的清洁效果、不安全的厨房操作、虚假的智能锁安全声明、变形的手、多余的手指、无法阅读的标签以及不连贯的房间几何结构。

## 示例

将此作为完整提示词脚本的质量参考，而非必须遵循的格式。

**输入：** 为一个手持迷你吸尘器创建一个电商视频提示词。

**示例提示词脚本：**

为一个手持迷你吸尘器创建一个15秒的竖屏电商视频。风格为写实的家居用户生成内容（UGC），包含可见的脏乱、令人满意的清洁过程以及清晰的产品操作。

0:00-0:02：沙发垫和狭窄汽车座椅缝隙上散落碎屑的极端特写。屏幕文字：“小脏乱，积少成多。”

0:02-0:05：一只手打开抽屉，拿起紧凑型吸尘器，并卡上窄嘴吸头附件。

0:05-0:08：吸头在沙发垫上移动，一次可见的吸尘过程将碎屑吸入吸尘器。确保碎屑和吸尘路径清晰可见。

0:08-0:11：吸头清洁汽车座椅缝隙的特写，同时可听到吸尘声，碎屑从缝隙中消失。

0:11-0:13：以快速的前后对比构图展示清洁后的沙发和汽车座椅缝隙。屏幕文字：“无需大吸尘器，快速清洁。”

0:13-0:15：以产品整齐地放置在干净沙发旁的架子上结束。行动号召（CTA）文字：“在容易脏乱的地方放一个。”

音频：抽屉滑动声、附件卡入声、吸尘声、碎屑移动声、安静的家居氛围。

避免：不可能的清洁跳剪、变形的手、多余的手指、无法阅读的标签、不连贯的房间几何结构。
