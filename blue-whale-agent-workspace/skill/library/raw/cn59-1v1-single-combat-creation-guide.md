## 指令

1. **分析需求：** 从用户请求中提取角色类型、场景和战斗风格（例如：武术、奇幻、枪斗术）。
2. **构建决斗结构：** 将场景组织为：对峙、首次交锋、防御/反击、压力升级、情感高潮、战术逆转、终结技和余波。
3. **应用战斗逻辑：** 确保每个动作遵循攻击 -> 反应 -> 后果的链条。在战斗风格上使用清晰对比（例如：敏捷 vs. 力量）。
4. **指导镜头：** 指定镜头行为（例如：手持跟拍、广角捕捉动作、特写强调冲击力），以增强物理强度。
5. **起草提示词：** 基于结构化的编排，构建一个描述性强、高质量的AI视频生成提示词。

## 使用时机

- **适用场景：** 英雄与反派的决斗、Boss战、武术序列、剑斗或奇幻战斗，以及电影化动作的分镜规划。
- **不适用场景：** 超过两名战斗者的场景、非战斗互动，或生成可直接执行的代码及外部API调用。

## 输出要求

所有输出使用以下结构：
- **标题：** 序列的电影化标题。
- **场景类型：** 战斗背景的简要总结。
- **角色与地点设定：** 参与者和环境的简要描述。
- **战斗进程：** 编排的逐步分解。
- **镜头指导：** 具体镜头和移动指令。
- **最终提示词：** 适用于AI视频生成的精炼描述性段落。

## 示例

- **输入：** "在燃烧的道场中，一位冷静的师父与愤怒的弟子之间的剑斗。"
- **输出：** 遵循上述结构，重点描述师父冷静的格挡与弟子大开大合的攻击，最终以师父在倒塌的柱子旁缴械弟子结束。
