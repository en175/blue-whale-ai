# Blue-Whale 中文 Skill 库索引

本索引用于 Skill Selector Agent 先快速选择候选 Skill，再按需读取 `raw/` 下的完整 Skill 原文。

使用规则：

1. 先根据用户需求、产品类型、视频目标选择 1-3 个候选 Skill。
2. 只读取候选 Skill 的完整文件，不一次性读取全部库。
3. 用户明确指定某个 Skill 时，优先读取对应文件。
4. 如果需求跨类型，优先选择主创作 Skill，再选择镜头/优化/行业辅助 Skill。

## 推荐选择策略

### 产品广告

优先从 A、B、C、D 中选择一个主 Skill。

### 需要高级镜头

主 Skill 之外，再搭配 F 中的镜头/导演工具。

### 需要生成前审核

搭配 `raw/cn54-video-optimization-review-expert.md`。

### 行业明确

先看 D 的行业 Skill，再用 A/B/C 的表达结构补强。

### 用户想要剧情

优先考虑 `raw/cn07-micro-drama-ad-creator.md`、`raw/cn18-story-driven-product-ad.md`、`raw/cn60-suspense-thriller-plot-creation-guide.md`。
