# 昆汀·塔伦蒂诺标志性工具包

## 说明

在生成具有塔伦蒂诺标志性风格的 AI 视频时使用此技能。选择与情感目标相匹配的技巧。自定义方括号内的占位符。然后生成。

## 创作规则

- 塔伦蒂诺的核心：对话即行动，音乐定义时刻，酷是一切，时间是玩具，细节是恋物癖，紧张感通过耐心构建。
- 音乐/音效设计是**强制性的**——除非沉默本身就是紧张感，否则绝不能静音。
- 调色板：温暖的金色、深红色、刺眼的荧光色、70 年代的模拟感。
- **反油腻**：酷服务于角色，暴力服务于故事，风格服务于实质。

## 技巧 1：后备箱镜头（塔伦蒂诺标志）

摄像机位于汽车后备箱内，**直直向上**拍摄站在其上方的角色。
观众就是后备箱里的那具尸体。

**情感：** 脆弱、威胁、权力失衡、黑色幽默。

**电影：** 《落水狗》、《低俗小说》、《杀死比尔》、《杰基·布朗》、《死亡证据》。

```
后备箱镜头——摄像机位于汽车后备箱**内部**，直直向上拍摄
[数字] 个人站在打开的后备箱上方，低头看着摄像机。他们被
[刺眼的阳光 / 停车场荧光灯 / 夜空] 从背后照亮。
由于极端的低角度，他们的脸部部分被阴影遮挡。表情：
[觉得有趣 / 威胁 / 随意 / 讨论该做什么]。其中一人手持
[武器 / 物品 / 包]。后备箱盖框住了画面——所有边缘形成
暗色晕影。轻微的广角畸变使人物显得更加庞大。温暖的
色调，略微过曝的高光。声音：沉闷的汽车引擎声、远处的交通声、
他们从上方传来的声音——用随意的语气谈论着可怕的事情。
标志性的塔伦蒂诺权力角度。
```

## 技巧 2：章节标题卡（时间结构中断）

在纯色或黑色背景上的粗体文字。章节编号和标题。
标志着时间跳跃、视角转换或叙事重置。

**情感：** 重置、期待、文学性的酷感、“注意——新章节开始了。”

**电影：** 《杀死比尔 1 & 2》、《低俗小说》、《八恶人》、《无耻混蛋》。

```
章节标题卡——[纯色背景：黄色 / 红色 / 黑色 / 白色]
充满整个画面。出现粗体文字：“第 [数字] 章”，使用大号字体，
然后下方以较小字体显示副标题“[章节标题]”。字体风格：
[复古打字机 / 粗体无衬线 / 磨坊剥削风格 /
优雅衬线]。文字可能以锐利剪切或打字机式逐字出现。
持续 [时长]。声音：[静音 / 黑胶唱片噼啪声 /
单一戏剧性的音乐重音 / 前一场景的最后一个回声逐渐消失]。
这张卡片是一次**呼吸**——一次重置——在投入下一个时间线之前。
图形化，文学性。
```

## 技巧 3：仪表盘对话镜头

摄像机安装在汽车仪表盘上，面向前排座位。两个角色
在开车时交谈。长时间不间断的拍摄。道路在他们身后
通过挡风玻璃向后滚动。

**情感：** 运动中的亲密感、随意的危险、角色自我揭示。

**电影：** 《低俗小说》、《死亡证据》、《落水狗》、《好莱坞往事》。

```
仪表盘对话镜头——摄像机固定在汽车仪表盘上，面向 [两个角色]
在前排座位上。驾驶员在 [左/右]，乘客在说话。从
胸部以上拍摄，两人面部可见。道路和风景在他们身后
通过挡风玻璃向后滚动。随着汽车移动，自然光发生变化——
透过树木的斑驳光线或稳定的高速公路阳光。角色随意谈论着
[揭示角色的平凡话题——食物 / 音乐 / 电影 / 个人
哲学]。表情生动，手势丰富。汽车内部
就是他们的舞台。温暖的自然光，轻微的镜头眩光来自太阳。
声音：引擎嗡嗡声、对话下的道路噪音，可能还有一首
在汽车收音机上播放的**歌曲**（特定的曲目设定了时代和情绪）。
单一不间断的镜头，[时长]。亲密，流动。
```

## 技巧 4：脚部镜头 / 物体恋物癖特写

对特定身体部位或物体的极端特写。镜头停留。摄像机
**崇拜**这个细节。不是功能性的——是恋物癖式的。

**情感：** 痴迷、质感、通过物体展现角色、感性的威胁。

**电影：** 《杀死比尔》（赤脚踩在地板上）、《低俗小说》（注射器、公文包）、
《死亡证据》（脚放在仪表盘上）、《无耻混蛋》（馅饼、奶油、香烟）。

```
恋物癖特写——对 [特定细节：赤脚走在
木地板上 / 手指缠绕武器手柄 / 香烟
烟雾从嘴唇缭绕升起 / 食物被精确切割 / 液体被
倒入玻璃杯 / 皮靴踩在砾石上 / 手转动门把手] 的**极端**特写。
摄像机距离拍摄对象**几英寸**。浅景深——只有
恋物癖对象是清晰的，其他一切都融化了。镜头**停留**——不是
一瞥而是**凝视**。温暖饱和的色彩，皮肤纹理可见，
材料纹理超现实。声音：ASMR 级别的细节——皮革的吱吱声、
食物的嘶嘶声、机械装置的咔嗒声、皮肤上的呼吸。
缓慢微妙的摄像机漂移（微动）。[时长]。强迫症式的，
纹理化的，亲密的。
```

## 技巧 5：墨西哥对峙圆圈

多个角色同时互相用武器指着对方。
摄像机缓慢地围绕对峙现场环绕。每个人都离扣动扳机
一步之遥。冻结的紧张感。

**情感：** 最大紧张感、同归于尽、无路可逃、黑暗的荒谬。

**电影：** 《落水狗》、《无耻混蛋》、《八恶人》、《被解救的姜戈》。

```
墨西哥对峙——[3-4 个角色] 站成 [圆圈 / 三角形 /
直线]，每个人都将 [武器] 指向另一个人。每个人同时是猎手
和猎物。摄像机在视线高度缓慢环绕该群体，揭示每张
面孔和每个武器的目标。表情：[冷酷 / 冒汗 /
咧嘴笑 / 恐惧]。手部稳定或颤抖。环绕需要 [时长]，
经过每个角色。紧张感是**物理性的**——可见于
紧咬的下巴、发白的指关节、浅促的呼吸。刺眼的实用
灯光在脸上投下深深的阴影。声音：近乎寂静——时钟
滴答声、皮革吱吱声、呼吸声，可能还有远处可能触发
爆发的声响。难以忍受的紧张感，冻结的暴力。
```

## 技巧 6：针落漫步（音乐 + 慢动作昂首阔步）

角色以**绝对的自信**行走。慢动作或正常速度。
**歌曲**承载着场景。行走是编排好的舞蹈。纯粹的酷。

**情感：** 酷、招摇、登场、“这些人危险而美丽。”

**电影：** 《落水狗》（开场行走）、《低俗小说》（Mia Wallace）、
《杀死比尔》（医院里的新娘）、《好莱坞往事》（Brad Pitt 在屋顶上）。

```
针落漫步——[主体/群体] 以完全的自信和招摇 [朝向摄像机 /
远离摄像机 / 横向] 行走。[慢动作，速度为 60-70% 或正常速度，步伐节奏与音乐节拍匹配]。
每一步都深思熟虑、有力、有型。服装和剪影是
**标志性的**——[西装 / 皮夹克 / 黄色运动服 / 牛仔靴]。
从 [强调权力的低角度 / 视线高度侧跟 / 展示全身和环境的广角] 拍摄。
背景 [因运动而模糊 / 清晰显示环境背景]。温暖的金色或霓虹灯浸染的
灯光。头发或外套在风中飘动。声音：**特定的歌曲**主导着
配乐——行走是配合节拍编排的。音乐就是
方向。纯粹的电影酷感，神话般的。
```

## 技巧 7：低角度权力爬行

摄像机**实际上**在地板上，向上拍摄角色和环境。
甚至比后备箱镜头还低——地板高度。物体和脚在
紧贴前景。

**情感：** 无力感、虫眼般的崇拜、磨坊剥削片的粗粝感。

**电影：** 《杀死比尔》（地板上的新娘）、《低俗小说》、《死亡证据》。

```
地板级权力爬行——摄像机在**地面**上，镜头距离地板表面几英寸。
从极低角度看到 [主体]——脚和腿在前景中巨大，
身体向上高耸。地板纹理超清晰可见（木板 / 瓷砖 / 混凝土 / 地毯）。
摄像机在地面水平**缓慢爬行**向前，推过 [地板上的物体——弹壳 /
碎玻璃 / 散落的物品 / 鞋子]。从地板看世界是
陌生而具有威胁性的——一切都高耸在上。来自
广角镜头的透视畸变使环境显得像洞穴一样。来自上方的实用
灯光在脸上投下戏剧性的向上照明。声音：地板接触
声音被放大——脚步声轰鸣，物体刮擦声刺耳。[时长]。
磨坊剥削片风格，发自肺腑的。
```

## 技巧 8：快速变焦推拉

摄像机**突然**向关键细节或面部变焦。没有轨道移动——纯镜头
变焦，快速而猛烈。视觉上相当于唱片刮擦声。

**情感：** 震惊强调、“看这个”、喜剧性的标点符号、危险信号。

**电影：** 《杀死比尔》（看到敌人）、《被解救的姜戈》、《无耻混蛋》。
```

急推变焦——从[场景]的[广角/中景]镜头，摄影机突然快速推近至[关键细节——一张脸/一个物体/一把武器/一个名字/一处伤口/一种反应]。变焦过程不到——猛烈、刺耳、刻意。轻微过冲后稳定。推近的主体充满画面。其他一切消失。急推变焦传达：这很重要。这将改变一切。在继续之前短暂保持特写镜头()。声音：与变焦同步的尖锐音频刺音或音乐重击——[戏剧性和弦/鞭裂声/低音重击/静默]。标点符号，暴力强调。

## 技巧 9：镜像虚荣镜头

角色看着镜子中的自己。摄影机同时捕捉角色和他们的倒影。行动前的自我审视时刻。

**情感：** 自我对抗、准备、双重身份、暴力前的仪式。

**电影：** 《低俗小说》（特拉沃尔塔在浴室）、《杀死比尔》、《危险关系》。

```
镜像虚荣镜头——[主体]站在[浴室镜子/化妆镜/汽车后视镜/反光表面]前。摄影机位置使真实人物和他们的倒影同时可见。主体[对自己说话/练习台词/给自己打气/沉默凝视/洗掉手上的血/像涂战漆一样化妆]。镜子倒影显示出直接角度看不到的东西——真相、恐惧、决心。温暖的浴室灯光或刺眼的荧光灯。水流声，可能有蒸汽。声音：内心独白的能量——呼吸声、水声、夜晚建筑的安静嗡嗡声。单一固定镜头。亲密，自我对抗。
```

## 技巧 10：长镜头紧张对话

摄影机保持在一个对话上，不进行剪辑。拒绝剪辑制造出难以忍受的紧张感。观众无法逃避。

**情感：** 不断加剧的恐惧、审讯、言语博弈、对话本身就是行动。

**电影：** 《无耻混蛋》（开场农舍）、《八恶人》（餐桌）、《低俗小说》（皇家芝士堡）。

```
长镜头紧张对话——摄影机稳定保持[两个或更多角色]坐在[桌子/吧台/面对面]。一方是[审讯者/阿尔法]，另一方是[隐藏着某事/猎物]。对话表面礼貌，但暗藏杀机。摄影机缓慢、几乎难以察觉地推进或保持锁定——静止创造紧张感。面孔显示微表情——抽搐、吞咽、强颜欢笑。灯光聚集在脸上，房间其余部分更暗。桌上的道具变得重要（一杯牛奶、一份馅饼、一支香烟、桌下的枪）。声音：对话主导，下方有低沉的、几乎听不见的嗡嗡声或逐渐增强的配乐。环境音被放大——时钟声、地板声、餐具在盘子上的声音。不间断的、不断累积的压力。令人窒息，戏剧化。
```

## 技巧 11：非线性时间跳跃（视觉）

展示时间已被打破和重组的视觉词汇。色彩偏移、胶片类型变化或视觉处理变化标志着我们现在处于不同的时间。

**情感：** 迷失方向、拼图式叙事、“我们什么时候？”

**电影：** 《低俗小说》（整体结构）、《杀死比尔》、《八恶人》、《危险关系》。

```
非线性时间跳跃——[场景A]以[调色板A/灯光A/时代标记A]剪辑到[场景B]，其视觉处理明显不同。时间跳跃通过以下方式标记：[从彩色到黑白的转变/从冷色调到暖色调的转变/从干净数字到颗粒胶片感的转变/从白天到夜晚的转变/从一个地点地理到另一个地点的转变]。新场景从动作中间开始——没有建立镜头，直接投入那一刻。角色可能相同但更年轻/更年长/穿着不同服装。物体或对话片段在时间线之间回响。声音：突然的音乐变化——不同时代、不同流派、不同能量。剪辑本身就是叙事。碎片化，非线性。
```

## 技巧 12：分屏

画面分为 2-4 个部分，显示同时发生的动作。每个面板有自己的摄影机角度或时间线。刻意设计的信息过载。

**情感：** 平行动作、汇聚、风格致敬、“一切都有联系”。

**电影：** 《杀死比尔1》（动画序列过渡）、《危险关系》（三分屏）。

```
分屏——画面分为[2/3/4]个面板。每个面板显示[来自不同角度的同时动作/不同地点的不同角色做相关事情/同一时刻的不同视角/汇聚的不同时间线]。面板由[硬黑线/柔边融合/颜色编码边框]分隔。每个面板有自己的灯光和运动。观众的眼睛在面板之间跳跃——联系和对比浮现。一个面板可能静止，而其他面板移动。声音：来自面板的音频混合或交替——创造拼贴效果。图形化，信息密集，风格化。
```

## 规则

- 每种技巧必须服务于角色或紧张（说明目的）
- 音乐/声音设计对塔伦蒂诺来说是强制性的——除非沉默本身就是紧张，否则永远不要静音
- 调色板：温暖的金色、深红色、刺眼的荧光灯、70 年代模拟感
- 建议使用胶片颗粒以获得符合时代的感觉
- 急推变焦：每个序列最多一次
- 反油腻：酷服务于角色，暴力服务于故事，风格服务于实质
