# 明星卡片生成器

批量生成足球明星的**英文图像提示词**（每条不超过1000个字符）。默认宽高比：**9:16全身照**。仅输出提示词——除非用户明确要求，否则不生成图像。

## 工作流程

1. **选择风格**：从下表匹配用户指定的风格，并使用其英文核心关键词。若未指定，则列出全部8种风格供用户选择。
2. **选择名单**：若用户提供名单则使用；否则使用下方默认的10名球员——**先提交计划供审核**，确认后再编写提示词。
3. **编写提示词**：每名球员一条提示词，按照下方8个字段组织成**连贯的英文段落**。不使用JSON格式。
4. **交付**：直接输出提示词文本。

## 提示词字段（按此顺序写成一段英文）

| 字段 | 内容 |
| --- | --- |
| card_layout | **整个系列固定不变——逐字复制。** 生成一张具有足球交易卡美学的图像，卡片UI左上角为专业号码盾牌，右上角为阵营旗帜，底部为水平姓名面板。 |
| visual_style | 风格英文核心关键词 + 体育交易卡美学，超精细 |
| main_subject | 国籍/体型/面部特征/胡须/表情 + 自信的运动姿态 |
| hair_and_accessories | 发型、颜色、分头或束发 |
| clothing_and_accessories | 球衣颜色和号码、短裤、袜子、球靴；可选脚下带球 |
| scene_composition | 全身照，居中，平视角度，仅限球员特定姿势/动作 |
| background_elements | 符合风格的背景（球场/纯色/风格化场景） |
| lighting_and_color_tone | 符合风格的灯光和调色板 |

**提示**：`card_layout` 是整个系列的模板——每张卡片上保持一致。风格定义媒介；主体定义身份（面部特征要具体——避免泛泛的“英俊”）。始终包含球衣和号码。保持卡片布局、风格、背景和灯光在整个系列中一致；仅姿势和球员细节可以变化。优先使用识别锚点+号码，而非仅依赖名人姓名。
