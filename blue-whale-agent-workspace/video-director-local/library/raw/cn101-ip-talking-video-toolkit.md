## 说明
1. 从提供的模块中识别您的 IP 原型（知识、生活、趋势等）。
2. 组合选定的模块以形成连贯的视觉提示。
3. 始终将强制否定提示附加到您的生成指令中。
4. 使用“[扬声器设置]”或“[背景环境]”等占位符来自定义您的特定场景。

## 何时使用
- **适用：** 构建视频生成工具的提示、定义 IP 的视觉风格一致性以及选择摄像机/灯光逻辑。
- **请勿用于：** 直接视频文件渲染、自动 API 调用或绕过安全/内容过滤机制。

## 核心创意原则
- **真实性：** 优先考虑自然的面部微表情和流畅的肢体语言。
- **层次结构：** 确保视觉细节支持演讲者，而不是分散他们的注意力。
- **一致性：** 在整个序列中保持统一的灯光和调色板。

## 强制否定提示
将其附加到所有生成提示中：
“表情虚假、动作僵硬、脸部修饰过度、塑料质感、妆容夸张、眼神交流生硬、色彩过度饱和、细节模糊、比例扭曲、多余水印、无意义的UI元素、不恰当的特效。”

## 工作流程模块
### 情感和语气
- **平静的洞察力：** 低饱和度、柔和的光线、最小的运动。
- **温暖治愈：** 温暖的色调，漫射的光线，温柔的微笑。
- **热情：** 分层灯光，富有表现力的手势。
- **Rational Professional：** 柔和的色调、均匀的灯光、简约的背景。

### 相机语言
- **眼睛水平：** 身临其境的直接互动。
- **略显疏忽：** 柔和、平易近人、日常分享。
- **略低角度：** 自信、专业、权威。
- **慢拉/平移：** 主题转变的动态过渡。

### 场景与灯光
- **学术：** 书架，简约，中性色调。
- **休闲：**家庭环境，自然光。
- **精英：** 高端、定向照明、纹理。
