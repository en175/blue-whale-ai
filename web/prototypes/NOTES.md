# Agent 侧边栏 UI 原型（IKFLB9 前端）

`agent-panel-timeline.prototype.html` 是用完即删的原型，2026-09-15 与李述对过五版（A 折叠工作组 / B 时间轴 /
C 状态行+抽屉 / D 时长条 / E 阶段分组+表单）后定下的最终版，前端按它改。双击打开，浮条「运行中」看最后一轮还在跑的样子。

## 定下来的

1. **思考链路**：每轮只有一行「▶ ✻ 已处理 31s · 思考 2 段 · 工具 1 次」，默认折起，运行中是「✶ 处理中」并展开。
   点开里面按阶段分组（理解需求 / 查阅对应的创作方法 / 整理下一步……），每阶段一个合计时长，再点开看思考原文、
   读了哪些文件。正文直接铺在对话里，不套消息卡，不再一句正文一句思考交替。
2. **追问选项**：所有题一张表单，每题一行分段按钮，推荐项带小圆点默认选中，下面一行是选中项说明 + 推荐理由。
   支持多选（标「多选」，推荐组合默认全选）。每行末尾「其他」，点了展开输入框。选了什么，输入框上方出一行草稿，
   输入框的发送就是回答。答过的轮次锁住只显示当时的选择。**前提：agent 侧把题目结构化成部件**，目前是 markdown 文字。
3. **方案卡**：卡头一条色带放「方案卡 · 等你拍板 · ▤ .md」和媒介 / 模型 / 参数；目标做标题、方向做引文；
   「你要求的（不会改）」「我替你定的（不合适就说）」两个清单；「接下来怎么做」移出卡放到卡后正文。
   动作：确认，按这个写 / 换个思路 / 我来改（展开输入框）。确认后收成「● 已确认 · 21:37」。
   ▤ .md 在面板里盖一层渲染成 md，可下载。
4. **提示词卡**：标题 + 张数 / 模型 / 画幅；「参考」一排素材胶囊；正文里的 #1 也是胶囊（复用 AssetMentionChip）；
   默认 3 行「展开全文」；动作：应用到画布 / 复制提示词 / 打开查看（同 md 层）。
5. **统计行**：只在输入框上方一行，「✻ 上一轮 57s · ↓ 14.7k · 上下文 9% · 21:37 完成」，不再每轮尾都有。
6. **强调色**：暖黄 `#f2b544` 替换柠檬绿，只用在主按钮、进行中、选中描边。
