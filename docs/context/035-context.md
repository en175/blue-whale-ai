## 本次唯一修复：refMode 按钮文案绑定
- **问题**：底部「全能参考」按钮的文字之前是硬编码字符串 `全能参考`（`page.tsx:2031`），没有绑定到 `refMode.label`。默认状态下视觉与参考稿一致，但当用户点开下拉切换到「首尾帧 / Text to Video」后，按钮上的文字不会跟着更新，属于交互 bug。
- **修复**：把硬编码的 `全能参考` 改为 `{refMode.label}`。
- **效果**：默认 `refMode = REF_MODES[0]`（「全能参考」）视觉不变；切换后按钮文案同步更新。

## 保持现状（按确认）
- 高级设置按钮（`display:none`）和联网搜索展开块（折叠）保留代码不删，避免影响其它模式及后续需求。
- 底部模型 Pill 文案保持「Seedance 2.0」（与参考稿一致）。
- 积分生成按钮保持禁用置灰态（与参考稿一致）。
