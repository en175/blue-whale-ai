# 项目上下文 009

## 时间
2026-06-30

## 本次任务
实现「AI 图片」Tab 上传参考图后的媒体列表展示样式。

## 变更内容

### 1. AI 图片 Tab 上传后布局调整
- 当 `mediaList.length > 0` 时，在编辑器上方渲染横向媒体列表
- 左侧 88×88 上传按钮隐藏，改为列表末尾的 52×52 虚线「+」按钮
- 编辑器 placeholder 更新为：「从文字与参考图生成 AI 图片。\n描述你想生成的图片，已上传的参考将引导风格与细节。」

### 2. 媒体列表项样式
- 每个图片项：
  - 52×52px 圆角缩略图（`rounded-md`）
  - 底部名称（`text-[10px] text-white/40`）
  - 右上角移除按钮（X 图标），hover 显示
  - 移除按钮样式：`bg-[rgb(30,30,30)]` 背景、`border-white/[0.12]` 边框
- 列表末尾「添加更多图片」按钮：
  - 52×52px 虚线边框（`border-dashed border-white/[0.12]`）
  - 透明背景，hover 加深

### 3. 与视频 Tab 媒体列表的差异
- AI 图片列表项没有「替换」按钮
- 移除按钮样式不同（深色背景 + 细边框）
- 列表间距为 `gap-1.5`
- 末尾按钮为虚线边框样式
