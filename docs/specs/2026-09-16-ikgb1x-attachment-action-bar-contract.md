# 附件操作条契约

## 时间

2026-09-16

## 背景与范围

父需求 IKGB1X（生成面板附件操作条与附件栏空态改造）：图片/视频/音频三个生成面板的添加入口从附件栏尾部单「+」二选一菜单，改为输入框上方第一行的「附件操作条」；附件栏空态整条隐藏；禁用态统一为「常显 + 置灰 + 悬停原因」。本契约随首个切片 IKGB7U（共享组件 + 图片面板落地 + 契约成文）落盘，固化布局、分派与禁用语义；视频（IKGB7W）、音频（IKGB82）面板接入按「验证与关联」推进。

本需求实质修订 2026-09-13「三面板添加入口统一 = 单 + 入口」的既定决策（当时仅记录在工单，无规格文件），以本单为准。

## 1. 布局三段

- 生成面板输入区自上而下固定为三段：**附件操作条**（第一行，常显）→ **附件栏**（第二行，空态不渲染）→ **输入框**。
- 附件操作条左侧为「+ 参考」「资产库」两个圆角 pill 按钮（左对齐）；右侧并入面板现有的展开 / 关闭按钮，保持在第一行右侧原位。
- 附件栏空态：没有任何附件时整条不渲染（初始界面 = 操作条 + 输入框两段）；添加首个附件后出现，删光后重新隐藏。
- 空态判定由实际附件项**派生**（普通媒体参考 + 文本附件；视频首尾帧模式另含槽位内容），不引入新的持久状态。

## 2. 按钮分派语义

- 「+ 参考」= 原菜单项「从节点添加素材」：点击进入画布点选模式，点选进行中按钮高亮（picking 态），点到的节点立即成为参考。
- 「资产库」= 原菜单项「从资产中选择」：点击直接打开同一个资产库选择弹窗（AssetsPickerModal），按当前面板过滤媒体类型，确认后落地行为不变（绑定模式落画布并连线、自由模式本地引用）。
- 分派沿用面板现有回调接口 `onPickFromCanvas` / `onPickFromAssets` 及 `kind`、`role` 参数，不改动 Canvas 页面与 AssetsPickerModal 的现有路由与过滤逻辑。
- 共享组件 `AttachmentActionBar`（`web/src/pages/CanvasPage/components/AttachmentActionBar/`）承载入口形态与高亮；三条链路的行为仍由各面板既有回调承载。
- 附件栏尾部旧「+」菜单（RefSourceMenu 普通变体）随操作条落地从各面板退役；RefSourceMenu 仅保留首尾帧具名槽位的 label 变体（「+ 首帧」「+ 尾帧」）。

## 3. 禁用态三原因

- 操作条常显。按钮禁用 = **常显 + 置灰 + 悬停说明原因**，替代三面板各自「入口消失」的旧口径。
- 禁用原因与现有能力门控一一对应：
  1. **模型参考能力位不支持**（如视频面板 `caps.referenceImage` 为否）；
  2. **附件达数量上限**（图片面板：参考图片达模型能力 `max_reference_images`；音频面板：参考音频达上限）；
  3. **生成中只读**（readOnly：生成中 / 保存提交中）。
- 禁用经 `aria-disabled` + 点击守卫承载（非原生 `disabled`），保证禁用时悬停原因（title）仍可见；置灰样式由共享 CSS 的 `.pill[aria-disabled='true']` 提供。
- 图片面板现状门控为「达上限 / 生成中只读」两项（无模型能力位入口门控），其达上限悬停文案为「参考图片最多 N 张，已达上限」，生成中只读悬停文案与只读提示条同一来源。

## 4. 首尾帧顺序填充与溢出（视频面板，IKGB7Y 落地）

- 首尾帧模式下，「+ 首帧」「+ 尾帧」具名槽位与空槽判断原样保留、常显，不吃空态隐藏规则；精确指定槽位仍走槽位自有入口。
- 操作条按钮以「首个空槽位」的角色发起添加：第一张进首帧、第二张进尾帧，仅图片（与槽位媒体口径一致）；两槽均满时按钮置灰。
- 溢出处理：资产库多选超出剩余空槽时按选择顺序取前 N 张（N 为剩余空槽数）并 toast 提示；画布点选在两槽均填满后自动退出选取模式并提示「首尾帧已就绪」。

## 5. 视觉同源约定

- 操作条视觉定义**单一来源** = `AttachmentActionBar/index.module.css`（`.actionBar` / `.actions` / `.pill` / `.picking` / `.trailing`），三面板同源使用，不在面板样式表保留第二份操作条规则。
- pill 色板与既有面板控件同源（沿用 RefSourceMenu trigger 的 `#2a2a2a` 底 / `#333` 边 / `#888` 字体系）；点选高亮沿用 RefSourceMenu `picking` 同口径（虚线强调边框）。
- 源断言与源唯一性锁：`AttachmentActionBar/actionBarVisualSource.test.ts`（沿用 mediaChipVisualSource 惯例，node 环境读 CSS 源断言规则体）。

## 6. 范围边界（Out of Scope）

- 音乐面板（MusicDialog）：结构不同，入口已废弃、模型仍为 mock，本次不动；登记「音乐面板退役或后续统一」观察项。
- 首页输入区（ChatBox）与画布左侧工具栏的「+」菜单：往画布落素材的另一入口，不属于面板附件逻辑。
- 参考产品截图中的「标记 / 特效 / 角色库 / 运镜」按钮：非本产品功能，不预留占位。
- 资产库弹窗、画布参考选取模式、@ 菜单、参考缩略图三态与放大预览本身的任何行为变更。
