# IKIZ2Y 生成 Dock 协调器设计

关联工单：[IKIZ2Y](https://gitee.com/hangzhou-xuanfu_1/blue-whale-ai/issues/IKIZ2Y)。Grill-with-docs 的 Q1–Q11 已逐项获用户批准，整体理解于 2026-10-07 获用户确认。本文保留设计阶段记录；其中源码行号、图谱与未运行测试说明均指设计阶段基线。当前实施接入、自动验证和不可达边界见[八面板验收清单](../projects/IKIZ2Y/generation-dock-acceptance.md)。

## 已确认决策

### 第一轮

1. Q1，2026-10-07。以当前发布线的实际交互和有效规格作为兼容基线。已有缺陷单独记录，再确定修复范围，不在重构中顺带改变产品行为。
2. Q2，2026-10-07。允许等价迁移测试。先建立协调器公开接口覆盖，再收敛重复整页断言；保留各面板差异与真实页面接线测试。后续工单规格应以此条替代原有“测试仅允许机械性调整”的限制。
3. Q3，2026-10-07。统一八面板的打开、关闭、互斥和活动面板视图。五个普通面板的页面编排状态迁入协调器；高清、视频 HD、视频插帧继续读取和调用工具会话运行时。详见 [状态分工 ADR](../adr/0123-generation-dock-coordinator-ownership.md)。

### 第二轮

1. Q4，2026-10-07。协调器接管五个普通面板的显隐、草稿绑定、选择豁免、seed 快照和草稿参数派生。节点与连线继续作为画布数据的权威来源，通过宿主能力读取和更新，不复制画布数据。
2. Q5，2026-10-07。表单内部编辑、菜单、上传和展开状态继续留在各面板组件；保留关闭卸载、草稿等值 seed 不重挂和真实变化重挂等已有生命周期。协调器提供视图模型与少量动作回调，不统一托管所有表单字段，也不新增音乐或自由面板的内容恢复。
3. Q6，2026-10-07。页面保留节点选中态规范化、参考选取和工具事件的既有处理顺序，再将适用的选择事件与点卡意图交给协调器。面板联动集中处理，显式关闭、选择导致隐藏和手动重开分别表达；本票不迁移整个画布选择或参考选取流程。

### 第三轮

1. Q7，2026-10-07。公开接口采用只读视图模型与语义动作，动作涵盖打开、关闭、全部收起、草稿编辑和发送。面板调用方无需访问内部显隐 setter、选择豁免标记或其他面板状态；页面宿主接入适用的选择事件。
2. Q8，2026-10-07。用一个静态、带类型约束的注册入口绑定面板渲染、打开策略、视图派生与专属提交接线。新增面板的协调接入只新增一项注册，不再修改页面互斥分支或共同发送骨架；新组件与专属业务协议仍按需要实现，不建设表单配置引擎。
3. Q9，2026-10-07。协调器统一发送编排，类型定义承载专属准备步骤、交接方式和面板收尾时机。后台任务交给已有生成任务运行时，三个工具面板复用已有会话提交接口；文生文继续本地写卡，音乐保留当前处理，各类面板的实际关闭点保持不变。

### 第四轮

1. Q10，2026-10-07。页面宿主通知项目、文档和节点变化，协调器与工具运行时分别执行现有清理规则。卸载时协调器释放自身新增的订阅等资源，任务与工具运行时保留各自职责；不新增切换或重载统一关闭八面板并清空编辑的规则。
2. Q11，2026-10-07。通过与调用方相同的公开接口验证共同规则，注入可控画布宿主、发送结果与工具会话适配器。覆盖八面板互斥、选择豁免、绑定与 seed、提交差异和生命周期；保留专属行为与页面接线，用测试面板定义验证只加注册项即可接入协调层。观察视图、请求、节点写回和清理，不断言私有字段或 setter 次数。

## 接口与注册约束

| 接口类别 | 调用方可做的事 | 模块内部负责的规则 |
| --- | --- | --- |
| 只读视图 | 读取活动面板、绑定目标、初始化输入及当前可用性，渲染对应面板 | 从五普通面板状态与三工具会话快照派生统一活动视图，保留 seed 身份 |
| 打开与关闭动作 | 表达从工具栏、点卡、重新编辑等入口打开某面板，或显式关闭当前面板 | 统一互斥与准入；按注册策略处理绑定、参考选取退出和关闭差异 |
| 全部收起动作 | 通过一个入口收起八面板 | 协调五普通面板并调用三个工具面板的既有关闭能力 |
| 草稿编辑动作 | 按面板类型表达已存在的草稿编辑 | 通过宿主执行原有节点写回及派生规则，保留组件局部状态 |
| 发送动作 | 提交当前面板已有的输入形态 | 集中共同编排，按类型准备、交接和收尾，保持各路径实际完成点 |

视图模型承担读取与展示，动作承担用户意图，调用方不再手工关闭其他面板或组合页面状态。参考选取和工具事件按 Q6 保留宿主处理顺序。

### 整体接口形态

下表给出语义接口，方法名用于设计交接。输入按已有面板类型约束，复用已有草稿与发送类型；接口不新增服务端字段。

| 动作 | 输入含义 | 契约 |
| --- | --- | --- |
| open(request) | 面板身份、入口意图及该入口已有的目标或初始化输入 | 从一个入口执行准入、互斥与类型策略；手动重开和选择联动分别表达 |
| close(reason) | 当前面板已有的显式关闭意图 | 按类型关闭及清理；与选择导致隐藏不同 |
| dismissAll(reason) | 现有操作要求收起八面板的意图 | 协调普通面板与工具句柄，按已有收起规则执行 |
| updateDraft(change) | 对应面板已有的草稿编辑输入 | 调用原有节点写回能力并派生展示，不接管组件局部表单状态 |
| submit(input) | 对应面板现有发送回调的输入 | 集中共同规则，按类型准备、交接及收尾；保持返回语义和组件等待方式 |

只读视图提供活动面板或空状态、对应面板的视图模型与动作。活动身份从唯一状态所有者派生，组件不保存可独立修改的镜像开关。视图中的绑定目标、初始化内容和可用性来自既有编排状态与宿主事实；seed 的等值身份保持，不因普通通知产生新挂载标识。

互斥的可观察约束是同一时刻最多一个实际可见面板。保留的绑定或隐藏草稿不等于活动面板，也不因另一面板显示而自动获得新恢复能力。所有八面板打开和全量收起入口经过协调接线；普通面板活动身份集中维护，三个工具面板由已有会话快照提供事实，统一活动视图作为派生结果读取。

宿主接入分为适用选择事件、项目与文档变化、节点变化、模块卸载四类通知。宿主负责先完成 Q6 的事件规范化和消费顺序；模块按 Q10 分派清理，工具会话仍通过原有 setProject、reconcileSources 和提交能力处理自身状态。通知不代表统一关闭指令。

发送回调保留各类型的同步或异步形态。普通任务的 boolean true 只表示提交链登记，高清、HD、插帧沿用已有会话交接，文生文和音乐不被包装成后台任务。共同能力集中承载现有门槛、锁、保存、交接及收尾规则；类型定义负责真实差异，不复制共同规则，也不强制所有准备步骤采用相同顺序。画布宿主和任务运行时已有的锁与数据归属能力继续复用，协调器不创建另一套任务锁或恢复协议。

静态注册项连接现有面板组件及其协调策略。三个工具面板通过同一注册入口引用已有工具会话句柄，不复制 state、visible、hidden 或 submitting。注册承诺覆盖协调层：新面板不要求修改公共互斥与发送分支，其专属组件和协议依然有自己的实现位置。共同规则和类型差异均须通过接口验收，不能只把旧参数包进一个对象而保留页面重复规则。

## 发送路径现状

发送完成点与锁的时机存在真实差异。统一协调的设计不能把“提交链已登记”解释成“请求已发送”“服务端已受理”或“任务已完成”。

| 路径 | 当前处理 | 当前面板收尾 |
| --- | --- | --- |
| 图片、视频、音频 | 按各自顺序校验、处理引用和保存，再经 startGenerationJob 调用任务运行时 submit | 同步返回 true 时关闭；该结果仅表示提交链登记，运行时此后仍可能等待预保存 |
| 文生文 | 合成附件与正文，直接更新文本节点，不创建后台任务 | 写卡后关闭 |
| 音乐 | 现有页面 handler 仅打印日志，不创建后台任务 | handler 不关闭面板 |
| 高清、视频 HD、插帧 | 使用现有工具会话提交接口；高清启动后退出界面，HD 等交接 Promise 结算后关闭，插帧按同步调度结果关闭 | 收尾仍受工具会话身份守卫，并保留各自关闭点 |

普通图片与视频组件会等待页面发送回调，音频组件不等待；自由音频在调用页面回调后立即清空正文和本地引用。视频部分引用在前置保存后从连线读取，插帧的任务冻结参数在受理回调中更新。当前路径不存在“五类面板均在首次异步等待前冻结完整输入”的共同事实，因此本票不能未经确认把所有准备步骤改成同一顺序。

来源为 `index.tsx:4039`、`:6409`、`:8942`、`:9717`、`:9785`、`:9884`，`generationRuntime/runtime.ts:410`、`:454`、`:510`，`toolSessionRuntime.ts:171` 和 `panelToolSessions.ts:79`、`:111`、`:138`，均位于 `web/src/pages/CanvasPage/`。这些结论已经通过 search_graph、trace_path 和 get_code_snippet 核验，所引用生产文件 coverage 为 metadata_match，未记录解析问题。

### 单独记录的源码风险

普通三面板的异步准备回调在后续隐藏与 finally 清锁时，没有已查明的面板会话身份守卫；任务运行时的项目、加载纪元、节点及执行归属校验不能代替界面归属校验。尚未复现“发送准备中关闭后同卡重开，旧准备完成关闭新面板”的用户序列，不能把它作为已验证缺陷或本票新增必修项。按 Q1 单独记录，后续如需修复，先复现并确认范围。
