# 方案编辑与逐目标素材同步（IKETSY）

## 时间

2026-09-11

## 背景与基线

承接 IKE5G8 已确认规格及 IKETSW/X 的共享引用契约，基线为本地 release/2026.09.15 的 52a89ca4。只有方案节点保存可编辑正文，各目标保留自己的确认集合。

## 同步命令

复用 `POST /api/canvases/:projectId/prompt-references`，增加可选 `syncBindings: Array<{index,assetId}>`。不传时保持首次引用行为；传入时表示用户明确同步一个已引用方案到一个目标。数组取点击时方案的规范化绑定（按 index 排序去重），包括删除全部标签时的空数组。

客户端先保存编辑，再携带保存版本 `expectedVersion` 与点击时 `syncBindings`。服务端要求画布版本及当前方案绑定同时匹配，绑定不匹配或版本过期返回 412；不得把旧确认套用于后续素材编辑。事务保存继续复核版本、素材存在性和访问权限。

同步只更新指定方案到指定目标的确认集合和该目标媒体入边。删除旧的方案来源后，仅清除无手动来源且无其他方案来源的媒体边；保留其他目标、其他方案、手动来源、媒体卡和目标草稿。新增引用继续按 assetId 去重，验证素材和目标模型后原子保存。失败不产生部分边。

## 编辑、生成与恢复

方案编辑保存正文、标签区间、身份和素材展示元数据。新增标签只从画布中的明确素材身份选择；替换保持该标签编号，删除移除对应标签。纯文字变更不改变确认集合。待同步状态由当前绑定与目标确认集合比较派生，不保存可过期的布尔标记。同步期间继续编辑，返回值仅更新连线，当前编辑保留并重新推导待同步状态。

图片与视频消费相同确认语义。公开生成 API 继续校验当前保存内容、直接连线与确认集合，拒绝未同步输入；接纳后的任务与重试保持原快照。

## 验证

沿用已确认的真实浏览器、公开业务 API、独立本地数据库测试边界。覆盖 A/B 独立确认、共享来源、空绑定、过期确认、失败原子性、当前文字与历史快照；不替换业务 API。
