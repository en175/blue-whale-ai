# Canvas 外部标题行分段缩放设计

## 时间

2026-09-06

## 状态与背景

用户已逐项确认范围、缩放阈值、字号边界与连续变化规则。本文件记录设计决策，尚未实现。

本设计补充 [Canvas 四类节点卡片布局规格](2026-09-05-canvas-node-card-layout.md)，关联 IKDICP 的后续体验优化，不改变原有内容区尺寸策略与自由编排。

现有标题随 Canvas 整体缩放。名称为 11px、元信息为 10px，在截图的 63% 缩放下，屏幕可见字号约为 6.93px、6.3px；放大时又会无限随倍率增大。目标是在常用范围保障可读、放大封顶、远景总览时释放最小字号限制，避免文字占满画面。

## 范围与用语

外部标题行指图片、视频、音频、文本四类卡片内容区上方的类型图标、现有名称，以及有值时的分辨率和时长。整行参与适配。

屏幕字号指经过 Canvas 缩放后实际看到的 CSS 像素大小，不是字体样式中未经变换的数值，也不是设备物理像素。总览阈值指开始释放可读下限的 Canvas 缩放倍率。

文本正文、音频播放器、卡片内容区和操作工具栏的大小行为保持现状。只调整工具栏与标题的相对位置以避免重叠。不修改名称生成、元信息内容、连接关系或卡片位置；不增加自动排布。本设计中的分辨率仅改变文字显示大小，显示值仍为真实媒体分辨率。

## 已确认规则

Canvas 可操作缩放范围保留 50%～800%。总览阈值为 75%，标准阅读倍率为 100%。

| 元素 | 标准大小 / 可读下限 B | 放大上限 M |
| --- | ---: | ---: |
| 名称 | 12px | 16px |
| 分辨率、时长 | 11px | 14px |
| 类型图标边长 | 14px | 18px |

令 z 为 Canvas 缩放倍率（100% = 1），S 为屏幕上的字号或图标边长，各元素分别应用以下规则：

```text
z < 0.75：       S = B × z / 0.75
0.75 ≤ z ≤ 1：  S = B
z > 1：          S = min(B × z, M)
```

低于总览阈值后不再保障最小字号，随卡片等比例缩小，始终保留而不突然隐藏。公式在各段连接处连续；不要求变化速率连续。各元素独立到达自身上限：名称为 133⅓%，辅助信息约为 127.27%，图标约为 128.57%。

如果元素仍位于受 Canvas 缩放变换的节点内部，所需局部尺寸为 S / z；具体使用字体尺寸还是局部变换由实现决定，但最终屏幕尺寸必须满足公式。

| Canvas 缩放 | 名称 | 辅助信息 | 图标 |
| --- | ---: | ---: | ---: |
| 50% | 8px | 7.33px | 9.33px |
| 63% | 10.08px | 9.24px | 11.76px |
| 75% | 12px | 11px | 14px |
| 100% | 12px | 11px | 14px |
| 125% | 15px | 13.75px | 17.5px |
| 150%～800% | 16px | 14px | 18px |

表中小数为展示近似值，计算保留精度，允许正常的亚像素渲染误差。

## 排版与交互约束

标题行高度、图标间距与字号一起适配，避免字形被纵向裁切。标题行仍占据卡片内容区的宽度，名称及元信息单行截断，不能撑宽节点或伸入邻近卡片。极窄卡片仍优先遵守宽度限制，不为完整显示文字扩大卡片。

操作工具栏保持原有大小行为，其位置须避开适配后的标题行。缩放不得改变卡片内容尺寸契约、已保存坐标、选中状态、拖动状态或连线端点与内容区的对应关系。

## 验证场景

1. 对四类卡片检查 50%、63%、75%、100%、125%、150%、800% 下的实际屏幕字号或图标尺寸，验证公式和上下限。
2. 在 75%、100% 和各元素封顶倍率的两侧连续缩放，确认尺寸连续、无突然隐藏或跳变；低于 75% 后继续缩小。
3. 使用长名称、完整视频元信息、极窄竖图与缺失元信息，确认标题不撑宽、单行截断、图标和文字无纵向裁切。
4. 在选中、拖动、连接和媒体加载状态下缩放，确认工具栏不遮挡标题、卡片不回跳、内容区与连接点关系保持正确。
5. 在真实浏览器中验收字号、间距、截断与工具栏位置；公式单测只能证明数值，不能替代实际布局验收。正文、播放器及工具栏大小行为应与改动前一致。
