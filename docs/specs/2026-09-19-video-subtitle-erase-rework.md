# 画布视频智能去字幕交互推翻重做（R3，ADR-0104）

> 规格工单：**IKH3NP**（id 34390213，需求型、P1、ready-for-agent，2026-09-19 发布）。
> 权威口径：docs/adr/0104-video-subtitle-erase-interaction-rework.md。
> 性质：!756（IKGZ7V）已上线功能的前端交互返工，后端契约与 worker 零改动。

## Problem Statement

!756 上线的智能去字幕交互形态被推翻（Kim 以四张截图定案，判「完全错误」）：单按钮直启把模式选择藏进会话内「全画面文字」开关，与「有无拉框」共同推导发送语义，用户难以理解；「上方工具条+下方发送条」双条布局与画质工具家族的目标形态不符。

## Solution

模式选择前置到入口：「智能去字幕 ▾」下拉触发钮（交互同图片「高清 ▾」家族），菜单两项「智能去字幕」「框选去字幕」各进一种会话——智能模式零工具直发（极简单条），框选模式必框+重置（完整单条）；编辑态统一为视频下方单条；「全画面文字」开关废除；「音视频分离」入口与编辑态同步对齐家族形态；后端契约零改动。

## User Stories

1. 作为画布用户，我想悬停视频卡工具条上的「智能去字幕 ▾」按钮时自动展开下拉菜单，以便无需点击就能看到全部去字幕方式。
2. 作为画布用户，我想让「智能去字幕 ▾」触发钮文案固定不变，以便形成稳定的肌肉记忆（不随使用历史变化）。
3. 作为画布用户，我想在菜单中看到「智能去字幕」与「框选去字幕」两个纯文字选项，以便一目了然地区分全自动与手动两种去字幕方式。
4. 作为画布用户，我想在悬停「智能去字幕」菜单项时看到「自动擦除画面下半字幕」说明，以便理解智能模式的边界。
5. 作为画布用户，我想在悬停「框选去字幕」菜单项时看到「拉框指定要擦的区域」说明，以便理解框选模式的用法。
6. 作为画布用户，当视频分辨率超 2K 或时长超 10 分钟时，我想让「智能去字幕 ▾」整钮置灰且悬停显示原因，以便提前知道该视频不可处理。
7. 作为画布用户，当入口置灰时我想悬停仍能展开菜单查看两项说明，以便理解置灰是整卡门槛而非某一模式不可用。
8. 作为画布用户，我想让菜单在指针移出后延迟 120ms 关闭、Esc 与点击外部立即关闭，以便滑向菜单不误关、需要时能快速收起。
9. 作为画布用户，我想点击菜单「智能去字幕」直接进入智能模式会话，以便一步开始全自动去字幕。
10. 作为画布用户，我想在智能模式会话只看到「X | 智能擦除 ⚡0 | ↑」的极简单条，以便不被多余工具干扰。
11. 作为画布用户，我想在智能模式直接点发送就提交任务，以便零参数完成全自动去字幕。
12. 作为画布用户，我想让智能模式固定检测画面下半部分字幕（火山默认范围），以便获得稳定可预期的智能擦除效果。
13. 作为画布用户，我想点击菜单「框选去字幕」进入框选模式会话，以便手动指定要擦除的区域。
14. 作为画布用户，我想在框选模式看到「X | 框选擦除 ？ | 框选 / 撤销 / 重做 / 重置 | ⚡0 | ↑」完整单条，以便完成精细的区域指定。
15. 作为画布用户，我想在视频画面上拉出半透明检测框（最多 20 个），以便框选分布复杂的字幕区域。
16. 作为画布用户，我想让框落笔即固化、修改靠撤销/重做/重置，以便误操作可回退。
17. 作为画布用户，我想让重置一键清空全部框且可通过撤销恢复清空前的框，以便误触重置也能救回。
18. 作为画布用户，当还没有拉任何框时我想让发送钮置灰并悬停提示先拉框，以免误发空框任务。
19. 作为画布用户，我想悬停「？」帮助图标时看到框选效果说明，以便理解框与擦除范围的关系。
20. 作为画布用户，我想让进入任一去字幕模式后视频暂停锁定在当前帧（无播放与进度条控制），以便稳定框选。
21. 作为画布用户，我想让进入会话后顶部悬浮工具栏隐藏，以便画面专注。
22. 作为画布用户，我想在发送前通过 X/Esc/点其他卡/点画布空白四路退出且不建卡，以便随时反悔零成本。
23. 作为画布用户，我想让会话内不提供模式切换入口，以便模式语义清晰（换模式退出重选）。
24. 作为画布用户，我想让发送钮旁显示 ⚡0 积分徽标，以便知道本期免费。
25. 作为画布用户，我想悬停发送钮看到「输出最高 1080P」说明，以便了解输出规格。
26. 作为画布用户，我想发送后在源卡侧看到去字幕占位卡并最终得到字幕被无痕擦除的成品视频（音轨保留、失败可重试），以便继续后续创作。
27. 作为画布用户，我想让「音视频分离」入口也以「▾」下拉形态出现在视频工具条（单菜单项），以便与去字幕入口形态一致。
28. 作为画布用户，我想让音视频分离编辑态也是视频下方单条（X | 音视频分离 + 分离格式下拉 + ⚡0 | ↑），以便与去字幕编辑态形态统一。
29. 作为画布用户，当视频未关联资产时我想让「音视频分离 ▾」整钮置灰且悬停说明，以便知道不可用的原因。

## Implementation Decisions

- 入口：「智能去字幕」单按钮改「智能去字幕 ▾」下拉触发钮，交互复用图片画质家族下拉口径：悬停自动展开、移出 120ms 延迟关闭、Esc/点外关闭；固定文案不做最近工具记忆；菜单两项纯文字；整钮置灰（分辨率>2K 或时长>10 分钟门槛沿用，宽高/时长缺失放行）且 hover 仍展开菜单；菜单项直启进对应模式会话。
- 模式建模：去字幕编辑态分「智能模式」「框选模式」两态，入口菜单定死，会话内不互切，换模式=X 退出后重选。
- 智能模式：detect_mode 固定 `subtitle_smart`、无框直发、零框选工具；单条=X、「智能擦除」标题、⚡0、发送。
- 框选模式：detect_mode 固定 `subtitle_smart` + 检测框集合随任务提交；无框发送钮置灰（title 提示先拉框），不回落智能语义；框上限 20、归一化坐标、落笔固化；撤销/重做/重置，重置=清空全部框且作为可撤销操作进 undo 栈；单条=X、「框选擦除」标题、？帮助、框选/撤销/重做/重置、⚡0、发送。
- 编辑态布局：废除「上方工具条+下方发送条」双条，两模式统一视频下方单条，锚定源卡下方居中并跟随缩放平移；会话期顶部悬浮工具栏隐藏、视频暂停锁定、四路退出（X/Esc/点其他卡/点画布空白）未发送丢弃——全部沿用现状。
- 「全画面文字」开关删除；`text_full` 参数契约保留但本期无 UI 入口（后端枚举不动）。
- 发送条信息：⚡0 积分徽标（本期免费）取代「本期免费」文字；「输出最高 1080P」挪到发送钮 title；发送钮沿用家族灰底↑样式。
- 发送闭环沿用：占位卡+轮询+终态补丁、失败可重试（原参数重发）。
- 音视频分离联动：入口改单菜单项「▾」下拉（唯一置灰条件 assetId==null，整钮置灰 hover 展开）；编辑态单条化（X | 音视频分离 | 分离格式下拉 | ⚡0 | ↑）；「本期免费」文字改 ⚡0 徽标。
- 后端契约零改动：job type、detect_mode 枚举、boxes 字段、错误码、异步链路全部不动。
- 自查细节：菜单项无图标、单条 X 在最左、重置图标环形箭头、智能模式无 ？帮助、框选模式有。

## Testing Decisions

- 只测外部行为，不测实现细节。
- 四层既有接缝全部复用、零新增（均为 !756 已建立测试面的改造）：纯逻辑（参数推导+门槛判定）/ 编辑态组件（两条单条形态、开关删除、无框置灰、重置可撤销）/ 工具栏（下拉交互、整钮置灰 hover 展开、菜单直启）/ 画布集成（模式入会话、不互切、四路退出、发送闭环、undo 栈含重置）。
- 先例：既有去字幕纯逻辑/编辑态/工具栏三套测试文件改造；后端与 worker 无测试面变化。

## Out of Scope

- `text_full`（全画面检测）的 UI 入口（本期无途径，能力回退已知，产品再拍板时以新入口回归）。
- 截图其余按钮：视频卡「高清 ▾」、片段重拍、逐帧拉片、主体消除、截取当前帧。
- 模式就地切换。
- 分时段框（time_segment_filter 契约留位不变）。
- 后端契约、worker、网关的任何变更。
- 智能模式耗时告知（沿既有口径不做）。
