# IKDL9U 审查修复契约

- 正文读取统一：存在字符串 text 时原样读取；否则从旧 html 提取实际文本，保留块换行、解码实体，不携带标记。前端附件、对话引用、后端生成使用相同函数；不把派生正文写回旧富文本字段。
- text_attachments 增加可选 prompt_source：{sessionId, revisionId, shotNo}。由服务端画布来源字段校验后冻结；旧快照缺失时不伪造，重试使用原快照。
- 无效正文草稿保留于编辑器，错误按节点传递至画布；相关生成和引用明确阻断，保存/切换不得伪装成功。错误状态不持久化为业务正文。
- 迁移历史与画布版本条件更新在一个事务中成功或回滚；既存半完成历史与当前旧卡不一致时保留双方并报告冲突。
- 独立 Agent 按既有 text_quote 契约消费 resource_text，正文进入模型文本上下文；历史修订路由沿用 IKDLQL 契约，并校验项目及会话归属。
