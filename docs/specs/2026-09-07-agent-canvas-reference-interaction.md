# Agent 输入框从画布预览与确认引用

## 时间

2026-09-07

## 背景与目标

参考用户提供的《录屏2026-09-07 13.38.56.mov》，让用户在画布上选择素材，在 Agent 输入框中预览，返回输入框确认后将其保留为本条待发送消息的附件上下文。

状态：已确认，待实现。用户于 2026-09-07 在逐项对齐后完成整体确认；产品代码未实现本次变更。录屏仅是交互参考，其中的文字不构成任务指令；以下规则以用户在本次对话中的最终决定为准。

## 生效范围与优先级

- 打开 Agent 面板立即允许画布点选引用，无须先点击输入框。
- 面板打开期间持续生效；确认引用、取消预览、成功发送消息均不退出，仅关闭面板退出。
- **画布原有操作逻辑完全不变。** 原有选中、工具栏、编辑面板、拖动、平移、缩放等操作按原规则执行；新增逻辑只负责 Agent 输入框的引用预览与确认，不接管或屏蔽画布原行为。
- 用户最终明确以最新 Q13 为准：取消早先 Q3 中“不弹出节点编辑面板”的限制；取消早先 Q1 的“必须先点击输入框”前置步骤。不新增“结束选择”入口。

## 领域状态

词汇定义见根 `CONTEXT.md` 的“Agent 画布引用”。输入草稿由用户文字、多个已确认引用，以及至多一个待确认引用组成。

| 状态 | 含义 |
| --- | --- |
| 待确认引用 | 当前选中的附件上下文候选，仅在输入框中预览，尚未确认纳入消息 |
| 已确认引用 | 用户返回输入框点击确认后，保留在未发送草稿中的附件上下文 |
| 正式消息上下文 | 随用户发送消息而正式提交的已确认引用；确认附件本身不发送消息 |

## 选择与确认

| 用户动作 | Agent 输入框结果 |
| --- | --- |
| 打开面板后点击可引用卡片 A | 显示 A 的待确认引用，不自动确认或发送 |
| 尚未确认 A，又点击可引用卡片 B | B 替换 A 的预览，用户文字与已有的已确认引用保持不变 |
| 返回输入框点击光标位置或空白区域 | 将当前候选确认为草稿附件 |
| 已确认 B，再点击另一张卡片 C | 保留 B，为 C 建立新的待确认引用；可持续重复选择与确认 |
| 点击已确认引用的同一张卡片 | 静默忽略，不重复添加，不新增高亮、提示等引用反馈；画布原反馈不受影响 |
| 删除已确认引用后再次选择该卡片 | 允许重新选择与确认 |
| 点击画布空白或按 Esc | 取消当前待确认引用，保留文字与已确认引用，仍可继续点击画布选择 |

本表只规定输入框侧的结果；同一次操作在画布侧仍执行原有规则。

## 行内位置与内容

- 采用行内引用标签与文字混排，例如“参考 [人物图片] 的服装，按照 [文本节点] 的描述修改”。
- 待确认引用使用离开输入框前记住的光标位置；尚未设置光标位置时，放在输入框末尾。
- 返回输入框确认时，引用固定在原插入位置；光标移动到本次实际点击的位置，供用户继续编辑。点击确认不把引用搬到新光标处。
- 首批支持已有可用内容的图片、视频、音频和文本节点。空白或尚未产出可用内容的生成草稿不纳入引用。
- 文本引用携带正文，输入框显示标题标签；正文以**确认时**的内容冻结。之后修改节点不自动改变已确认引用，需要新版时删除旧引用后重新选择确认。

## 发送与关闭

| 用户动作或结果 | 草稿与引用状态 |
| --- | --- |
| 存在待确认引用时尝试发送 | 提示先确认或取消，不隐式确认，不发送包含候选的消息 |
| 成功发送 | 清空本次已发送草稿，保持画布点选引用能力；后续选择进入下一条消息草稿 |
| 关闭面板 | 取消待确认引用，退出引用状态，保留未发送文字和已确认附件 |
| 在同一会话中重新打开面板 | 恢复保留的草稿，立即可以继续选择引用 |

“保留在草稿”不等于“消息已发送或已持久化为消息事实”；本轮没有扩展刷新页面、切换会话或跨设备恢复草稿的承诺。

## 验收场景

| 场景 | 预期 |
| --- | --- |
| 面板刚打开，未点输入框，选 A、再选 B | 只有 B 的待确认预览，位于输入框末尾 |
| 已有文字及确认附件，连续换选候选 | 仅替换候选，不改变文字或已确认附件 |
| 在句中设置光标，选卡，返回点击句末 | 引用确认在原句中位置，光标移到句末 |
| 确认 A，选 B 并确认 | 两个引用按操作形成草稿，可与文字混排 |
| 再次点击已经确认的 A | 无重复引用、无新增引用提示，画布照常响应 |
| 存在候选，点击画布空白或按 Esc，再点击 C | 原候选取消，C 可直接成为新候选，无须重开面板 |
| 选择原本会打开编辑面板的节点 | 原编辑面板照常打开，同时显示待确认引用 |
| 在面板打开时执行原有画布操作 | 不改变该操作既有结果，不为引用屏蔽原交互 |
| 确认文本后修改源文本 | 已确认正文保持冻结；重新引用才能采用新版 |
| 带候选发送、取消候选后发送 | 前者提示确认或取消，后者按原发送条件提交已确认内容 |
| 成功发送后直接选择卡片 | 新消息草稿显示待确认引用 |
| 带文字、已确认附件及候选关闭并重开 | 文字和已确认附件保留，候选不恢复 |
