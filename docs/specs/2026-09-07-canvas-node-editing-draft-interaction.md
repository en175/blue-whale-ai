# Canvas 媒体节点编辑草稿与原卡重新生成

## 时间

2026-09-07

## 背景与状态

用户希望通过提示词生成的图片、视频、音频节点在选中时显示对应生成面板，保留可继续编辑的输入。本文记录 grill-with-docs 访谈中逐轮确认的决定。第一、二轮 Q1–Q8 已确认，多选与保存失败后的节点切换边界待讨论；未开始产品实现，未同步外部工单。

本修订替代既有生成草稿规格中成功卡“再次编辑立即复制新草稿”的规则。侧栏创建新草稿不是本次修订对象。

## 已确认决定

| 编号 | 决定 | 用户可见行为 |
| --- | --- | --- |
| P1 | 选择驱动面板显示 | 选中有生成记录的图片、视频或音频节点，打开对应生成面板；点击画布空白区域隐藏面板 |
| P2 | 编辑自动持久化 | 修改原节点的提示词自动保存；编辑、切换显示或保存本身不触发生成 |
| Q1 | 原卡重新生成 | 选中、修改和发送均不新增卡片；用户手动点击发送，生成的新素材替换原卡素材 |
| Q2 | 只保留最新编辑输入 | 用 A 生成素材后改成 B，即使未发送，下次选中仍显示 B；无需提供 A 的保留、查看或恢复功能，不新增提示词版本历史 |
| Q3 | 恢复完整生成配置 | 恢复提示词、模型及适用于媒体类型的比例、分辨率、时长、参考素材等配置；模型或参考素材不可用时明确提示，用户调整后再发送 |
| Q4 | 上传素材不自动打开面板 | 本轮自动显示面板仅针对有生成记录的节点；上传素材保留现有选中行为 |
| Q5 | 成功后才替换旧素材 | 重新生成期间继续显示旧素材并标记生成中；成功后替换，失败或取消保留旧素材与最新编辑内容 |
| Q6 | 原卡重新生成固定单结果 | 原卡重新生成每次固定为 1 个结果，不产生额外结果卡；本决定不改变侧栏新建草稿的数量规则 |
| Q7 | 引用关系跟随节点保留 | 替换素材后保持引用连线；下游节点下次手动生成时使用新素材，已有生成结果不变，正在执行的任务仍使用提交时的素材 |
| Q8 | Enter 仅换行 | 生成面板内编辑提示词时 Enter 仅换行，图片、视频、音频生成均必须手动点击发送，键盘输入不触发生成 |

“无需保留 A”约束节点编辑与用户可见历史功能，不构成清除既有任务输入快照或审计记录的授权。

## 待确认边界

- 多选节点时生成面板是否隐藏。
- 自动保存失败时，是否允许切换至其他节点继续编辑。

未列为已确认的方案不得直接实施；完整交互方案需用户最终确认。

## 当前源码核查

只读源码核查，未运行浏览器交互或测试：

- 节点已有 `data.prompt`，生成成功合并更新不清除该字段，Canvas 保存保留此字段；因此缺口不是所有生成提示词都未持久化。
- 成功卡普通点击未接通生成面板与节点编辑绑定；空白点击未接通隐藏 Dock。
- 已有“重新编辑”可回填图片或视频提示词，但成功卡编辑未建立自动回写绑定；音频面板缺少节点绑定与提示词初值。
- 图片和音频面板当前存在 Enter 快捷发送，已确认按 Q8 移除。

## 已确认验收场景

| 场景 | 预期结果 |
| --- | --- |
| 将生成节点提示词从 A 改为 B，不发送，保存成功后刷新重选 | 恢复 B 与最新生成配置；卡片数量和当前素材不变，不提供 A 的版本恢复功能 |
| 原卡重新生成成功 | 仅产生 1 个替换结果，仍由原卡承接，节点身份与引用连线保持 |
| 原卡重新生成尚未结束、失败或取消 | 生成中显示旧素材与生成状态；失败或取消后仍保留旧素材与最新编辑内容 |
| 下游节点引用的原卡素材被替换 | 下游已有结果不自动改变；正在执行的任务使用提交快照；下次手动生成使用替换后的素材 |
| 在三类生成面板编辑提示词并按 Enter | 仅换行，无生成请求；手动点击发送后才提交生成 |

以上是待实现的验收要求，不是已执行的测试结果。

源码入口：`web/src/pages/CanvasPage/index.tsx`、`web/src/api/canvas.ts`、`web/src/pages/CanvasPage/components/ImageDialog/index.tsx`、`web/src/pages/CanvasPage/components/AudioDialog/index.tsx`。此为本次调查快照，实施前须以最新代码验证。
