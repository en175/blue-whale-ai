# 画布参考节点持续选取交互

## 时间

## 状态

## 背景与目标

用户提供的录屏「录屏2026-09-10 16.07.24.mov」中，为金发人物图片节点从画布添加参考图片后，生成面板消失；重新点击目标节点，面板中的参考缩略图已经增加。相同过程重复三次。目标是让用户一次进入选取模式后连续添加所需参考，并有明确方式结束选取。

当前源码将添加参考、结束选取与按普通画布选中态隐藏生成面板分别处理。这些行为与录屏现象一致；尚未通过浏览器事件插桩确认具体回调顺序。

## 第一轮已确认决定

用户于本轮对以下三项回复「全部按推荐」。

| 决策 | 已确认行为 |
| --- | --- |
| 持续边界 | 本次交互中保持选取模式，直到主动退出；刷新页面或切换画布后退出模式，保留已添加参考。 |
| 生效时机 | 每次有效点击立即添加参考；退出只结束选取，不撤销本轮参考；不引入暂选后统一确认。 |
| 适用范围 | 图片、视频、音频生成面板的从画布选择入口统一适用，保留各自素材类型和数量限制。 |

领域术语为「画布参考选取模式」，定义见根 CONTEXT.md。它与普通画布多选、Agent 对话引用不同。

## 第二轮已确认决定

用户对 Q4–Q8 回复「全部按推荐」。

| 决策 | 已确认行为 |
| --- | --- |
| 主动结束选取 | 提供明显的「完成选取」按钮，并支持 Esc。点击画布空白不退出。完成后仍显示原目标的 Dock，保留全部参考。 |
| 重复点击与删除 | 已添加节点显示勾选标识；重复点击不新增、不移除。移除参考使用 Dock 缩略图上的移除按钮。 |
| 选取期间的操作 | 允许平移、缩放画布；节点点击仅用于选择参考。暂不允许拖动节点、框选或切换编辑目标。Dock 保持可见，编辑提示词、切换模型与生成操作须先完成选取。 |
| 单槽位参考 | 视频首帧、尾帧等单槽位的选取模式仍持续；连续点击替换当前槽位，最后一次有效选择生效，其他槽位不变。 |
| 非法输入与上限 | 类型不符或数量已满时，不添加、不退出，明确提示原因。达到上限后仍可在 Dock 移除参考，再继续选择。 |

## 待确认的设计分支
