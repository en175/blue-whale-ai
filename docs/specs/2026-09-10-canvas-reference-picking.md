# 画布参考节点持续选取交互

## 时间

2026-09-10

## 状态

三轮交互决定已逐项获用户确认，等待整体设计最终确认；尚未开始产品实现。

## 背景与目标

用户提供的录屏「录屏2026-09-10 16.07.24.mov」中，为金发人物图片节点从画布添加参考图片后，生成面板消失；重新点击目标节点，面板中的参考缩略图已经增加。相同过程重复三次。目标是让用户一次进入选取模式后连续添加所需参考，并有明确方式结束选取。

当前源码将添加参考、结束选取与按普通画布选中态隐藏生成面板分别处理。这些行为与录屏现象一致；尚未通过浏览器事件插桩确认具体回调顺序。

## 第一轮已确认决定

用户于本轮对以下三项回复「全部按推荐」。

| 决策 | 已确认行为 |
| --- | --- |
| 持续边界 | 本次交互中保持选取模式，直到主动退出；刷新页面或切换画布后退出模式，保留已添加参考。 |
| 生效时机 | 每次有效点击立即添加参考；退出只结束选取，不撤销本轮参考；不引入暂选后统一确认。 |
| 适用范围 | 图片、视频、音频生成面板的从画布选择入口统一适用，保留各自素材类型和数量限制。 |

领域术语为「画布参考选取模式」，定义见根 CONTEXT.md。它与普通画布多选、Agent 对话引用不同。

用户对 Q9、Q10、Q11 分别回复「按你推荐的」。

| 决策 | 已确认行为 |
| --- | --- |
| 关闭面板 | 直接结束选取并关闭 Dock，保留参考，不弹二次确认；重新打开时恢复普通编辑。 |

## 完整交互流程

1. 用户打开某个生成目标的 Dock，选择从画布添加参考，进入绑定该目标及当前参考槽位的选取模式。
2. Dock 持续可见，用户可以平移、缩放画布并连续点击节点；有效选择立即更新参考及勾选标识，目标不切换。
3. 多参考场景按现有限制连续添加，重复点击不改变结果；单槽位场景仅替换当前槽位。类型不符或数量满时提示原因并保持模式，用户可从 Dock 移除参考后继续。
4. 点击「完成选取」或按 Esc 结束模式，保留参考与原目标 Dock，恢复普通编辑；点击画布空白不结束模式。
5. 关闭 Dock、目标删除、刷新或实际切换画布会结束模式；保存失败保留本地结果并提示重试，不把本地已显示误称为已持久保存。

## 范围与既有规则

- 统一图片、视频、音频生成面板的选取体验，不修改各自素材类型、槽位、数量与素材有效性限制；失效素材沿用既有有效性处理。
- 模式持续期间允许 Dock 移除参考；提示词编辑、模型切换、生成、节点拖动、框选与切换编辑目标须先结束选取。
- 模式本身不跨刷新或画布恢复。刷新后的参考恢复以成功保存的数据为准；保存失败时的本地修改不能承诺刷新后恢复。
- 画布切换继续遵守现有保存门禁；现有地址栏与浏览器历史导航的保存覆盖问题不在本次范围，不扩展为导航重构。
- 本次不引入暂选提交、取消整轮选择、Undo/Redo 或 Agent 对话引用改造。

## 验收场景

| 场景 | 预期结果 |
| --- | --- |
| 连续添加 | 针对同一目标依次点击三张有效参考图，模式不中断、Dock 不消失、目标不变化；缩略图、节点勾选及参考关系一致。 |
| 重复与拒绝 | 重复点击不新增或移除；不兼容素材或达到上限时提示且保持模式；从 Dock 移除后可以继续添加。 |
| 单槽位与操作隔离 | 依次选择两个首帧来源后，只有最后一个占用首帧，尾帧等其他槽位不变；平移缩放可用，节点拖动、框选、切换目标及生成编辑被隔离。 |
| 正常与异常退出 | 完成按钮、Esc 均保留原目标 Dock 和参考；空白点击不退出；关闭 Dock 后重开为普通编辑；目标删除后不存在遗留选取；刷新与切换画布不恢复模式。 |
| 保存与恢复 | 保存失败时本地参考和模式保留，显示未保存并可重试；成功后恢复已保存状态，重新加载可恢复参考但不恢复模式；版本冲突不自动覆盖。 |
