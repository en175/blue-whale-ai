# Canvas 生成草稿与引用交互规格

## 时间

2026-09-07

## 背景与状态

用户反馈：侧栏图片、视频、音频入口只打开 Dock，画布中没有生成目标，无法先建立参考连线再编辑生成参数。
本规格记录 grill-with-docs 讨论中已确认的产品决定；Q1–Q19 均已确认，其中 Q7 按用户修正禁止 Dock 上传素材，Q10 经代码核查后收敛为仅选择当前画布素材。状态：核心交互方案已确认，待制定实现计划；不表示产品代码已实现或通过交互验收。

## 已确认决定

| 编号 | 决定 | 用户可见行为 |
| --- | --- | --- |
| Q1 | 先建立生成草稿节点，首次结果填回原卡片 | 点击侧栏媒体入口后先在 Canvas 放入对应类型节点，再通过 Dock 编辑；首次生成成功沿用节点、位置和连线，不额外创建结果卡 |
| Q2 | 草稿持久保留 | 关闭 Dock 或刷新后保留未生成卡片、已填写参数与参考关系；关闭 Dock 仅结束当前编辑，删除卡片才移除草稿 |
| Q3 | 侧栏每次新增 | 每次点击图片、视频、音频入口新增并选中一张对应卡片；点击已有草稿继续编辑该卡片，成功卡的再次编辑按 Q15 创建新草稿 |
| Q4 | Dock 引用与连线双向同步 | 在 Dock 添加画布素材时建立对应连线，移除引用时断开对应连线；画布建立、断开参考连线同步更新 Dock 参考列表 |
| Q5 | 成功后的再次生成另建卡片 | 原成功结果保留，再次编辑时按 Q15 复制参数与输入连线建立新草稿；新结果填入新卡，便于比较 |
| Q6 | 失败或取消后保留草稿 | 首次生成失败或取消后保留卡片、参数与连线；失败显示原因并允许重试，取消后回到待生成状态 |
| Q7 | 移除 Dock 素材上传 | Dock 不允许上传素材；引用范围按 Q10 收敛为当前画布已有素材 |
| Q8 | 显式指定视频参考角色 | 在 Dock 明确指定普通参考、首帧、尾帧，不根据连线先后自动猜测；输入不符合当前模型能力时明确提示，禁止静默丢弃 |
| Q9 | 音频本轮保持文字输入 | 本轮完成音频卡创建、保存与生成流程，继续使用文字描述，不扩展音频参考输入能力 |
| Q10 | Dock 仅选择当前画布素材 | 新素材先通过画布上传入口放入 Canvas，再在 Dock 引用；不提供画布外素材选择或选择后自动放入画布的入口 |
| Q11 | 生成期间目标只读 | 执行期间目标参数与输入连线只读，允许查看和取消；提交时冻结输入，来源文本后续修改不影响正在执行的任务 |
| Q12 | 删除生成中卡片先取消任务 | 删除时请求取消，取消确认后才移除卡片；取消失败保留卡片并提示原因，避免后台任务失去可见入口 |
| Q13 | 媒体参考必须已有有效结果 | 本轮仅接受已有有效媒体结果的节点作为媒体参考，待生成、生成中或失败的卡片不可作为媒体输入；文本节点仍按文本附件规则使用 |
| Q14 | 新卡放置并聚焦 | 侧栏新卡放在当前可见画布中心附近空位并避开 Dock，再次生成的新卡放在原卡旁边；自动选中并打开对应 Dock |
| Q15 | 再次编辑立即创建新草稿 | 点击成功卡的“再次编辑”时即复制出新草稿并打开 Dock，修改与生成均在新卡进行；提交时不再额外创建一张卡，原结果保持不变 |
| Q16 | 移除引用不删除素材 | 移除引用仅断开连线，保留来源素材卡；删除素材是独立操作，不能因移除引用影响其他生成卡 |
| Q17 | 重试沿用失败输入快照 | 未修改输入时，“重试”沿用失败任务的输入快照；修改参数或引用后属于一次新生成，仍由该失败卡承接结果 |
| Q18 | 删除与成功竞态保留结果 | 删除过程中任务已成功时停止自动删除，保留结果并提示“任务已完成”；用户仍需删除时再次操作 |
| Q19 | 保存失败暂停生成与项目切换 | 保留当前编辑并提示重试，暂停生成和项目切换；保存成功后才继续，避免提交旧参数或丢失草稿 |

生成草稿节点尚未提交时不是 GenerationJob，也不是已生成 Asset。只有用户在 Dock 点击“生成”才提交任务。
Q4 不自动扩展生成模型的输入能力；音频引用能力不属于本轮范围。Dock 移除上传功能不表示移除 Canvas 其他入口的上传能力。

## 当前实现约束

以下为首轮代码调研时的快照，不能当作已确认的新产品规则，也不代表其他任务更新主分支后的最新实现：

- 侧栏三种媒体入口目前仅切换 Dock；文本入口会立即创建节点。
- 当前提交生成时才创建新的媒体节点；成功后在该节点填入结果。
- 媒体节点没有生成状态且无有效素材身份时，刷新会标记素材缺失；待生成草稿需要独立于素材缺失的语义。
- 当前媒体参考由 Dock 的 files/refs 提交，图片或视频媒体连线尚未转换为参考输入；已有文本连线输入仅适用于图片目标。
- 当前图片 Dock 在打开时展示附件快照，但服务端提交时读取最新画布；新的双向同步要求消除展示与实际输入的差异。

## Q10 代码核查与结论

用户指出“上传的素材理论上应显示在画布”，要求确认真实实现。核查结果按入口区分：

- **Canvas 侧栏上传**：`CanvasPage/index.tsx` 的 `handleUploadFile` 调用 `placeFileOnCanvas`；先创建带本地预览的媒体节点，上传成功后在原节点补齐素材 ID 与地址。正常成功路径符合用户理解。
- **旧 Dock 上传参考素材**：图片和视频 Dock 选文件时只保存本地文件与预览；发送时经 `uploadFileToAsset` 完成 presign、PUT 和上传登记。该路径不为来源素材创建画布节点，之后只新建生成结果占位卡，因此确实存在“素材已上传但来源节点不在画布”的情况。
- 上述第二条是待移除的旧 Dock 上传路径，不能据此新增一个“选择画布外已上传素材”的产品入口。核查后，用户确认 Dock 仅选择当前画布已有素材；原自动放入画布建议不采用。

## 实现计划前的核查事项

以下为需要从最新代码、模型能力和契约中核实的实施事项，不是额外确认的新产品能力。发现与 Q1–Q19 冲突时应列出具体冲突再讨论，不得静默改变已确认行为。

1. 图片与视频模型支持的输入类型、数量、首尾帧组合，以及已有输入去重和校验逻辑；按 Q8 显式呈现不兼容，不能静默丢弃。
2. 当前 Canvas 保存、任务接纳、取消与重试接口如何支持草稿身份、冻结输入和取消完成竞态；不能把请求已发出视为取消成功。
3. 与其他并行任务最新实现的衔接，尤其文本附件、媒体节点工具条和生成恢复路径；首轮调研快照不得代替实施前的代码核查。

## 验收场景

### 创建与草稿恢复

| 场景 | 预期结果 |
| --- | --- |
| 分别点击侧栏图片、视频、音频入口 | 先出现对应草稿卡，自动选中并打开 Dock；尚未提交生成任务 |
| 连续点击同类入口 | 每次建立独立草稿；切回已有草稿可继续编辑 |
| 新建卡片 | 位于当前可见中心附近空位并避开 Dock |
| 已保存草稿关闭 Dock、刷新或重开项目 | 卡片、参数与参考关系恢复，不显示“素材已被删除” |
| 保存失败后尝试生成或切换项目 | 保留编辑并提示重试，操作暂停；保存成功后可继续 |

### 引用与输入

| 场景 | 预期结果 |
| --- | --- |
| Dock 添加当前画布素材或画布建立参考连线 | 两处显示同一组参考输入 |
| Dock 移除引用或画布断开连线 | 两处同步移除关系，来源素材卡仍在 |
| 需要使用新文件 | Dock 无上传入口，也无画布外素材选择入口；先通过画布上传入口放入再引用 |
| 媒体参考没有有效结果 | 待生成、生成中或失败卡不可作为媒体输入；文本附件按其独立规则处理 |
| 视频参考角色与模型能力 | 首帧、尾帧、普通参考由用户显式指定；不兼容输入明确提示，不按连入顺序猜测角色或静默丢弃 |
| 音频生成 | 保持文字描述输入，本轮不扩展参考输入能力 |

### 生成与再次编辑

| 场景 | 预期结果 |
| --- | --- |
| 首次生成成功 | 结果填回原草稿卡，节点身份、位置和连线保持 |
| 执行期间编辑目标参数或输入连线 | 目标只读，仍可查看与取消；来源正文修改不改变已提交快照 |
| 成功卡点击“再次编辑” | 原卡旁立即出现复制参数和输入连线的新草稿；旧结果保留，新结果填入新卡 |
| 首次任务失败或用户取消 | 保留卡片、参数与连线；失败显示原因，取消后回到待生成状态 |
| 失败后不修改输入直接重试 | 使用原任务冻结快照；不会回读已变化的来源正文替换历史输入 |
| 失败后修改参数或引用再生成 | 形成新任务，使用新输入，结果仍落在该失败卡 |

### 删除与竞态

| 场景 | 预期结果 |
| --- | --- |
| 删除生成中卡片，取消成功 | 取消确认后移除卡片 |
| 删除生成中卡片，取消失败 | 保留卡片并提示原因 |
| 删除过程中任务先成功 | 保留成功结果并提示“任务已完成”，不自动删除 |

以上是待实现的验收要求，不是已运行的测试结果。
