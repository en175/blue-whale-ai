# 图片高清放大（火山 AI MediaKit）规格

> 需求共识来自 2026-09-17 两轮 grilling（12 项拍板，Kim 已确认）。需求工单 IKGLZV（ready-for-agent）。术语以根 CONTEXT.md「画布高清放大」节为准，关键取舍见 ADR-0092。

## Problem Statement

用户在画布上生成或上传的图片分辨率有限（当前生图最高 2K 档），需要印刷、放大展示或进一步精修时，没有办法拿到更高清的版本。用户希望能对任意一张图片卡一键发起画质增强，得到一张分辨率成倍提升的新图片，且过程不离开画布。

## Solution

图片素材卡的悬浮工具条新增「高清放大」入口。点击后画布自动在源卡右侧创建一张「高清」草稿卡、连一条来源线，并在新卡下方弹出高清放大面板。用户在面板上选择版本档（Lite / Pro / Max）、放大倍数（2/4/6）与高级参数（增强策略、色彩校正）后发送，系统调用火山引擎 AI MediaKit 图像画质增强接口，把结果图填回高清卡。源卡不动，高清卡是一张普通图片素材卡，可以继续链式放大。本期高清放大免费：不显示积分预估，也不扣用户余额。

## User Stories

入口与可见性：

1. 作为创作者，我希望选中一张图片卡后在工具条看到「高清放大」按钮，以便把低清图变成高清图。
2. 作为创作者，我希望按钮排在「生成视频」之后，位置稳定可预期。
3. 作为创作者，我希望只有图片卡显示该按钮，视频卡、音频卡、文本卡不显示，以免误点。
4. 作为创作者，当卡片正在生成、已失败或素材缺失时，我希望看不到该按钮。
5. 作为创作者，多选卡片时我不看到该按钮（与工具条整体口径一致）。

建卡与连线：

6. 作为创作者，点击「高清放大」后，我希望系统自动在源卡右侧空位建好新卡，无需手动摆位。
7. 作为创作者，我希望新卡标题为「高清」、占位文案为「配置参数生成高清图像」，一眼明白它的用途。
8. 作为创作者，我希望源卡与新卡之间自动出现一条连线，看得出新卡从哪来。
9. 作为创作者，我希望这条连线只是来源表达，不占用参考位、不参与 @ 编号。
10. 作为创作者，我希望新卡自动选中并弹出参数面板，立刻就能配置。
11. 作为创作者，我希望可以双击标题把「高清」改成我想要的名字。

面板与参数：

12. 作为创作者，我希望面板跟随在高清卡下方，拖动卡片时面板跟着走。
13. 作为创作者，我希望「模型选择」下拉当前显示 MediaKit（仅此一项）。
14. 作为创作者，我希望「模型」下拉提供 Lite / Pro / Max 三档，默认选中 Pro。
15. 作为创作者，我希望放大倍数是 2 / 4 / 6 三个分段按钮，默认选中 2。
16. 作为创作者，我希望高级参数里能选增强策略（生成度优先 / 保真度优先），默认生成度优先。
17. 作为创作者，我希望高级参数里能开关色彩校正，默认开。
18. 作为创作者，当我选 Lite 时，增强策略置灰并告诉我该版本不支持。
19. 作为创作者，当我没选 Max 时，色彩校正置灰并告诉我该版本不支持。
20. 作为创作者，当源图尺寸不满足某档门槛时，我希望该档直接置灰并说明原因（Lite 长边超 2160px、Pro 短边不足 256px、Max 宽高比超 32）。
21. 作为创作者，当默认档不可用时，我希望面板自动落到第一个可用档；三档都不可用时发送按钮禁用并说明原因。
22. 作为创作者，发送后我希望面板自动关闭，回到画布看进度。
23. 作为创作者，生成中我希望面板参数只读冻结。
24. 作为创作者，我希望能用点画布空白、点画布外区域、按 Esc 关闭面板，与其他面板一致。

生成与结果：

25. 作为创作者，发送后我希望高清卡显示生成中状态，离开或刷新页面任务不丢。
26. 作为创作者，成功后我希望增强图填回高清卡，并看到新的分辨率。
27. 作为创作者，我希望源卡内容全程不变。
28. 作为创作者，我希望增强结果自动进入我的资产库，可以在别处继续使用。
29. 作为创作者，失败时我希望在卡上看到失败状态和重试入口，重试沿用上次参数。
30. 作为创作者，因源图超门槛被供应商拒绝时，我希望看到能读懂的失败原因。
31. 作为创作者，本期我不想看到积分预估数字，也不希望余额因此减少。

高清卡的后续操作：

32. 作为创作者，我希望点高清卡的「重新编辑」打开的还是高清放大面板，并带回上次参数。
33. 作为创作者，重新生成的结果替换本卡素材，不新建卡。
34. 作为创作者，我希望能在高清卡上再点「高清放大」，继续链式放大。
35. 作为创作者，我希望高清卡的生成图片、生成视频、下载、@、信息按钮与普通图片卡一致。
36. 作为创作者，我希望高清卡可以删除、复制、粘贴、参与撤销，与普通卡一致。

## Implementation Decisions

前端：

- 工具条入口按既有可见性机制扩展一个图片专属动作（与「生成图片」同族），仅在正常态图片卡单选时出现。
- 点击后的「建草稿卡 + 连线 + 开跟随面板」整链照搬「生成图片」既有骨架；高清卡就是图像素材草稿卡，节点数据上增加一个高清身份标记，标题初始值「高清」，占位文案「配置参数生成高清图像」。
- 连线为纯视觉来源线，不携带参考角色，不进媒体索引与 @ 编号体系。
- 高清放大面板是新的轻量面板组件：无提示词输入框、无参考栏；锚定、拖拽跟随、点外关闭、Esc 关闭、发送后自动关闭、生成中只读冻结全部沿用既有面板约定。
- 「模型选择 / 模型」两级下拉是新组件（全站此前只有平铺单级下拉）；供应商级当前仅 MediaKit 一项。版本档与高级参数选项为前端静态配置，不进模型能力目录（CONTEXT 词条已明确）。
- 放大倍数 2/4/6 复用宽高比分段按钮的视觉模式。
- 高级参数两个控件（增强策略二选一、色彩校正开关）常驻，版本不支持时置灰并悬停说明原因，沿用附件操作条的置灰口径。
- 源图尺寸预检在前端打开面板时执行： Lite 要求长边 ≤2160px 且短边 ≥16px，Pro 要求短边 ≥256px 且长边 ≤2048px，Max 要求短边 ≥64px、长边 ≤6240px 且宽高比 ≤32；不满足的档置灰，默认档不可用时自动落到第一个可用档，三档全不可用则禁用发送并说明。
- 高清卡的「重新编辑」按节点上的高清身份标记分流到高清放大面板，并回填上次参数；其余工具条行为与普通图片卡完全一致。
- 前端任务类型联合扩展新类型；提交时冻结源素材身份、版本档、倍数与高级参数。
- 本期不渲染积分预估；高清放大提交不经过余额拦截门（免费工具口径同 media_extract）。

后端（NestJS）：

- 新增生成任务类型 `image_enhance`（任务类型字段是自由字符串，无需数据库迁移）。
- 创建路径仿 media_extract 的独立轻量入口：直接落任务，不写成本预留、不接成本估算、不走素材库合规门；冻结输入包含源素材身份、版本档、倍数、高级参数与目标节点身份。
- 服务端复核全部参数合法性（版本档枚举、倍数 ∈ 2/4/6、高级参数与版本的生效关系、源素材归属与媒体类型、源图尺寸门槛），前端预检只是体验层，不作权威。
- 供应商调用经 blue-whale-api 网关的既有 MediaKit 渠道（同步路由，对客模型名 `mediakit-enhance-image`），不在本仓直连火山、不新增凭证配置项；渠道与上游 API Key 在网关侧配置（见 Further Notes）。

执行（worker-java）：

- 新增一个 MQ tag 与对应的消费者/处理器（以既有 mediaExtract/audio 接线为模板），含领取 SQL 与 CAS、租约、恢复扫描、终态收口 payload 组装；任务来源白名单登记新来源。
- 新增 MediaKit 客户端：调用网关同步路由 `POST {网关地址}/v1/mediakit/sync/enhance-image`，鉴权与图片生成同构（携带任务冻结的用户 sk-），请求体为 MediaKit 原生参数，网关原样透传。入参映射为 image_url（源素材的公网对象存储地址，现有素材即公网可读，无需签名改造）、tool_version（Lite→standard、Pro→professional、Max→max）、multiple、generative_enhance_mode、enable_correct_color。
- 网关原样透传上游响应：响应成功即下载结果图（URL 仅 24 小时有效，须立即落对象存储并设公开读），随后建 Asset、终态收口、向前端投影进度，全链路与图片任务同构。
- 调用失败、超时、供应商错误（网关对 success=false 返 400 且不扣费）统一映射到任务失败与既有错误码投影，不提供自动重试，由用户在原卡手动重试。
- 参数快照随任务输入冻结，重试沿用首次提交参数。

契约与数据：

- 无数据库 schema 变更；任务输入冻结在既有任务记录的 input 字段。
- 跨进程字段（任务类型、来源值、参数键名、版本档映射）先在契约文档定死后双端实现，遵守「同族工单串行、契约先行」。

## Testing Decisions

好测试的标准：只测外部可见行为（渲染结果、提交参数、状态流转、错误呈现），不测内部实现细节；一份视觉/口径定义只在一处断言，防漂移断言用于「两处必须同源」的约定。

- 前端组件与画布链路（vitest + jsdom）：工具条按钮可见性矩阵（卡类型 × 卡状态）、点击后的建卡/连线/开面板链、面板的选项渲染与默认值、置灰与悬停原因、尺寸预检各档边界、提交 payload 冻结内容、发送后关闭与重新编辑分流。既有先例：图片面板组件测试、mediaExtract 建占位卡链路测试、宽高比共享组件的防漂移断言。
- 后端创建入口：参数校验矩阵（枚举、倍数、版本与高级参数生效关系、尺寸门槛复核）、免费口径（无成本预留记录）、任务输入冻结、源素材归属拒绝。既有先例：media_extract 服务测试。
- worker-java：MediaKit 请求映射与错误分类（mock 网关端点）、结果下载落库与 Asset 创建、终态收口事件；以接口级 mock 隔离真实网关调用。既有先例：图片/音频处理器单测。
- 契约层：任务类型与参数键名的双端一致性断言。

## Out of Scope

- 积分预估展示与实际扣费（后续单独工单一并补上）。
- Topazlabs 或任何第二家供应商接入（供应商级下拉仅预留形态）。
- 任意倍率输入、按目标像素（target_width / target_height）指定输出尺寸。
- 视频画质增强、批量放大、队列分账（queue_id）。
- 版本档的后台管理配置界面（版本档不进模型能力目录，无管理端改动）。
- 高清卡的专属连线样式（沿用既有连线视觉）。

## Further Notes

- 上线前置条件在网关（blue-whale-api）侧：先在火山控制台 AI MediaKit 页面创建 API Key，再在网关执行 mediakit-bootstrap.sql 建 MediaKit 渠道（渠道 key 字段填真 Key，模型清单与 abilities 由脚本配齐），本期 `mediakit-enhance-image` 的 model_price 配 0 即免费。注意网关同步工具未配价会被硬拦 400，免费形态是配零价而不是不配价；网关缺渠道或缺定价时，本侧任务以失败呈现。
- 计费粒度已知限制：网关按模型名按次计费，不区分 tool_version，而三档官方成本差 40 倍（standard 6 元/千次、professional 36、max 240）。本期免费无影响；后续计费工单需先解决分档计价（拆模型名或网关侧增强），再恢复预估展示与扣费。
- MediaKit 结果图 URL 有效期 24 小时，执行侧必须在响应后立即下载落库，这一约束已在 ADR-0092 记录。
- 本期免费期间火山账单由平台自担，放量前须补计费工单。
- 供应商默认参数：增强策略默认生成度优先、色彩校正默认开，与火山官方默认一致。
