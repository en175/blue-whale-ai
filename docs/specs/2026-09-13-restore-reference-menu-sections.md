# 恢复素材分类菜单并叠加已引用分区

## 时间

2026-09-13

## 背景与目标

用户人工查验发现，新增正文素材标签时，原有搜索和四类素材菜单被挪到「引用画布素材」的二级入口。用户确认要求增量叠加：恢复历史菜单，在其上方增加已引用分区。适用图片与视频生成面板。

## 已确认交互

- 无搜索词：搜索框、已引用分区、素材引用分类依次展示。分类保留图片、视频、音频、文本及原有悬浮展开列表。
- 无已引用素材时不展示该分区，保持历史菜单结构。
- 同一个搜索词同时检索已引用素材和画布素材；结果按已引用、图片、视频、音频、文本分组，只展示有匹配项的组。
- 两个分区不跨区去重：同一素材可同时显示在已引用与画布类型分组。
- 点击已引用项，或从画布分类选中已经引用的同一身份，直接插入正文素材标签，不重复添加附件或连线。
- 从画布分类选择新素材沿用既有选取、校验、加入参考流程；成功加入后沿用现有正文标签插入机制。
- 原有类型与生成模式限制保持。搜索不扩大模型支持的类型；不以名称、缩略图或相似度判断身份。
- 素材库和画布点选仍通过附件栏的既有添加入口提供；不再用这些入口替代 @ 菜单的四类素材分类。

## 检索口径（IKIQGR：文本附件与文本节点全文检索）

- 搜索词按名称、已引用编号（图片N/视频N/音频N/文本N 等 badge）与文本正文全文匹配，忽略大小写；正文不再截断为前 200 字摘要，超过前 200 字的关键词同样命中。
- 已引用分区与画布素材分区都覆盖正文匹配：已引用的文本附件按附件正文全文命中；画布上未引用的文本节点（含无标题、显示为「文本节点」的）按节点正文全文命中。
- 仅文本类候选携带正文检索字段；图片/视频/音频等媒体项不携带正文，不按正文误命中。
- 菜单不展示正文片段：搜索结果行仍只显示名称与编号，正文仅参与匹配。
- 无搜索词的分组展示、悬浮分类浏览与既有交互保持不变；本口径适用于图片、视频、音频三个生成面板的 @ 菜单（音频面板文本项与画布文本节点共用同一匹配通道）。

## 实现与验证

复用 AtMentionMenu 搜索和分类组件，新增可选已引用项；图片和视频面板直接接入统一菜单。正文存储、生成接口和素材身份契约保持不变。

回归覆盖：同屏分类、跨区重复搜索、禁用项、原位插入、新参考添加、已有参考不重复添加、图片/视频/文本标签与失效行为。视觉位置与真实画布操作由人工检查。

历史定位：c92ed541 引入原菜单；8d5723cb 将图片入口挪到二层；1fc73a99 对视频做了同类迁移。本次为可逆 UI 修复，不新增架构 ADR。

## 焦点与取消规则（录屏反馈后确认）

- 首次输入新的 `@` 打开菜单，并自动聚焦搜索框。
- 点击回正文立即关闭菜单，光标回到点击位置；Esc 和菜单外点击采用同一取消规则。
- 取消保留正文原有 `@`，用户可正常编辑、删除；移动光标、重新聚焦或继续编辑原查询都不会重开菜单。
- 删除原 `@` 后重新输入，才重新触发该位置的菜单；新输入的 `@` 开启新的引用查询。
- 图片与视频生成面板共用上述规则，不改素材分类、搜索分组或引用绑定。

## 键盘选择规则（人工反馈后确认）

- 键盘焦点与鼠标悬停使用相同背景高亮，不增加浅蓝描边。
- 上下键在当前层级的可用项中循环，跳过禁用项。
- 分类上的 Enter 或右方向键进入子列表；子列表左方向键返回所属分类。
- 素材上的 Enter 与鼠标点击执行同一选择动作；成功插入后关闭菜单，光标位于正文标签后。
- 画布快捷键让出引用菜单内的键盘事件；保留此前的首次搜索聚焦与取消规则。
