# Canvas 空格平移交互约定

## 时间

2026-09-05

## 背景与目标

选择模式下，空格键原本只启用 React Flow 的视口平移，没有关闭节点拖拽。
用户从卡片主体开始拖动时仍会移动卡片。修复后，鼠标按下时的操作意图决定
整个手势，避免误改卡片位置。

以下边界由用户在本次 `grill-with-docs` 对齐中确认（Q1–Q3 均采用建议）。

## 行为约定

| 场景 | 预期行为 |
| --- | --- |
| 选择模式，未按空格，从卡片主体按下左键并拖动 | 移动卡片 |
| 先按空格，再从卡片主体、图片、正文或内部按钮按下左键并拖动 | 平移 Canvas 视口；节点坐标和选中集合不变 |
| 空格平移期间点击卡片内部按钮 | 不触发按钮，不触发节点点击或空白点击行为 |
| input、textarea 或可编辑正文有焦点时按空格 | 保持文字输入，不接管为平移 |
| 已按下鼠标开始拖卡片，再按空格 | 本次继续拖卡片；松开鼠标后，下次手势重新判断 |
| 已按下鼠标开始平移，先松开空格 | 本次继续平移；松开鼠标后恢复当前工具模式 |
| 工具栏已选拖拽模式，再按下并松开空格 | 仍保留工具栏拖拽模式 |
| 窗口失去焦点 | 清理临时空格状态，防止松键事件丢失后卡在平移模式 |

“卡片移动”改变节点的布局坐标；“视口平移”改变用户看到的 Canvas 位置，
不改变节点的布局坐标。沿用现有 Canvas 与节点术语，不新增领域实体。

## 实现与验证

空格与工具栏拖拽在 Canvas 容器统一决定是否平移；卡片无需各自监听空格。
鼠标按下时固定操作，鼠标松开后的点击处理结束后解除固定。保留现有
空格加滚轮平移能力。

自动回归使用真实 React Flow 与卡片组件，覆盖按键状态、视口和节点坐标、
编辑焦点、按钮点击、选中状态与手势期间的模式固定。jsdom 不执行 CSS 命中测试，
因此从卡片及其内部控件开始拖动的鼠标命中行为仍需在浏览器人工回归。

定向测试：

```sh
cd web
npm test -- src/pages/CanvasPage/components/Canvas/spacePan.test.tsx
```

人工验收：在 `/canvas` 放置图片、生成卡、文本节点，逐项执行上表场景；
尤其检查按钮上起拖、框选多个节点后从选中区域起拖、先松空格后松鼠标、
文字编辑中输入空格。

此修复是可逆的交互行为校正，不引入新的架构取舍，因此不新增 ADR。
