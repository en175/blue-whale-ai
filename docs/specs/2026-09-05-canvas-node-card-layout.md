# Canvas 节点卡片布局设计

## 时间

2026-09-05

## 状态与背景

设计对齐阶段；用户已确认 Q1–Q9，末节列出尚待确认的状态占位规则。尚未修改产品代码。

参考用户提供的现有画布与新设计两张截图，调整单张节点的视觉布局：外置标题、独立内容区、按媒体比例展示、弱化边框和连接点。截图中的 JSON 仅作为正文内容示例，不代表新增代码编辑器或生成工作流。

本规格描述 Canvas 内节点的视觉呈现，不改变 CONTEXT.md 中 NodeItem、Asset、对话 Card 等领域概念。本轮是可逆的界面设计调整，不新增 ADR，不把像素与样式规则写入领域词汇表。

## 已确认范围（Q1、Q2、Q4）

- 图片、视频、音频、文本统一调整；商品卡及其他资产卡不在本轮范围。
- 保留自由投放、拖动与已有节点位置；不执行自动排列、避让或对齐。
- 保留现有名称来源；自定义命名和自动编号另行规划。
- 保留现有富文本编辑、媒体播放、右键菜单及生成状态操作能力。

## 内容尺寸（Q3、Q5、Q6）

以下尺寸均为画布缩放 100% 时的内容区尺寸，不包含外置标题与操作工具栏。

| 节点 | 已确认规则 |
| --- | --- |
| 图片、视频 | 默认短边 280px；长边按原始比例计算，最大 840px；超过上限时整体等比例缩小，完整展示，不裁切 |
| 文本 | 固定 360×270px，即 4:3；正文超出可用区域时内部上下滚动，不撑高卡片 |
| 音频 | 固定 280×280px，即 1:1；保留播放器 |

已知原始宽高 W、H 时：缩放系数 s = min(280 / min(W, H), 840 / max(W, H))，展示宽高为 W×s、H×s。

| 媒体比例 | 展示尺寸（约） |
| --- | --- |
| 3:4 | 280×373px |
| 4:3 | 373×280px |
| 16:9 | 498×280px |
| 1:10 | 84×840px |

短边 280px 是默认显示基准；极端比例触及长边上限时，短边会同步缩小。由于卡片尺寸变化且不重排，既有密集布局可能出现重叠，用户仍通过自由拖动整理。

## 标题与元信息（Q4、Q7）

标题行常驻内容区上方，直接位于画布背景上。左侧为类型图标与现有名称，右侧为元信息。媒体内容自身形成圆角主体，移除包裹标题与图片的一体式深色顶栏，减弱容器边框。

| 节点 | 标题左侧 | 标题右侧 |
| --- | --- | --- |
| 图片 | 现有文件名或生成名称 | 原始分辨率 |
| 视频 | 现有文件名或生成名称 | 原始分辨率与时长 |
| 音频 | 现有名称 | 时长 |
| 文本 | 沿用“文本节点” | 留空 |

缺失的元信息留空，不伪造尺寸。分辨率表示原文件像素，与卡片展示尺寸、画布缩放无关。文件大小在详情中呈现，不占用标题行。

## 操作区与连接点（Q8、Q9）

- 选中后的操作工具栏位于外部标题行上方，不覆盖标题或内容。
- 文本编辑时格式工具栏使用同一层位置，避免多个工具栏叠放；保留富文本能力。
- 连接点平时隐藏，悬停、选中或正在连接时显示；位置为内容区左右两侧中点。
- 本轮仅调整连接点呈现，沿用当前连线行为，不扩展连线持久化或生成工作流。

## 待确认：未知尺寸与状态占位（Q10）

以下为建议，尚未视为用户已确认的规则：

- 图片/视频生成中或加载中，若已有可信的目标比例或原始尺寸，按该比例套用短边与长边规则。
- 比例与尺寸均未知时，暂用 280×280px 占位；取得实际尺寸后按真实比例更新外观，保留节点位置。
- 失败、取消或素材缺失时，保留已知比例对应的尺寸；仍未知则使用 280×280px。沿用已有提示与操作。
- 展示比例的临时兜底不用于填充标题分辨率，右侧缺失元信息仍留空。

## 后续验收

1. 横版、竖版、方形及极端比例的图片和视频均完整展示，并符合尺寸表与长边上限。
2. 标题常驻、内容边界清晰；选中、悬停、文本编辑时操作条不遮挡标题与正文。
3. 文本 360×270px 内滚动；音频 280×280px 内可正常播放与操作。
4. 连接点仅在规定状态出现，锚定内容中点；拖动与既有连线交互保持可用。
5. 既有节点位置不被重排；上传、生成中、成功、失败及素材缺失分别检查尺寸和元信息，并验证刷新恢复。

本次文档整理不代表上述产品验收已经执行。实现须在最终设计确认后开始。
