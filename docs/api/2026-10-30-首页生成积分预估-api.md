# 首页生成积分预估接口（前端对接文档）

## 背景

首页 AI 视频 / AI 图片两个页签已经预留了「预计消耗 N 积分」徽标位（`web/src/custom/pages/Home/components/ChatBox/QuoteBadge.tsx`），四处 `<QuoteBadge />` 均未接入数据源。首页此刻还没有项目，无法复用画布的 `POST /api/projects/:projectId/generation-jobs/quote`。本单只新增一个与项目无关的预估接口，前端接线另开工单。

## 接口

```
POST /api/generation-quotes
Authorization: Bearer <token>（或携带登录态 Cookie）
Content-Type: application/json
```

必须登录，未登录返回 HTTP 401。响应走全站统一信封：`code === 200` 为成功，能否报价由 `data.credits` 是否为 `null` 表达。

### 请求

```json
{
  "type": "video",
  "parameters": {
    "model_id": "doubao-seedance-1-0-pro",
    "prompt": "海边的日落，镜头缓慢推进",
    "aspect_ratio": "16:9",
    "resolution": "1080p",
    "duration": 8,
    "generate_audio": true,
    "mode": "text2video"
  },
  "expected_output_count": 1,
  "references": [
    { "type": "image" },
    { "type": "video", "duration": 8 }
  ]
}
```

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `type` | 是 | `image` 或 `video` |
| `parameters.model_id` | 是 | 当前选中模型 |
| `parameters.prompt` | 否 | 参与提示词字数计价 |
| `parameters.size` | 否 | 图片档位（图片页签） |
| `parameters.resolution` | 否 | 视频清晰度（视频页签） |
| `parameters.aspect_ratio` | 否 | 画面比例 |
| `parameters.duration` | 否 | 视频时长（秒），`-1` 表示自动 |
| `parameters.generate_audio` | 否 | 仅模型 `features.audio === true` 时传 |
| `parameters.mode` | 否 | 视频生成模式；不传时后端按参考素材与提示词推断，口径与画布一致 |
| `expected_output_count` | 否 | 默认 `1`，首页不用传 |
| `references` | 否 | 参考素材清单，见下 |

`references[]` 只需要类型和视频时长，**不需要 asset_id**：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `type` | 是 | `image` 或 `video` |
| `duration` | 视频时必填 | 参考视频时长（秒），用于按秒计价 |

本地文件尚未上传也能传；后端不校验素材归属，报价只做展示。

### 响应

```json
{ "code": 200, "msg": null, "data": { "credits": 128 } }
```

```json
{ "code": 200, "msg": null, "data": { "credits": null } }
```

| 情况 | 结果 |
| --- | --- |
| 正常 | `code: 200`，`data.credits` 为正整数 |
| 模型不在启用白名单 | `code: 200`，`data.credits: null` |
| 参数组合不合法（如样片模式参数） | `code: 200`，`data.credits: null` |
| 计费服务不可用 / 超时 | `code: 200`，`data.credits: null` |
| 请求体不合法（字段缺失或多余） | `code: 100000`，无 `data.credits` |

`code !== 200` 与 `data.credits === null` 一律按「暂不显示数字」处理：请求失败不弹 toast、不阻断输入。

## 前端接入要点

1. 只在 AI 视频 / AI 图片两个页签请求。视频智能体页不请求，徽标保持只有图标、没有数字。
2. 未登录不请求。
3. 参数或提示词变化才重新请求；提示词影响价格，输入停止后再发（建议 300–500ms 防抖）。
4. 请求走静默模式：失败、超时、401、`code !== 200` 都不弹 toast，按无数字渲染。
5. 查询 key 用完整请求体；建议 `staleTime` 30–60 秒，避免切页签重复打计费服务。
6. 后端不返回 `quote_revision`，首页预估**不参与提交确认**；提交仍由画布按真实参数与素材重新报价。

## 参数来源映射（`Home/components/ChatBox`）

| 页签 | 请求字段 | 现有 state |
| --- | --- | --- |
| video | `parameters.model_id` | `videoModel` |
| video | `parameters.mode` | `videoMode` |
| video | `parameters.aspect_ratio` | `aspectRatio` |
| video | `parameters.resolution` | 当前 `resolution` 对应的 `supported_sizes` 项，取 `api_value ?? id`（与提交口径一致） |
| video | `parameters.duration` | `duration` |
| video | `parameters.generate_audio` | `generateAudio`（仅 `selectedVideoModel.features.audio === true`） |
| video | `parameters.prompt` | `inputValue` |
| video | `references` | `refFiles` + `keyframeRefs`（首帧/尾帧按 `image` 传） |
| image | `parameters.model_id` | `imageModel` |
| image | `parameters.size` | `imageResolution` |
| image | `parameters.aspect_ratio` | `imageAspectRatio` |
| image | `references` | `imageRefFiles`（统一按 `image` 传） |

参考视频的 `duration`：本地文件在 `loadedmetadata` 时从 `<video>` 读取；资产库来源的记录本身带时长。

## 验收清单

- 选中模型即出现数字。
- 改时长、清晰度、比例、生成音频开关，数字跟着变。
- 增加或移除参考图、参考视频，数字跟着变。
- 视频智能体页不出现数字。
- 未登录、断网、计费服务异常时，只显示图标，无报错提示。

## 非目标

- 不改提交链路，不校验提交时的价格一致性。
- 不返回 `quote_revision` / `expected_credits`。
- 首页预估不接防刷限流，节奏由前端防抖保证。
