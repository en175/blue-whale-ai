# ADR 0021: blue_whale_api 统一 RMB 计费（展示层 CNY + 前端¥/$输入辅助）

- 状态：Accepted（2026-07-22；方案修订 2026-07-22）
- 决策者：李述 + Claude（grill-with-docs / to-spec / to-tickets 会话）
- 上游规格：IK30C5（统一 RMB 计费）

## 背景

blue_whale_api（开源 new-api 二开）默认按美元锚点计费：`quota` 是中性积分（500000 quota = $1），`quota_display_type` 默认 USD，模型突变抽屉「价格模式」标 "$/1M tokens"，`ratio_sync` 从 models.dev 拉 USD 官方价。

受众与结算均面向国内，老板要求**统一 RMB**：用户可见界面（余额 / 额度 / 价格 / 报表）全部 ¥；删除货币切换逻辑（不要 USD/CUSTOM，保留 TOKENS 调试模式）。

**方案演进（2026-07-22 修订）**：初版设想「价格模式人民币化 + 计费公式÷汇率 + ratio_sync 拉¥存¥」。代码勘察确认后端 DB / `quota` / `relay/helper/price.go:170`（`modelPrice * QuotaPerUnit * GroupRatio`）/ `ratio_sync` / `model_ratio` **全链美元锚点**，改后端语义 / 计费 / 同步风险大、收益低。故改为**后端完全不动**，仅做两件事：①展示层锁 CNY（用户可见 ¥）；②前端 ¥/$ 输入辅助（管理员对国产模型按 ¥ 填，提交时前端 ÷汇率 转 $）。汇率基本固定（默认 7），无漂移顾虑。

## 决策

**核心约束：不触碰 `QuotaPerUnit = 500000`、DB schema 与后端计费 / 同步代码**，避免数据迁移与语义重定义风险。统一 RMB 走「展示层 CNY + 前端 ¥/$ 输入辅助」，后端全美元锚点不动：

1. **展示层锁 CNY**：默认 `quota_display_type = CNY`；**用户可见界面**（余额 / 额度 / 价格 / 报表）货币符号显示 ¥（经 `lib/currency.ts` getDisplayMeta 动态返回，非逐处改写）；移除 USD/CUSTOM 货币切换 UI，保留 TOKENS 调试模式（仅管理员看原始 token 计数）。`QuotaPerUnit = 500000` 不变。**管理员模型定价 UI（内部）符号保持 $**（美元锚点）。
2. **价格模式保美元锚点 + 前端¥/$输入辅助**：模型定价编辑 UI 加 **¥/$ 输入开关**（或互斥两行，只能填一个）。选 ¥ 填则前端提交时 ÷`USDExchangeRate` 转 $ 存入；选 $ 直接存。**`ModelPrice` 存储语义保持美元锚点不变**，不新增表 / 列、不做语义重定义。国产模型（火山 / 国产，上游同步不了 USD 官方价的）管理员按 ¥ 思维填，前端换算。
3. **后端计费公式不动**：`relay/helper/price.go:170` 保持 `modelPrice * QuotaPerUnit * GroupRatio`（美元锚点），**不加 ÷汇率**。管理员填的 ¥ 经前端换算成 $ 后，后端按 $ 正常计费。实时换算发生在前端提交，无需「重算」按钮。
4. **汇率统一默认 7、可动态配**：`USDExchangeRate` 默认 7，统一用于**展示换算**（getDisplayMeta，展示层锁 CNY）与**前端 ¥→$ 输入换算**。**不用于后端计费÷**（计费美元锚点）。动态配置后重启生效。汇率基本固定，无漂移顾虑。
5. **ratio_sync 不动**：保持从 models.dev 拉 USD 官方价 → ratio（美元锚点），不改造成拉¥存¥。美元模型（claude 等）上游有官方 USD 价，自动同步正常。手填优先逻辑（同步不覆盖已手填）保持现状。

## 后果

**优点**：零 DB 迁移；quota 中性积分不变（向下兼容历史数据）；**后端零改动**（price.go / ratio_sync / model_ratio 全不动）；**无语义重定义风险**（存储保持美元锚点）；用户可见全链 ¥；管理员国产模型可按 ¥ 思维填；汇率可动态调。

**风险 / 权衡**：
- **前端换算正确性**：管理员填 ¥ 靠前端 ÷汇率 转 $，若换算逻辑 / 汇率配错则实际 $ 错。缓解：汇率固定 7、换算在提交前可预览（前端展示换算结果）；逻辑集中在一处易测。
- **汇率配置**：`USDExchangeRate` 同时服务展示换算与前端输入换算；改后重启生效，影响所有 ¥→$ 换算。比率模式（存乘数）不受影响。
- **ratio_sync 覆盖**：手填优先逻辑须正确实现（现状保持），否则同步覆盖人工调价。
- **美元模型（claude）**：上游有官方 USD 价，ratio_sync 自动拉，管理员无需手动换算。
