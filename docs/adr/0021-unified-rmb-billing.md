# ADR 0021: blue_whale_api 统一 RMB 计费（展示层 CNY + 价格模式人民币化）

- 状态：Accepted（2026-07-22）
- 决策者：李述 + Claude（grill-with-docs / to-spec / to-tickets 会话）
- 上游规格：IK30C5（统一 RMB 计费）

## 背景

blue_whale_api（开源 new-api 二开）默认按美元锚点计费：`quota` 是中性积分（500000 quota = $1），`quota_display_type` 默认 USD，模型突变抽屉「价格模式」标 "$/1M tokens"，`ratio_sync` 从 models.dev 拉 USD 官方价。

受众与结算均面向国内，老板要求**统一 RMB**：用户 / 管理员 / 前端 / 后端 / 计算 / 报表全部 ¥；管理员按 ¥/1M（非 $/1M）填价；后续接美元模型（如 claude）也用 ¥ 思维；删除货币切换逻辑（不要 USD/CUSTOM，保留 TOKENS 调试模式）。

## 决策

**核心约束：不触碰 `QuotaPerUnit = 500000` 与 DB schema**，避免数据迁移风险。统一 RMB 走「展示层 + 语义重定义 + 计费公式」，不动内部中性积分与存储：

1. **展示层锁 CNY**：默认 `quota_display_type = CNY`；前端所有货币符号 `$`→`¥`；移除 USD/CUSTOM 货币切换 UI，保留 TOKENS 调试模式（仅管理员看原始 token 计数）。`QuotaPerUnit = 500000` 不变。
2. **价格模式人民币化**：模型突变抽屉「价格模式」标签 `$`→`¥`，管理员直接填 ¥ 价。**复用现有价格模式存储（`ModelPrice`），语义从 USD 重定义为 RMB，不新增表 / 列**。
3. **计费公式 ÷汇率**：relay 计费公式价格模式分支加 ÷`USDExchangeRate`，使 ¥ 价正确换算为 quota 扣费（实扣 = ¥价 × 500000 ÷ 汇率）。实时换算，无需「重算」按钮。
4. **汇率统一默认 7、可动态配**：`Price`（充值单价）与 `USDExchangeRate`（展示 / 计费汇率）统一默认 7，动态配置后重启生效。不分离展示汇率与计费汇率（避免双汇率漂移）。
5. **ratio_sync 改造拉¥存¥**：从 models.dev 拉 USD 官方价 ÷汇率 存 ¥（价格 / 比率），手填优先（同步不覆盖已手填模型）。**不禁用**——自动填充官方价有用。

## 后果

**优点**：零 DB 迁移；quota 中性积分不变（向下兼容历史数据）；管理员 ¥ 思维填价；全链一致 ¥；汇率可动态调。

**风险 / 权衡**：
- **语义重定义风险**：价格模式存储值语义从 USD→RMB，历史已填的 USD 价会被当 ¥ 解释。缓解：尚未上线、无历史脏数据；上线前清 / 校准定价。
- **汇率变动**：改汇率后，价格模式 ¥ 价→quota 换算实时变（比率模式不受影响，因其存乘数非原始价）。符合「改汇率重启生效」预期。
- **ratio_sync 覆盖**：手填优先逻辑须正确实现，否则同步覆盖人工调价。
- **美元模型（claude）**：接 claude 时其官方价为 USD，管理员须手动 ÷汇率 填 ¥，或依赖 ratio_sync 改造路径（models.dev 收录则自动 ÷汇率 填¥）。
