# ADR-0071：ThinkingTrace——Agent 思维链面向 User 流式展示并按轮持久化

- **状态**：Accepted
- **日期**：2026-08-10
- **决策者**：钟金俊（经 `/grill-with-docs` 会话共同得出）
- **推翻**：`ReasoningSummary（思考摘要）` 的「内部思考链不展示、不持久化」决策（原 CONTEXT.md 条目）

## 背景

原决策（CONTEXT.md `ReasoningSummary（思考摘要）`）：Agent 只向 User 展示主动整理的一句话结论（≤280 字），模型内部思考链不展示、不持久化。实测暴露结构性缺陷：思考摘要是 `agent_runs` 单行字段，每次 AgentAdvance 提交覆盖写（同一 AgentRun 多轮澄清的中间轮摘要在数据库即丢失）；前端只投影最新一条 AgentRun 的摘要，并把它渲染在整个消息流末尾——表现为"思考过程只出现在最后一轮正文下方"。

产品决策升级为真思维链体验：右侧边栏 AgentChatPanel 是 ReAct 模式（推理 + 工具调用循环）的内容创作辅助 Agent，必须支持持续多轮连续对话，每一轮都要有完整思考过程。

## 决策

1. **思维链可展示、按轮持久化**：每个 AgentAdvance 产生的模型思维链随该轮产出的助手消息持久化（`conversation_messages` 加附属列；计划卡批次由首卡行承载）；思维链不是独立消息类别，不进入模型上下文。
2. **每轮一个思考块**：AgentChatPanel 中位于该轮产出（正文 / 澄清问题 / PlanMessage 计划卡）上方；一轮内多段思考聚合为同一块，不展示工具调用过程。
3. **真流式**：Worker 链路（聊天客户端 → 适配器响应面 → 推进循环增量事件 → RunCommit 契约 → 持久化 / 事件 / 前端投影）改为随模型输出增量推送；思维链在思考中展开流式显示，思考结束自动折叠为"思考过程"，历史轮默认折叠、可手动展开。**正文一并从伪流式（完整响应事后切片补发）升级为真流式**。
4. **审核豁免**：思维链作为未经内容审核的模型原始输出直接流式展示，不走 OutputReleaseGate（输出释放门）；决策者明确接受该风险。记录事实：OutputReleaseGate 在当前 TypeScript 实现中无代码，仅是 CONTEXT.md 术语与设计意图。
5. **异常轮零持久化**：User 主动停止或推进失败时，临时思维链与临时正文一并清除，不落库、刷新后不留块；模型未产出思维链的轮次不渲染思考块。
6. **ReasoningSummary 降级为内部字段**：`reasoning_summary` 保留（RunCommit 契约仍必填），不再面向 User 展示。

## 前置验证

MiniMax-M3 经 new-api 网关是否输出思维链字段（如 `reasoning_content`）仓内无证据。契约工单的第一项验收 = 探针实测（`stream=true` 直连网关观察流式 delta）。探针否决（模型不输出思维链）则本决策的实现路径重新评审。

## 已否决的备选

- **保持思考摘要语义、只修位置缺陷**：不满足"每轮边想边看"的产品意图。
- **`content_type='thinking'` 独立消息行**（仿 PlanMessage 先例）：零 schema 变更，但把思维链纳入 ConversationMessage「正式消息」体系污染概念边界，且必须在模型上下文构建处显式过滤此类行。
- **`agent_advances` 级持久化**：粒度最精确，但触点最多——advances 不进入 snapshot 投影，消息上也没有 advance 关联，需同时新增投影数组与关联字段。
- **正文保持伪流式**：思维链真流式会让正文伪流式的体感落差更明显，决策者要求一并升级。

## 后果

- 三工单串行（契约先行）：① MiniMax-M3 探针 + agent-runtime / 持久化 / 事件契约 + CONTEXT.md + 本 ADR → ② 后端五层链路（客户端、适配器、Worker 循环、契约、持久化与事件）→ ③ 前端投影与渲染。
- 思维链展示绕开内容审核边界；若未来补齐 OutputReleaseGate 实现，需重新评审思维链是否纳入审核。
- 旧的"思考过程"单例渲染（消息流末尾块）与其固化测试随前端工单退役。
