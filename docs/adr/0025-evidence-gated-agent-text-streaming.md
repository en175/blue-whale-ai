# ADR-0025：Agent 文字按 ReviewEvidence 受控释放并在 5 秒内审核

- **状态**：Accepted
- **日期**：2026-07-15

Agent 文字输出必须经过 Java Product API 的 OutputReleaseGate 才能向 User 可见。供应商能够提供可验证的流式安全证据时，Java 按确定性产品策略评估证据，只释放已被证据覆盖的输出前缀；供应商信号本身不能直接成为放行决定，也不能绕过产品事件与持久化权威。

检测到风险时立即停止释放，并以安全错误结束流，未释放文字不得出现在产品事件、Snapshot 或 Conversation。供应商不能提供可靠流式证据、证据滞后于待释放内容或证据无法覆盖当前策略时，完整缓冲回复，取得 ContentReview 明确通过后再整体展示。该方案不向 User 暴露“审核中”，也不为每个文本片段调用外部审核服务，以保留可信供应商下的流式体验并避免审核吞吐瓶颈。

完整缓冲后，从模型回复完成开始的专用审核总预算最多 5 秒，只允许对超时、限流或服务端不可用重试一次，且重试必须包含在同一预算内。等待期间界面保持普通“Agent 正在回复”。明确拒绝时返回 `CONTENT_REJECTED`；预算内无法形成决定时返回 `CONTENT_REVIEW_UNAVAILABLE`。两种情况都立即丢弃未释放文字，不写入 Conversation、产品事件或 Snapshot，也不进入媒体使用的 15 分钟后台恢复；User 后续重试属于新的模型调用，原供应商实际成本仍按事实记录。受控环境必须验证 P95、P99，正常调用若不能满足预算应先解决容量或重新选型，不得静默延长等待。
