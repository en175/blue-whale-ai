# 前端相关推送须通过双模式构建

## 时间

2026-09-30

普通推送能够绕过 PR 发布入口，原前端验证计划也没有执行 Vite 打包。前端相关推送统一核验实际待推送提交的构建凭证，本地提交保持既有检查；构建失败全部阻断，包括目标 release 已存在相同错误的情况。

类型检查执行一次，随后分别以 test、release 模式打包，覆盖同事提出的测试构建命令及仓内镜像使用的模式。共享代码、依赖和构建配置纳入触发范围；仅文档及无前端影响的工程工具改动继续使用原有定向验证。同一提交且构建输入未变时复用有效凭证，Hook 只核验，不自行构建或同步。

执行规则见 [前端推送构建门禁](../../agent-rules/frontend-build-push.md)。本机已安装依赖时，一次类型检查加双模式打包的单次测量为 10.2 秒，其中两次打包合计 2.2 秒；该测量不含依赖安装，也不作为 CI 耗时上限。
