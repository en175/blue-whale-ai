# 图片扩图接入火山 MediaKit 智能扩图：「高清 ▾」菜单第二项、模式化拖框、发送时建卡、比例预设按图动态可达、本期免费

画布图片素材卡工具条的「高清放大」按钮改为带下拉的「高清 ▾」菜单，菜单只含「高清」（既有高清放大，行为不变）与「扩图」两项；重绘/擦除/抠图/裁剪不展示。扩图接入火山 AI MediaKit「提交智能扩图任务」同步接口（`POST /api/v1/tools-sync/expand-image-canvas`），与高清放大同一条 new-api 网关 MediaKit 渠道家族、同一平台级 API Key；参数为 expand_top / expand_bottom / expand_left / expand_right（各 [0, 0.4]，相对原图短边，0 表示该方向不扩），前端把扩展框的像素扩展量换算为这四个比例值，契约只传比例。点「扩图」进入扩图模式：原图卡上出现只许向外扩的扩展框（4 边+4 角，永远包住原图，Shift 拖角锁定拖动开始那一刻的比例），扩图面板跟随源图卡下方浮出，比例预设为原图比例 / 1:1 / 4:3 / 3:4 / 16:9 / 9:16，按「每方向 ≤ 原图短边 40%」上限对当前图片动态判定可达性，不可达的预设置灰并悬停说明，手动拖拽后列表顶部显示被动状态「自定义」；点预设时框以原图中心为锚点外扩到能完整包住原图的该比例最小框，点「原图比例」收回到与原图重合。进入模式不建卡，点发送才创建扩图结果卡并拉纯视觉连线（区别于高清放大的草稿卡先行），发送成功即退出模式。本期不做分辨率（1K/2K/4K）与画质档位控件（API 无对应参数）；张数控件禁用展示、固定 1 张，为后续多张留位；本期不显示积分预估也不实际扣费（网关配零价，同 ADR-0092 口径）。源图长边超过 4160px 或文件超过 10MB 时「扩图」菜单项置灰并悬停说明，图片真实尺寸缺失时同处置。

## Considered Options

- 分辨率控件本期实现为「扩图完成后自动串联一次高清放大拉到 1K/2K/4K」：两次 API 调用、耗时与成本翻倍、失败组合变多，且用户可对扩图结果卡再点一次高清放大达到同样效果，否决；控件也不做禁用展示（不做没有功能的 UI，与菜单只放两项同口径）。
- 不可达比例不置灰、框扩到极限为止：产出比例与用户所选不符，静默偏离预期，否决；采用置灰加原因，与高清放大版本档门槛同口径。
- 沿用高清放大「点入口即建草稿卡加连线」：扩图发送前没有任何可落卡的产物，模式期间建卡会留下空草稿，否决；改为发送时建卡。
- 多次串联调用突破单方向 40% 上限（如 9:16 竖图扩成 16:9 横图）：质量随串联次数下降、成本翻倍、交互上还要解释为何更慢更贵，本期否决，登记为后续可选。
- 我们后端直连火山 MediaKit：同 ADR-0092 结论，自管凭证、绕开网关计费护栏、与既有链路分裂，否决。

## Consequences

- 上线前置条件在网关侧：网关新增 expand-image-canvas 同步工具（对客模型名建议 mediakit-expand-image-canvas），本期 model_price 配 0，复用已配置的 MediaKit 渠道与 API Key；网关未配置时调用以 400 失败，产品侧呈现为任务失败。
- 单方向 40% 上限使极端比例转换不可达（9:16 竖图一次调用扩不成 16:9 横图），面板的按图动态置灰是产品对外的唯一解释通道，置灰文案需要维护。
- 结果图 URL 仅 24 小时有效，执行侧必须在响应后立即下载并落入对象存储（同 ADR-0092）。
- 计费粒度限制同 ADR-0092：网关按模型名按次计费，后续计费工单需先解决分工具计价。
- 扩展框为前端自研（仓内无节点级 resize 设施），实现参考对齐吸附线与整组拖动把手的屏幕空间覆盖层做法；扩图模式期间画布拖拽语义被接管，参考既有框选参考会话的处置。
- 验收修订（IKGOQ0 3002 实测）：服务端复核的缺尺寸处置由「一律拒绝」改为「先探测回填」——assets 宽高由前端上传时上报，画布/资产库两条上传路径历史上不上报（库存约四成图片宽高为 NULL），画布卡片上的尺寸只是浏览器实测回填到节点 data、从不回写资产；用户在画布明明看得到尺寸却被拒，且「重新上传」指引无效（重传走同一路径仍无尺寸）。修订后：资产缺宽高时服务端从对象存储 Range 读文件头探测真实宽高（PNG/GIF/BMP/WebP/JPEG，backend/libs/shared/assets/image-dimensions.ts）并回填资产行，探测不到才拒绝（此时文件本身有问题，「请重新上传」名副其实）；同批把画布上传（uploadFileToAsset）与资产库页上传补齐探测上报，止住 NULL 增量。
