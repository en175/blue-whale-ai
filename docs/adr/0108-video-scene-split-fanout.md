# 场景切分：家族首个一对多输出，编辑态单条发送后场景段卡逐段扇出

视频素材卡新增「场景切分」工具（火山 MediaKit `segment-scenes` 异步任务，输出每段起止时间轴与独立切片文件；2026-09-20，十问拍板）。它是媒体处理工具家族第一个一对多输出的工具（去字幕、HD 高清、音视频分离均为一对一）。决定：入口为视频卡工具条上「音视频分离」之后的图标加文字单按钮，所有视频素材卡可用；点击进入场景切分编辑态（源卡锁定，卡下单条承载 X、标题、切分粒度三档、积分与发送），发送后在源卡右侧建一张场景切分任务卡占位，任务成功后该卡移除，N 张场景段卡以源卡右侧网格扇出并各拉来源连线，失败可原参数重试。

**判定依据是段数未知**。`segments` 是任务结果字段，完成前无法预知会切出几段，所以不能预铺 N 张占位卡，以单张任务卡承载生成中与失败态；HD 式草稿卡加面板的核心价值在结果一对一回填本卡，一对多下草稿卡完成后身份尴尬（留空壳或删除都不干净），不走。

**参数与边界**。切分粒度三档（细 / 标准 / 粗，默认标准对应官方推荐阈值 10）是唯一暴露的参数，映射提交时的 `segment_threshold`（值越低切得越细碎）；`min_duration`、`max_duration`、`enable_clip_fade` 不暴露，走服务端默认。置灰门槛两条：视频未关联资产、时长超 2 小时（有数据时判，缺失放行后端复核）；格式限制不前置拦截，走任务失败口径兜底。任务正常完成但只有 1 段时不特判，照常扇出 1 张段卡（第 1 段，全程时间轴），用户从时间标注自然看出没切开，可换「细」档重发。

## Considered Options

- **聚合结果卡**（一张卡内列段列表，再单段转卡或全部转出）：段数多时画布最稳，但段即素材，转出多一手中转，与节点画布「卡即节点」相悖，否决（原型对照后仍选逐段扇出）。
- **组容器**（结果收进组、组内 N 段）：引入组生命周期语义（展开、折叠、整组删除）超出本次范围，否决。
- **HD 式草稿卡加跟随面板**：见上文判定依据，否决。
- **参数全暴露**（阈值滑杆、时长上下限、fade 开关）：HD 极简面板先例下，粒度是唯一用户可感知差异的参数，其余数值对用户无意义，否决。
- **零参数一键发送**：阈值对效果影响大，切太碎或太粗时用户无纠偏手段，给三档预设保留纠偏能力，否决。
- **段数 1 特判**（提示「未检测到场景切换」不建卡）：多一条分支多一套文案，时间标注已自明，否决。

## Consequences

- 工具会话由六个增至七个（新增场景切分编辑态），四路退出（X、Esc、点其他卡、点画布空白）与互斥沿家族口径；IKH3ZE（PR !775）工具会话集中重构合入 release 后，实施须接其协调器口径。
- 视频卡工具条增至「HD 高清 / 智能去字幕 ▾ / 音视频分离 / 场景切分 / 分隔线 / 详情 / 下载 / @」，工具条屏幕恒定口径（[ADR-0099](0099-canvas-card-toolbars-screen-pinned.md)）下须复核视口钳制常量与图片卡横排（[ADR-0107](0107-quality-tool-family-inline.md)）的宽度并存关系。
- 一对多扇出为家族建立先例：后续多输出工具可复用「单占位卡 + 完成后扇出 + 来源连线 + 段卡即普通卡」骨架。
- 后端与 worker 同构 MediaKit 异步链（提交 segment-scenes 加轮询，编排同去字幕与视频 HD）；网关配置为上线前置，同 HD 与音视频分离先例。
- 进规格阶段须补抓官方参数级 API 参考页（`min_duration` / `max_duration` 服务端默认值、回调结构），本次依据的开发指南 PDF 不含这些内容。
- [CONTEXT.md](../CONTEXT.md) 词条同步（场景切分、场景切分编辑态、切分粒度、场景切分任务卡、场景段卡）；原型归档 `web/prototypes/scene-split.prototype.html`（单文件、双击即开，入口 / 编辑态 / 生成中 / 完成扇出四状态）。
