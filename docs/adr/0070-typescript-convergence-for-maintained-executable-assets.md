# 长期维护可执行资产逐步收敛到 Node.js / TypeScript

- **状态**：Accepted
- **日期**：2026-08-09
- **决策者**：KimJohn（经 `grill-with-docs` 会话确认）
- **关联工单**：[IK7FI6 统一技术栈规则与 Python 存量处置决策](https://gitee.com/hangzhou-xuanfu_1/blue-whale-ai/issues/IK7FI6)
- **关联决策**：[ADR-0068 产品主技术栈与专用计算边界](0068-node-typescript-product-runtime-and-specialized-compute-boundary.md)

Blue-Whale 不把 TypeScript 统一限制在产品运行时：新增长期维护的一方 Hook、工作流、验收工具与测试也必须使用 Node.js / TypeScript，现有 Python 存量按风险和维护机会逐步迁移或退役。目标是减少双工具链、同步副本与维护知识分裂，不是立即追求仓库中 `.py` 文件数量归零。

一次性脚本、未经修改的外部工具，以及 ADR-0068 已允许的专用计算组件可以保留其他语言，但必须符合后续明确的分类与例外判据。现有无关 Python 存量不得自动扩大普通功能工单的范围；具体迁移优先级、完成判据、阻塞条件与规则落位由本次 grilling 后续决策补充。

## 分类判据

- **长期维护可执行资产**：由团队维护、随仓库交付，被运行时、CI、Hook、发布、恢复或重复验收流程依赖，且当前工单结束后仍会继续使用。
- **一次性脚本**：只服务一个边界明确的迁移或调查，不被长期入口依赖，并具有明确删除或归档条件。
- **外部工具**：由第三方、平台或供应商维护且未经本仓修改，本仓只维护调用配置；维护 fork 或修改实现后即成为第一方资产。

分类只看维护责任、长期依赖与任务结束后的生命周期，不按目录、文件后缀或短期调用频率判断。

## 调度与阻塞

Python 存量通过独立迁移任务推进，默认不阻塞无关普通功能。只有功能工单直接修改对应 Python、依赖其行为，或该资产已经形成安全、正确性或验收阻断时，才在同一行为边界内先完成迁移；不得继续新增 Python 债务，也不得借无关存量扩大功能范围。

## 非 TypeScript 例外

- 一次性脚本必须关联具体工单，并写明删除或归档条件；一旦被长期入口依赖，就失去一次性资格。
- 外部工具必须保持未经本仓修改，并记录来源与版本；维护 fork 或修改实现后按第一方资产管理。
- 专用计算组件只有在 Node.js 明显不适合时才允许采用其他运行时，且必须由 ADR 记录原因、边界与产品事实隔离。

## 无保护空窗迁移

Hook、授权、审计、Worktree、同步与发布属于团队协作护栏，禁止原地大爆炸式重写。迁移必须保持现有 Shell 包装器、命令路径、参数、stdin/stdout/stderr、退出码和持久状态格式稳定，并按以下顺序推进：

1. 先把现有 Python 行为冻结为黑盒契约并接入标准测试入口。
2. 在不修改正式入口的前提下实现共享 Node 版本。
3. 纯解析与决策逻辑使用相同输入做差分比较；授权、审计和 Git 副作用只在隔离目录与临时仓库验证，禁止对真实状态双写。
4. 按只读检查、审计、授权与 PreTool、Worktree 与发布的顺序逐域切换；每次只启用一个正式实现，并保留通过包装器显式回退旧实现的能力。
5. 所有消费端完成切换且 Hook 与隔离 Git 黑盒全绿后，才删除对应 Python 实现和同步镜像。

安全 Hook 的新实现异常时必须 fail closed。一次调用中不得自动依次执行两套有副作用的实现，以免重复消费授权、写审计或改写 Git 状态。

## Python 存量去向

本次盘点的 20 个受版本控制 Python 文件最终分类为：16 个迁移、4 个退役、0 个长期暂留。四个退役项是三份 `.qoder` Hook 同步镜像与一份已失效的脱敏器 Python 测试；其余有效 Hook、工作流和黑盒测试均保留行为并迁移到 Node.js / TypeScript。逐文件优先级与完成判据见 [IK7FI6 Python 存量分类与迁移计划](../specs/2026-08-09-ik7fi6-python-inventory-and-migration-plan.md)。

## 被否方案

- **只统一产品运行时，长期工具永久自由选语言**：会长期保留重复依赖、测试方式与维护知识，无法兑现技术栈收敛收益。
- **立即迁移或删除全部 Python 才允许继续普通功能**：会把无关基础设施债务扩张到每个功能工单，违反手术式变更原则。
- **作者自行决定长期工具语言**：无法形成稳定边界，会让临时便利持续增加双工具链。
- **所有例外一律禁止**：会迫使一次性迁移与专用计算使用不合适的工具，偏离技术选择服务于问题的目标。
- **一次切换全部 Python 护栏**：无法隔离行为差异，会同时暴露漏拦、误拦、授权重复消费和 Git 半成品风险。
