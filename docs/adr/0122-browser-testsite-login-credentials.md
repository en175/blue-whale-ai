# ADR-0122: 浏览器自动化测试站登录凭据——家目录个人文件 + agent-rules 指引

**日期：** 2026-10-04
**状态：** 已接受
**工单：** IKJMZ1
**关联：** ADR-0064（测试站凭据治理）

## 背景

浏览器自动化验证（web-gui-tester 等插件技能）连接远程测试站时需要登录账号密码，而插件技能规定「需要登录凭据时停下问用户」，每次会话重复索要。凭据随手放项目 `.env` 也有结构性问题：任务 worktree 之间未跟踪文件不共享（每任务复制一份），且 `.env` 已承载本地服务运行时变量，混入登录凭据会扩大产品进程的读取面。

## 决策

1. **凭据存放**：`~/.bw-test-login.env`（600 权限，dotenv 格式，键 `BW_TEST_LOGIN_USERNAME` / `BW_TEST_LOGIN_PASSWORD` / `BW_TEST_API_BASE_URL`）。家目录跨 worktree、跨 Agent 端共享；凭据值不入库、不进对话记录，延续 ADR-0064 口径。
2. **指引链路**：CLAUDE.md 路由表一行指向 `agent-rules/browser-testsite-login.md`（读文件 → GUI 账密填表登录 → 缺失/失效即停问用户并附创建指引）。指引入库为团队规则，凭据留各人机器——规则与秘密分离。
3. **用途边界**：写操作允许（真实落测试站库，同事可见）；消耗积分的操作先告知再执行；凭据明文只出现在浏览器输入动作中。

## 理由

- web-gui-tester 是插件缓存，项目改不动其「停下问用户」原文；仓库层路由行叠在它上层，让 Agent 在触发场景前先读到取凭据的路径。
- CLAUDE.md 路由表是本仓既有渐进披露机制（ADR-0044），浏览器登录属低频专用流程，按 rule-placement 协议归 `agent-rules/`，主文件只留一行指针。

## 后果

- 无凭据文件的机器上，Agent 落到兜底行为（停下问用户并给出创建命令），团队规则对无凭据者自然降级。
- 凭据轮换只改个人文件一处，无仓库联动。
- 测试站改用其他登录形态（如仅验证码）时，本指引与 `~/.bw-test-login.env` 一并修订。
