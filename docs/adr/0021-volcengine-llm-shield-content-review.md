# ADR-0021：ContentReview 采用火山引擎大模型应用防火墙

- **状态**：Accepted
- **日期**：2026-07-15

Blue-Whale 的文字、图片和视频 ContentReview 统一采用生产账号 `cn-beijing` 区域内的火山引擎大模型应用防火墙，并通过 SDK 检测接口接入。Java Product API 只把供应商返回的消息标识、命中类别和处置建议作为证据，仍由产品策略形成唯一权威决定；不采用 CNAME 流量代理或安全代答替代产品控制面，也不把模型或生成供应商自带审核视为最终决定。

生产启用以前，供应商必须以书面或合同形式确认：送审数据仅在中国境内处理，原始内容不用于模型训练，不被长期留存或保留期可配置，并提供删除、访问审计和安全事件响应能力。任何一项无法确认时，该实现不得进入生产，必须重新选择 ContentReview 供应商。Blue-Whale 自身只保存内容摘要、模态、策略与模型版本、规范化决定、原因码、时间和供应商证据引用，不复制供应商原始响应或不必要的原始内容。

首版不接入第二家专用 ContentReview 供应商，也不在故障时把内容自动路由到未经同等合规核验的服务；生成供应商自身可验证的安全结果仍可按 ADR-0022 作为 ReviewEvidence，证据不足时才调用大模型应用防火墙。服务不可用时遵循各内容类型的 fail-closed 恢复边界，不建立人工审核兜底队列。生产启用前必须用受控环境测得峰值调用量，确认供应商配额足够，并验证限流、超时、不可用和恢复路径；若上线后容量或可用性持续不能满足 SLO，必须通过新 ADR 评估第二供应商，不能通过运行时配置静默切换。
