# 智能抠像：入口下拉双模式直选，编辑态单条一对一出普通成品卡

视频素材卡新增「智能抠像」工具（火山 MediaKit `matte-portrait-video` 人像抠像与 `matte-greenscreen-video` 绿幕抠像两个异步任务端点，共用 tasks 查询；2026-09-21，两轮九问拍板）。决定：入口为视频卡工具条上「场景切分」之后的「智能抠像 ▾」悬停下拉，菜单两项直选模式；选定后源卡停帧锁定，卡下浮出编辑态单条（X、模式标题、输出格式下拉、背景色（仅 MP4 时）、本期免费与发送钮）；发送即退会话，在源卡右侧建占位卡，成功回填为普通成品视频卡并拉来源连线，失败原参数重试。它是一对一输出工具，链路骨架完全复用场景切分以来的 MediaKit 异步家族（submit + 轮询 + 即收即转存 TOS 解 24 小时过期 + 心跳续租）。

**模式选择前置到入口下拉，而不是单按钮进编辑态再选**。两个模式算法与适用素材不同：人像抠像吃任意视频但只识别人，绿幕抠像要求绿幕或纯色背景素材、主体可以是人、物品、动物。「我的素材是不是绿幕」是用户发起前就必须回答的分类问题，放在入口菜单直选（对齐「智能去字幕 ▾」「音视频分离 ▾」下拉家族）；编辑态内再选会把模式与格式、背景色两组真参数混层。换模式不提供就地互切，退出后重选（去字幕家族口径）。

**编辑态单条，不走 HD 草稿卡加面板**。参数只有格式与背景色两组，在单条上一次选完即发，不发不留痕；抠像结果卡是成品素材，没有 HD 卡那种长期记住身份、选中反复开面板重配的诉求。结果卡因此也不记抠像身份，标题跟随模式，选中开普通视频面板，全工具可再发起。

**输出格式只暴露 WEBM 与 MP4 两档，MOV 不暴露**。WEBM（透明背景）为默认；MP4（纯色背景）追加背景色 white/black/green 三选、默认 white，不随官方「人像默认 green、绿幕默认 black」的绿幕合成场景口径，电商白底才是我方主流诉求。透明 MOV 一般为 ProRes 4444 编码，Chrome 无法预览，选了它的结果卡在画布上播不出来，体验断档；面向 AE/PR 的专业诉求出现后随时可加档。

**时长门槛对齐去字幕的 10 分钟置灰**。官方处理耗时为视频时长的 1 至 3 倍，而 worker 轮询上限约 60 分钟，不拦等于让 20 分钟以上的视频注定超时失败；10 分钟整钮置灰并悬停说明（悬停仍展开菜单，对齐去字幕下拉置灰口径），远在轮询安全区内。分辨率与输入格式不拦（官方支持主流格式、建议不超 10GB），WEBM 结果卡再次抠像不做特殊置灰（官方输入格式列表未明确含 webm），超限与不受支持均由任务失败口径兜底。

**透明呈现沿用图像抠图的棋盘格视觉语言**。透明格式结果卡的视频区垫棋盘格底纹标识透明（图像抠图结果卡先例扩展至视频卡，视频侧此前无透明素材），MP4 纯色背景结果不垫。占位卡无耗时预估文案，与 HD、场景切分、去字幕的生成中态统一；上线后体感太慢再补。

## Considered Options

- **单按钮加编辑态内选模式**（场景切分式）：模式与格式、背景色混层，且「素材是否绿幕」是发起前的分类问题而非参数，否决。
- **HD 式草稿卡加跟随面板**：结果卡无反复重配诉求，草稿卡身份对成品素材是负担，否决。
- **只做人像抠像**：绿幕是专业素材主路径，API 已提供，成本仅一个菜单项，否决。
- **格式三档全暴露（含 MOV）**：Chrome 无法预览透明 MOV，结果卡体验断档，否决。
- **背景色跟随官方默认**（人像 green、绿幕 black）：面向绿幕合成场景，与电商白底主流诉求相悖，否决。
- **时长不拦、超时失败兜底**：处理耗时为时长 1 至 3 倍，长视频必超 worker 轮询窗口，兜底等于注定失败，否决。
- **结果卡记抠像身份、选中开抠像面板**：无反复重配诉求，否决。
- **生成中耗时预估文案**：家族生成中态统一无预估，否决。

## Consequences

- 工具会话新增抠像编辑态一路（双模式共用同一会话形态、单条标题随模式），四路退出（X、Esc、点其他卡、点画布空白）与互斥沿家族口径（toolSessionCoordinator，IKH3ZE）。
- 视频卡工具条增至「HD 高清 / 智能去字幕 ▾ / 音视频分离 / 场景切分 / 智能抠像 ▾ / 分隔线 / 详情 / 下载 / @」（人声背景分离 ADR-0110 合并后「音视频分离」将变为「音视频分离 ▾」），工具条屏幕恒定口径（[ADR-0099](0099-canvas-card-toolbars-screen-pinned.md)）下须复核视口钳制常量。
- 透明呈现首次进入视频侧：棋盘格底纹从图像抠图结果卡扩展到视频结果卡（仅透明格式）。
- 后端与 worker 同构 MediaKit 异步链（两端点 submit 加 tasks 轮询，即收即转存 TOS 解 24 小时过期，心跳续租防长任务孤儿重投，per-job 凭证冻结）；两端点的对客网关路径与配零价为上线前置独立票，同 HD、去字幕、场景切分先例（IKH67T、IKH3VI、IKH8BK、IKHA31）。
- 契约与代码层命名对齐火山 matte 命名（video-matting、matte-portrait-video、matte-greenscreen-video），与图片侧 image cutout 各走各词。
- 进规格阶段须补抓两端点的参数级 API 参考页（提交与回调的完整字段、错误码），本次依据的开发指南 PDF 只含 video_url、format、background_color 三个参数与结果三字段。
- [CONTEXT.md](../CONTEXT.md) 词条同步（智能抠像、人像抠像、绿幕抠像、抠像编辑态、抠像输出格式、抠像结果卡）；原型归档 `web/prototypes/video-smart-matting.prototype.html`（单文件、双击即开）。
