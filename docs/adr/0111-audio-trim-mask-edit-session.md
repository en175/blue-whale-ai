# 音频卡「截取」：波形遮罩选段编辑态，格式跟随源音频，贴边省略提交

音频成品卡工具条首位「截取」点亮（ADR-0109 五功能占位中首个实装），接入火山 MediaKit `trim-audio` 异步任务。点击进入截取编辑态：进入即暂停、播放头归零，波形区叠加截取遮罩（白框选区+左右抓手+暗区+中央秒数胶囊四件套），默认全选、最小片段 0.1 秒；红色定位条选区内可点击定位也可按住拖拽；卡下单条发送条（时间范围只读、格式下拉、⚡0 本期免费、发送）；发送建任务与占位卡，成功原地补丁为截取卡（源名(截取).{格式}），失败按 lastInput 原参数重试。（2026-09-20 十七问拍板 + 原型验收通过）

**判定依据是骨架与模态各有先例。** 一对一「单占位卡→原地补丁成品卡」复用音视频分离已实现的整条链路（media_extract 家族：前端会话→路由→generation_jobs→RocketMQ→worker 网关提交/轮询→24h 临时链强制转存 TOS→前端轮询补丁），场景切分与人声背景分离的多产物扇出骨架尚只有 ADR，一对一是唯一已实现形态。编辑态模态接 toolSessionCoordinator 第七会话（互斥、Esc 链、选中规范化同音视频分离档）。遮罩事件走卡内注入层先例（`splitEditing`/`subtitleEraseEditing` 同款：渲染期注入标记、层内消化指针事件不冒泡开面板），化解「点波形试听」与「点卡开音频面板」的冒泡冲突。

**参数与边界。** 格式五档 mp3/m4a/ogg/flac/wav（以火山 trim-audio 官方文档为准，契约独立不与 media-extract 共用枚举，ADR-0110 先例）；默认跟随源音频格式（截取不改变格式的用户预期），源格式不在枚举（如 aac）回退 m4a；进入编辑态重置、不跨会话记忆。精度三级：内部全精度浮点、遮罩胶囊与发送条起止显示 0.1 秒、提交 start_time/end_time 两位小数（顶满 API 精度）；左缘贴 0 省略 start_time、右缘贴全长省略 end_time（走 API 默认片头片尾，规避上传时长整秒精度的超界风险）；产物时长以火山返回 duration 写回服务端权威时长。置灰双条件：音频 URL 缺失、时长缺失或为 0（悬停「音频时长缺失，无法截取」）——截取的手柄时间换算硬性依赖时长，不照搬「数据缺失不拦」家族口径。

## Considered Options

- **播放头不可拖（初版推荐）**：原型走查被 Kim 判交互缺陷，改为选区内按住拖拽连续定位（钳制选区内、播放中拖完续播、暂停态保持暂停），初版口径否决。
- **格式默认一刀切 m4a**（API 默认与分离家族默认）：截取的源本身是音频，用户预期「mp3 截完还是 mp3」，改默认跟随源格式，否决。
- **格式说明小字上发送条**：原型走查被删（提示占宽），规则由交互默认承担（默认即源格式、改选按所选），否决。
- **严格按参考截图的发送条**（无格式下拉、无积分徽标、按钮文案「生成」）：家族对齐优先——分离家族均有格式下拉与 ⚡0 免费徽标、按钮统一家族发送钮，否决。
- **超长音频波形缩放视窗**：1 小时音频 1 像素约 8 秒，接受像素精度上限，以 0.1 秒显示与实时反馈补偿；截取首发面向分钟级生成类音频，本期否决。
- **选区整体平移**：手柄为唯一选区调整手段（选区内点击/拖动已分配给试听定位），本期否决。

## Consequences

- 工具会话从六种扩为七种：toolSessionCoordinator 的 kind 清单、页面 activity/exits 装配、Esc 退出链与选中规范化分类均须接线；接入后 `editSessionActive` 自动隐藏音频卡自己的悬浮工具条（家族模态口径一致，无需额外处理）。
- 后端新路由 `POST /api/projects/:id/audio-trims`、`generation_jobs.type='audio_trim'`、契约包 `@lib/contracts/audio-trim`（source_asset_id/start_time/end_time/output_format，冻结 provider_credential 同 media_extract）；worker 抄 `MediaExtractJobProcessor`（submit/poll 5s×720）与新网关客户端（对客路径常量独立）、`TosAudioMediaRelay` 强制转存 TOS。
- 网关配置照 IKH28Y / IKH8BK 先例独立拆票、为上线前置；对客路径 ≠ 火山上游 `POST /api/v1/tools/trim-audio`（IKH67T 404 教训）。
- 对客免费：网关 model_price 配 0、无幂等头、无积分预估、发送条挂 ⚡0「本期免费」徽标。
- 上传音频 duration 为整秒精度（probeMediaMeta `Math.round`）：遮罩 0.1 秒显示是换算精度，真实边界以试听与火山产物 duration 为准；贴边省略口径已兜住整秒超界风险。
- [CONTEXT.md](../CONTEXT.md) 词条同步（截取、截取编辑态、截取遮罩、截取卡）；原型归档 `web/prototypes/audio-trim.prototype.html`（chore 分支「chore/音频截取交互原型」，单文件双击即开，七状态快跳 + 全程手动，frontend-dev 69 项断言通过；走查修订两处：删格式小字、定位条可拖拽）。
- 「截取」为 ADR-0109 五功能占位中首个点亮，其余四钮（调速/混合/音视频合成/转码）维持置灰占位，各自另立任务。
