# 团队工程技能使用单一权威目录

- 状态：已采纳
- 日期：2026-09-28
- 关联工单：IKIQQX、IKIQRD

团队工程技能保存在 Git 跟踪的 `.agents/skills`，`.claude/skills` 用指向同一工作树的目录符号链接提供 Claude 入口。两条路径引用同一物理文件树，因此增删改无需复制和冲突处理。ZCode 0.16.9 与 Qoder 1.1.45 已验证可直接扫描 Agent 目录；为它们再建项目副本会造成重复注册或覆盖。个人技能目录不由仓库管理。

这一选择要求 Git 检出保留符号链接。只读检查会拒绝丢失、普通目录替代或跨工作树的链接，并报告过期或额外项目副本。若未来客户端无法读取目录引用，可为该客户端生成完整副本，但须先确认它不会同时扫描 Agent 目录，并新增副本逐文件校验。具体维护入口见 [团队工程技能维护](../agents/project-skills.md)。
