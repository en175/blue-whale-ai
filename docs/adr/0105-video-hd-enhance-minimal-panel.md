# 0105：视频 HD 高清面板采用极简骨架，裁撤供应商/模型两级下拉

视频画质增强（大模型版）供应商仅 MediaKit 一家、模型仅「画质增强（大模型版）」一个、无版本档参数，可暴露的产品参数只剩目标分辨率一项。视频 HD 高清面板因此不复用图片高清放大面板的「供应商 → 模型」两级下拉骨架，采用极简布局：标题、目标分辨率三档分段、本期免费与发送钮（[ADR-0101](0101-quality-tool-family-interaction-alignment.md) 的发送钮统一口径继续适用）。被否决的两案（顶部保留只读模型信息行、分辨率做三张档位卡片）经 HTML 三案原型对比后由产品拍板极简案（2026-09-20），未来接入第二供应商（如 Topaz）时再恢复两级结构。

一并记录的本功能关键取舍：

- 入口为「HD」文字徽标单按钮直启（排位在重新编辑之后、智能去字幕 ▾ 之前），不并入图片侧「高清 ▾」下拉家族：视频侧画质工具当前仅此一个，无共用承载；也不用图片高清的 Expand 图标，跨类型用徽标区分。
- 目标分辨率只提供 1080P/2K/4K 三档（默认 1080P），裁掉 API 默认值 720p：产品语义为「高清」，默认 720P 名不副实。
- 码率固定 medium、帧率不传（保持原片帧率），均不暴露：码率是技术向参数且官方推荐 medium，帧率变化不属于「画质增强」语义。
- 供应商输入上限（短边 [360,1080]、长边 ≤1920、仅 SDR）做前置置灰与悬停说明，宽高缺失不拦、SDR 无前置元数据，均由任务失败口径兜底；链式增强受输入上限约束，只能进行到 1080P 输出为止，接受为供应商物理约束。
- 建卡与会话形态照抄图片高清放大（进入即建草稿卡 + 跟随面板，重新编辑回面板，结果回填本卡），本期免费不走积分预估与余额拦截。
