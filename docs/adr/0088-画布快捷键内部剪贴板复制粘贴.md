# ADR-0088：画布快捷键新增内部剪贴板复制粘贴并保留 Ctrl/Cmd+D 立即复制

- **状态**：Accepted
- **日期**：2026-09-16
- **决策者**：项目团队（IKGBP1 需求拍板，Kim 主持）
- **关联工单**：[IKGBP1 画布键盘快捷键](https://gitee.com/hangzhou-xuanfu_1/blue-whale-ai/issues/IKGBP1)（父单，本片 IKGBPA）
- **关联决策**：[ADR-0073 画布交互优化四需求](0073-canvas-interaction-optimization-four-features.md)（Ctrl/Cmd+D 立即复制基座）、[ADR-0081 画布滚轮/修饰键](0081-canvas-wheel-pan-modifier-zoom.md)（画布快捷键让位口径）

## 背景

画布已有 Ctrl/Cmd+D 立即复制（ADR-0073 / IKD0JT REQ-A-109）：副本立即出现在原卡右下 40px。用户还需要「把卡复制到别处」的工作流：先快照、再移动视口、再粘贴——立即复制无法覆盖（副本落在原位附近，且无法连续粘贴多份）。IKGBP1 为此新增 Ctrl/Cmd+C / Ctrl/Cmd+V 内部剪贴板，本片（IKGBPA）交付基座。

## 决策

1. **内部剪贴板是页面级内存状态，不碰系统剪贴板。** 快照数组 + 连续粘贴偏移计数放 `CanvasPage/index.tsx` 的 `useRef`；不持久化（刷新即失）、不写系统剪贴板（不污染用户跨应用剪贴板）、切换项目清空（对齐撤销栈不跨项目的既有实现）。本片 V 键在内部剪贴板为空时静默；系统剪贴板兜底是并行工单 IKGBPB，粘贴入口已留出明确分支点（内部剪贴板读取不与 V 键判定耦死）。

2. **C 快照定格。** 复制时对选中卡做 JSON 深拷贝（函数回调被自然剥离，粘贴时经 `attachCallbacks` 重注入）：原卡此后被删除、改名、编辑或生成完成，粘贴出的副本仍是复制时刻的样子。每次成功复制重置连续粘贴偏移。

3. **仅文本卡与媒体卡可复制。** 商品卡 / 资产卡 / 空选中按 C 静默忽略；混合多选时只快照文本/媒体卡（过滤在 Canvas 键盘入口的纯函数完成）。

4. **V 落位策略。** 以当前视口中心为锚（复用 Canvas 注册的 `screenToFlowPosition` 换算，页面侧即 `spawnPosRef`）；多卡快照按原相对位置整体落位（快照包围盒左上角对齐视口中心）；连续粘贴整组右下错开，步长 40px（对齐立即复制偏移惯例）；贴出的副本自动选中（新增 `selectManyRequest` prop，机制同既有单选 `selectRequest`——必须经 Canvas 内部 `setNodes` 应用，父层 selected 字段传播被合并保护忽略）。

5. **连线语义。** 手拉连线不随粘贴复制（粘贴只产散卡）；文本卡副本按 IKFM3Q 契约 §4 重建正文 @ 引用的派生索引线（来源节点仍在画布时 `syncTextIndexEdges` 同步复制，派生线非手拉线）。

6. **撤销按既有「新增节点」形态登记。** 一次粘贴产生两条撤销条目（`pushAddNodes` 整组副本 + 派生线 `pushAddEdges`），与 Ctrl/Cmd+D 立即复制的登记形态一致；撤销移除副本后悬空派生线由 IKDLQF 端点级联清理。

7. **Ctrl/Cmd+D 立即复制保留，与 C/V 并存互不干扰。** 两者服务不同工作流：D 是「就地多一张」，C/V 是「搬运到别处」。

8. **让位规则（决策纯函数 `keyboardClipboard.ts`，形态对齐 `keyboardDelete.ts`）。** 输入按键事件关键信息（key、metaKey/ctrlKey、shiftKey、target 可编辑性、@ 菜单是否打开），输出 `'copy' | 'paste' | 'ignore'`（枚举可扩展，后续 Z 撤销等并入同形态）。焦点在文本卡编辑器 / 输入框 / 生成面板输入区（`isEditableKeyboardTarget`）或 @ 引用菜单打开（`[data-canvas-keyboard-scope="mention"]`）时让位浏览器原生行为（不 preventDefault）；Shift 组合（DevTools 检查元素等）忽略；跨平台 `metaKey || ctrlKey` 行为一致。

## 被否方案

- **读写系统剪贴板作为主通道**：跨应用粘贴意图与画布内搬运意图混淆，且写系统剪贴板会覆盖用户既有内容。系统剪贴板只在内部剪贴板为空时作兜底（IKGBPB 范围）。
- **复制时携带手拉连线**：多选复制的目的通常是拆散重组，携带连线会在粘贴处产生意外边；需要连线随行时用户可框选后重新连线。
- **快照持久化到画布文档**：剪贴板是会话性工作状态，持久化会引入跨项目/跨用户语义问题，且与「切项目清空」拍板冲突。
