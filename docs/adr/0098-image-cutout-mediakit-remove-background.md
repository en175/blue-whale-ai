# 图片抠图接入火山 MediaKit 背景移除：「高清 ▾」菜单第四项、横条工具栏、场景三选、增强参数限场景、本期免费

画布图片素材卡工具条「高清 ▾」下拉菜单在「擦除」之后新增「抠图」（魔棒图标），续接 ADR-0093（扩图插高清与擦除之间）、ADR-0094（擦除）、ADR-0096（裁切殿后）的排位约定，最终顺序为高清/扩图/擦除/抠图/裁切，重绘未来再插。抠图接入火山 AI MediaKit「提交图像背景移除任务」同步接口（`POST /api/v1/tools-sync/remove-image-background`），与高清放大、扩图、擦除同一条 new-api 网关 MediaKit 渠道家族、同一平台级 API Key。接口是全自动抠图：无遮罩与选区输入，自动识别并保留主体、移除背景、返回透明背景图，因此交互上不存在编辑态，工作量集中在参数承载与链路接线。唯一必选业务参数 scene 三选一：通用（general，默认，自动识别主体）、人像（human，只保留人物）、商品（product，只保留商品）；主体描边（need_contour/contour_color/contour_size）与透明背景裁剪（need_crop_background）两组增强参数仅在人像与商品场景生效，通用场景接口直接忽略，界面上通用场景不显示这两组控件。参数承载形态采用扩图工具栏（ADR-0095 修订）同款横条：跟随源图卡下方，X 关闭、场景上拉菜单、人像或商品场景下追加描边上拉（启用开关+宽度滑杆 1~50 默认 10）与透明裁剪点亮式开关、本期免费、圆形发送钮；描边颜色固定白色不做取色器。进入不动视角；退出（X、Esc、点其他卡、点画布空白）参数丢弃。发送时才创建抠图结果卡并拉纯视觉连线（同 ADR-0093/0094，区别于高清放大草稿卡先行），输出固定 png（接口默认且支持透明），结果卡图片区垫棋盘格底纹标识透明；生成中到成品、失败可重试原参数，同步接口不支持取消。源图门槛按本接口官方限制独立判定（不与擦除共用）：webp/gif 格式、超过 30MB、超过通用场景上限（长边 10240px、短边 6000px、总像素 40MP）时菜单项置灰并悬停说明，真实尺寸缺失不拦；选人像或商品后发送前按更严上限（长边 7680px、短边 4320px）精校，超限发送置灰。本期不显示积分预估也不实际扣费（网关配零价，同 ADR-0092 口径）。

## Considered Options

- 一键直发（点菜单项即以默认通用参数直接发送，零界面）：scene 直接决定抠图效果，人像图与商品图必须选对场景，零界面剥夺用户选择权、返工率高，否决；参数承载于横条工具栏。
- 高清放大式跟随浮出竖向参数面板（ImageEnhanceDialog 模板）：验收中的扩图已把同类参数承载改版为横条工具栏（ADR-0095 修订），同门工具形态应一致，拍板否决；采用扩图式横条（场景收上拉菜单、圆形发送钮、无标题字）。
- 通用场景下描边与透明裁剪置灰显示并悬停提示：默认场景首屏出现两组死控件，徒增横条宽度与困惑，否决；隐藏，切换到人像或商品时出现。
- 描边颜色取色器：低频诉求、高实现成本，否决；固定白色（接口默认 #FFFFFF）。宽度暴露 1~50 而非接口全量 1~100：50px 以上描边产品上无意义。
- 暴露输出格式选择：jpeg 透明区填黑、webp 不能再进本接口输入，png 是唯一合理选择，否决；固定 png 不暴露。
- 与擦除共用输入门槛（2560×1440、10MB）：两个接口官方限制差异大（抠图 30MB、10240px），共用会误拦大量合法图，否决；各按官方限制独立判定。
- 透明结果不垫底纹直接显示：透明区混入画布底色，用户无法直观确认背景已移除，否决；结果卡垫棋盘格。

## Consequences

- 上线前置条件在网关侧：网关新增 remove-image-background 同步工具（对客模型名建议 mediakit-remove-image-background），本期 model_price 配 0，复用已配置的 MediaKit 渠道与 API Key；网关未配置时调用以 400 失败，产品侧呈现为任务失败。网关配置单另行建立（对标擦除的 IKGOTD）。
- 结果图 URL 仅 24 小时有效，执行侧必须在响应后立即下载并落入对象存储（同 ADR-0092/0093/0094）。
- 透明 png 进入擦除、高清放大、扩图、裁切等下游链路本期不额外处理；若下游出现透明语义问题（如扩图对透明区填充异常），届时另立工单。
- 计费粒度限制同 ADR-0092：网关按模型名按次计费，后续计费工单需先解决分工具计价。
- 抠图工具栏与扩图工具栏为同构形态而非共享组件（扩图整包尚未合入本分支），锚定、领土豁免、置灰守卫沿用既有面板同构口径；两侧后续如需收敛为共享横条骨架，另行评估。
