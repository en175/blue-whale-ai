# ADR-0033：生产启用前执行两阶段受控验证

- **状态**：Accepted
- **日期**：2026-07-15

IK10IG 采用非生产与生产隔离环境两阶段验证。第一阶段在独立非生产账号完成自动化测试和故障注入；第二阶段在生产账号 `cn-beijing` 的隔离 VKE namespace 中执行冒烟验证，使用专用 Kubernetes ServiceAccount、测试凭据、测试 Bucket 和合成内容，不接入真实用户流量、真实用户素材或公开展示面。只有两阶段证据包均通过，才能开启真实生产流量。

Agent 负责生成配置清单、部署脚本、验证脚本和证据报告，但不接触人工登录凭据，也不代替具备生产权限的人执行供应商控制台操作。IK10IG 当前负责人 `@kimjohn` 是生产账号操作与最终验收负责人，负责执行或明确授权 KMS、IRSA、旧凭据吊销和供应商控制台变更，并确认验证证据。

证据包至少覆盖：三个运行单元允许和拒绝读取的权限矩阵；凭据获取、轮换、撤销和异常访问告警；ContentReview 通过、拒绝、超时、不可用、重试和幂等；未通过内容无法进入下游、公开 Asset 或用户展示面；日志、Trace、产品事件和 AuditRecord 不包含原始凭据、供应商原始响应或受隔离内容。任何必测项失败都阻止生产流量启用，不能以人工抽查或供应商控制台显示成功代替自动化证据。
