# 图片高清放大接入火山 AI MediaKit：版本档映射 Lite/Pro/Max、本期免费、源卡连线纯视觉

画布图片素材卡新增「高清放大」入口，供应商为火山引擎 AI MediaKit 图像画质增强（同步接口 `tools-sync/enhance-image`），这是仓内第一条不经 new-api 网关的供应商直连通道，凭证为平台级 API Key（环境变量注入），不属于 per-user sk- 透传体系。面板上「模型」下拉的三档展示名 Lite / Pro / Max 分别映射 MediaKit 的 standard / professional / max 三个 tool_version，默认 Pro；放大倍数固定 2/4/6 三档，不开放 API 支持的 1~30 任意倍率；增强策略与色彩校正作为高级参数暴露，版本不支持时置灰并悬停说明。源图尺寸门槛（standard 长边 ≤2160px、professional 短边 ≥256px、max 宽高比 ≤32）由前端在打开面板时预检，不满足的版本档置灰。本期高清放大不显示积分预估也不实际扣费，沿用 media_extract 免费工具先例，预估展示与扣费后续单独工单一起补。源卡与高清卡之间的连线仅表达来源关系，不参与参考计数与 @ 编号；高清卡记住自身身份，其「重新编辑」始终打开高清放大面板，结果填回本卡而非源卡。

## Considered Options

- 设计稿中的 Topazlabs 作为供应商：设计稿为占位，实际接入只有火山 AI MediaKit 一家；供应商级下拉保留但只有 MediaKit 一项，未来接第二家时自动出现，当前不做 Topazlabs 任何接入。
- 开放 1~30 任意倍率：API 支持且 professional/max 上限 30 倍，但设计稿固定 2/4/6 已覆盖主流诉求，任意倍率引入输入校验与超分辨率上限的额外复杂度，否决。
- 本期即扣积分（只不做预估展示）：展示与扣费拆开会使用户余额无声减少，且预估展示在全站无先例，一并推迟到后续工单，否决。
- 复用图片生成面板（带提示词与参考栏）：高清放大的输入图固定为源卡、无提示词语义，复用会引入大量禁用态分支，另起轻量面板。
- 经 new-api 网关转发 MediaKit 调用：网关侧无现成渠道，且 MediaKit 使用平台级 API Key 而非用户 quota 计费，与网关的 per-user 透传模型不符，本期直连。

## Consequences

- 上线前需在火山控制台 AI MediaKit 页面创建平台级 API Key 并配入服务器环境变量；缺失时功能不可用，须以配置错误呈现。
- MediaKit 同步返回的结果图 URL 仅 24 小时有效，执行侧必须在响应后立即下载并落入对象存储，产物才成为 Asset。
- 「本期免费」意味着平台自担 MediaKit 调用成本（standard 6 元/千次、professional 36 元/千次、max 240 元/千次），放量前须补计费工单。
