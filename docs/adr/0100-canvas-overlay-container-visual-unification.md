# 画布浮层容器视觉统一（四件套令牌化）

画布与生成界面上悬浮的界面容器（浮层容器）此前各自硬编码色值、逐组件漂移：媒体卡工具条半透明
`rgba(24, 24, 24, 0.96)`（历史样式，非 IKGYYB 引入）、文本卡格式栏 `#2a2a2a`、各浮层菜单
`#262626`/`#2a2a2a` 两套，而底部面板家族早已事实统一为 `#1e1e1e`。产品拍板：顶部工具栏与生成
面板属于同一类面板组件 UI。为此统一三个家族共 21 个成员的容器四件套，值全部落令牌并配测试锁。

## 决定

容器四件套全家族统一（基准 = 底部面板家族现值，家族内像素零变化，其他成员向基准靠）：

| 项 | 值 | 载体 |
|---|---|---|
| 背景 | `#1e1e1e` | 新令牌 `--color-bg-overlay` |
| 描边 | `1px solid #2c2c2c` | 新令牌 `--color-border-overlay` |
| 阴影 | `0 8px 32px rgba(0, 0, 0, 0.4)` | 新令牌 `--shadow-overlay` |
| 圆角 | 大容器档 16px / 浮条与小菜单档 12px | 复用既有 `--radius-xl` / `--radius-lg` |

半透明容器背景退役；配 CSS 源断言测试锁（先例：文本卡 chip 缩略图统一），盯住成员容器必须引用
令牌、不得再出现硬编码色值。

成员清单（21 个）：

- **卡悬浮工具条家族（5）**：媒体卡工具条、文本卡格式栏、文本卡操作条、资产卡顶栏、商品卡顶栏。
  后三者现状无容器底，统一加底；资产卡/商品卡顶栏由文档流时代 `justify-content: space-between`
  撑满卡宽的布局改为 `width: fit-content` 按内容收紧，与媒体卡工具栏同构。
  （合并缝合纪要：资产卡顶栏已随 !742 迁入钉屏幕层，缝合后保留其 `space-between +
  min-width: 320px` 锚回口径，`fit-content` 在其上按内容收紧；商品卡未迁移，维持纯收紧版。
  测试锁 `overlayContainer.test.ts` 按此分卡断言。）
- **浮层菜单家族（6）**：高清▾ 下拉、右键菜单、@菜单、标签操作层、连线类型菜单、参考来源菜单。
- **底部面板家族（10）**：图片/视频/音频/音乐/文本生成/Agent 面板 + 高清放大/擦除/扩图/裁切
  工具对话框。纯切令牌引用，像素零变化。

条内按钮规格统一：卡工具条内按钮为透明底、悬停泛 `rgba(255, 255, 255, 0.08)` 微亮；
`#2a2a2a` 胶囊按钮（文本操作条/资产卡/商品卡顶栏内）退役，全产品「添加到对话」一个样子。

## 边界（明确的 no）

- 交互态半透明不动：按钮悬停微亮、删除红 `rgba(250, 82, 82, 0.8)`、遮罩黑 `rgba(0, 0, 0, 0.6)`、
  资产列表项近不透明表面，各归各的语义，不属容器四件套。
- 模态弹窗（资产库选择/共享资产/角色库/历史记录）不是浮层容器，另类。
- 扩图框/裁切框/擦除遮罩是画布内操作框架；画布左侧工具栏/顶栏是常驻控件，均不在范围。
- 连带修正仅限：容器统一 `#1e1e1e` 后个别成员内部件失去对比度（如 @菜单搜索框 `#1f1f1f`），
  逐成员核对微调内部层级色。

## Considered Options

- 圆角完全同值（全 16px）被否：40px 高的浮条配 16px 圆角接近胶囊、视觉夸张；两档都是令牌表内
  定义，不是各组件自由发挥。
- 共享 class（`.floatingPanel`，mediaChip.module.css 先例）被否：令牌只动 CSS 变量引用不改
  DOM 结构，改动面更小。
- 只修截图所指的媒体卡工具条被否：同类元素跨场景全面对齐、一次改到位（既有产品口径）。
