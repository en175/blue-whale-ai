# ADR-0024：上传媒体按不可变 Asset 一次审核并有界恢复

- **状态**：Accepted
- **日期**：2026-07-15

每个用户上传的图片或视频在内容完成固定并校验摘要后执行一次机器 ContentReview。审核中的 Asset 可以持久化并向 User 显示为“素材处理中”，但在明确通过以前不能进入 Agent 或生成供应商；首版不设置人工审核。文件类型、大小和恶意文件检测属于独立的上传安全校验，不计入 ContentReview。

上传审核最多自动恢复 15 分钟，只对同一素材追加 ReviewAttempt。明确通过后素材才可用；明确拒绝时返回 `CONTENT_REJECTED`，隔离媒体立即进入删除队列并最迟在一小时内删除。15 分钟仍无法形成决定时，ContentReview 进入不可变的 `failed`，界面显示“素材处理失败，请重试”，原始上传继续隔离保留 24 小时。User 在期限内重试时复用内容摘要并创建关联的新 ContentReview，不要求重新上传；到期仍未通过则硬删除，后续必须重新上传。任何故障状态都不能绕过使用门槛。

明确通过的决定随该不可变 Asset 长期复用，不因每次生成或后续审核策略升级重复调用外部服务。编辑、换源或其他派生操作必须创建新 Asset，并按新 Asset 创建时的策略重新审核。该取舍把审核量约束为新增 Asset 数量，同时接受历史 Asset 按其接纳时策略继续有效，与 ADR-0018 对已接纳历史 Asset 的连续可用边界一致。
