# 生成 Dock 协调器与工具会话运行时的状态分工

2026-10-07，用户已确认 IKIZ2Y 的整体设计。生成 Dock 协调器统一视频、图片、音频、音乐、文生文、高清、视频 HD、视频插帧八面板的打开、关闭、互斥与活动视图。五个普通面板的显隐、草稿绑定、选择豁免、seed 快照和草稿参数派生归协调器；高清、视频 HD、视频插帧的会话状态继续由工具会话运行时持有。协调器通过既有工具句柄接入三个面板，以派生视图读取其状态。

三个工具面板已经与其余编辑会话共用初始化、退出、会话身份及界面提交锁。再次迁移会使这些规则分离，并违背 [ADR-0101 的状态归属](0101-quality-tool-family-interaction-alignment.md)。保留所有权需要协调器对接既有工具会话接口，但可复用已统一的生命周期及各工具的真实差异。

调用方通过只读视图与语义动作使用模块，静态类型注册项绑定现有面板与专属策略。表单局部状态和组件生命周期保持原样，页面保留选中态规范化及参考选取、工具事件的既有顺序。宿主生命周期通知分别交给各状态所有者处理；共同发送编排保留类型差异，任务后续生命周期继续归生成任务运行时。整体接口、兼容差异及公开接口测试矩阵见 [IKIZ2Y 设计](../specs/2026-10-07-ikiz2y-generation-dock-coordinator-design.md)。

实施接入与兼容验收见[八面板验收清单](../projects/IKIZ2Y/generation-dock-acceptance.md)。该清单区分当前实现证据、设计阶段调查和仍未执行的人工验收。
