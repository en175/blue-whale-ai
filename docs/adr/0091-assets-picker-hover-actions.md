# 资产库选择弹窗承载素材删除与放大预览，三处卡片角标布局统一

资产库选择弹窗（AssetsPickerModal）的素材卡片在右下角提供悬浮操作（删除 + 放大预览），鼠标悬浮卡片时显现；选择弹窗自此承载素材管理，IKGC0J「选择弹窗只管勾选、素材管理归资产页」的口径作废。删除始终是彻底删除并与资产页同款确认：本仓资产删除前提示项目引用数，人像库素材提示不可撤销；删除成功后卡片就地移除，列表不整列刷新、滚动位置与其余勾选状态不变，已勾选的被删条目自动取消勾选并更新已选计数。放大预览打开与资产页同款的详情弹窗（左媒体右信息），只看不选。弹窗内三处卡片（主瀑布流、虚拟人像库、真人人像库）角标布局统一为：左上类型标、右上勾选圆钮、右下悬浮操作、底部名称条（处理中/失败状态标并入名称条）；资产页主瀑布流的删除按钮同步从右上角挪到右下角，三处同源同位。

## Considered Options

- 选择弹窗保持只读、管理仍归资产页（IKGC0J 原口径）：用户在弹窗内浏览素材时无法删除失败素材、无法看清大图，须跳资产页打断选择任务流；且真人人像库分组详情在弹窗内实际已保留删除按钮，原口径本身已裂口。否决。
- 删除仅「从当前候选列表拿掉」：与资产页删除语义分裂，同一图标两种后果，用户无法预期。否决。
- 放大预览用纯媒体 lightbox（无信息栏）：资产详情弹窗已存在且是资产页同款，另起一套放大视图违反跨场景共用一份视觉定义的口径。否决。
- 删除后整列刷新（资产页主瀑布流现状）：弹窗内边浏览边勾选，整列刷新回顶会打断操作；人像库路径本来就是就地移除，统一为就地移除。

## Consequences

- 选择弹窗内删除复用两套既有 API 与确认流：本仓资产 `deleteAsset`（带项目引用计数确认），人像库素材 `deleteMaterialAsset`（不可撤销确认）。
- 资产页主瀑布流删除按钮位置变更（右上 → 右下）属纯视觉对齐，无行为变化。
