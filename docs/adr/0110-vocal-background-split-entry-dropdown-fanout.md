# 人声背景分离：「音视频分离」入口改悬停下拉，编辑态场景与格式双参数，完成后逐轨扇出

视频素材卡工具条的「音视频分离」按钮改为悬停下拉（交互同「智能去字幕 ▾」：hover 展开、移出 120ms 延迟关、点击触发钮直启首项），菜单两项：「音视频分离」（原功能不改名）与「人声背景分离」（新工具，火山 MediaKit `separate-voice` 异步任务；2026-09-20 十问拍板）。人声背景分离点击进入编辑态：源卡锁定，卡下发送条为分离场景下拉加分离格式下拉加「本期免费」加发送；发送后在源卡右侧建单张占位卡拉来源边，任务成功后占位卡移除、轨卡纵向扇出（通用/音乐场景两张、短剧/口播三张），失败可原参数重试。

**判定依据是层级与骨架各有先例。** 入口下拉承载「功能选择」层级（同去字幕的模式选择），分离场景是任务参数（决定产出几轨的效果差异），参数放编辑态不混入入口；一对多输出复用场景切分刚立的「单占位卡 + 完成后扇出 + 来源连线 + 产物即普通卡」骨架（ADR-0108），不再新发明承载形态。轨卡样式完全跟随当前音频卡实现（!783 / [ADR-0109](0109-audio-card-landscape-toolbar-placeholders.md) 后为 480×240 横矩形），本功能零样式改动。

**参数与边界。** 分离场景四档（通用/音乐/短剧/口播，默认通用，进入编辑态重置不跨会话记忆）：通用与音乐出人声加背景音两轨，短剧与口播出人声、音乐、音效三轨，轨数说明写在菜单项悬停 title。分离格式五档（aac/mp3/wav/m4a/flac，默认 aac；与音视频分离的枚举不同，有 aac 无 ogg，契约各自独立）。轨卡与占位卡命名沿音视频分离的 `源名(…)后缀` 机制：占位卡 `源名(人声背景分离)`，轨卡 `源名(人声/背景音/音乐/音效).格式`。置灰照搬音视频分离口径：唯一置灰为视频未关联资产（整钮置灰但 hover 仍展开菜单看原因），官方文档未写时长/分辨率/大小限制，故不做前置预检，超限走任务失败口径兜底。

## Considered Options

- **原功能更名「提取音轨」**：语义更准、避免与触发钮重名，但 Kim 拍板原功能就叫「音视频分离」不改名，老用户零迁移，否决。
- **场景四档前置到入口下拉**：与功能项「音视频分离」混在一层共五项，层级混乱；场景是任务参数应随编辑态，否决。
- **单卡多音轨切换**：需为音频卡新发明轨切换交互，与刚定稿的音频卡横矩形改版（ADR-0109）耦合；逐轨扇出后轨卡即普通卡、可直接连线下载与 @，否决。
- **固定通用场景零参数**：放弃短剧/口播的三轨精细分离能力（换 BGM、留音效等二次创作的核心价值），否决。
- **纯音频输入（audio_url）本期一起做**：API 支持但音频卡工具条五功能刚置灰占位、样式改版刚落地，范围外待音频卡功能任务逐个点亮时另议，否决。
- **时长/分辨率前置预检**：官方 PDF 未写任何输入限制，无依据设阈值；照 ADR-0103 决策四不预检、超限走任务失败，否决。

## Consequences

- 工具会话新增人声背景分离编辑态，四路退出（X、Esc、点其他卡、点画布空白）与互斥沿家族口径，实施须接 IKH3ZE（PR !775）的 toolSessionCoordinator 协调器。
- 视频卡工具条「音视频分离」变「音视频分离 ▾」（增 ChevronDown 图标），[ADR-0099](0099-canvas-card-toolbars-screen-pinned.md) 屏幕恒定口径下须复核视口钳制常量。
- 轨卡与占位卡样式零改动：`mediaType: audio` 走 `mediaContentSize` 自动得 480×240 横矩形（ADR-0109），扇出布局按 `mediaContentBox` 实时尺寸计算。
- 后端与 worker 同构 MediaKit 异步链（编排骨架对齐 media_extract 家族）；新跨进程契约承载 scene、output_format 与三轨 result url 字段，输出格式枚举独立不与 media-extract 共用；网关配置为上线前置，照 IKH28Y / IKH8BK 先例独立拆票，网关对客路径以定稿为准（IKH67T 教训：网关路径不等于火山上游 `POST /api/v1/tools/separate-voice`）。
- 一对多扇出为家族第二例（继场景切分 ADR-0108），骨架复用成立后后续多输出工具可直接沿用。
- [CONTEXT.md](../CONTEXT.md) 词条同步（人声背景分离、人声背景分离编辑态、分离场景、轨卡）；原型归档 `web/prototypes/vocal-split.prototype.html`（chore 分支 `chore/人声背景分离交互原型`，单文件、双击即开，入口/编辑态/生成中/失败/完成扇出/置灰六状态，frontend-dev 截图回归 15/15 通过；原型内轨卡为改版前方形示意，实施以当前音频卡实现为准）。
