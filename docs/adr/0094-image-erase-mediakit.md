# 图片擦除接入火山 MediaKit 图像擦除修复：「高清 ▾」菜单第三项、涂抹编辑态、统一遮罩单路径、发送时建卡、本期免费

画布图片素材卡工具条的「高清放大」按钮改为带下拉的「高清 ▾」菜单（此改造与 ADR-0093 同一次落地），菜单先放「高清」（既有高清放大，行为不变）与「擦除」两项，扩图就绪后插入其间，最终顺序为高清/扩图/擦除；重绘/抠图/裁剪不展示。擦除接入火山 AI MediaKit「提交图像擦除修复任务」同步接口（`POST /api/v1/tools-sync/erase-image`），与高清放大、扩图同一条 new-api 网关 MediaKit 渠道家族、同一平台级 API Key；tool_version 仅 standard，接口无档位、比例、分辨率、张数参数，输出为原图尺寸。本期开放三种擦法：「清除文字」一键擦除全屏文字（standard_scene=full_screen_text_erase，不指定文字内容）、矩形框选、画笔涂抹，后两者统一走 selected_area_erase：前端把全部框与笔迹栅格化成一张与原图同分辨率的黑白遮罩图，经既有资产上传链路取得公网 URL 后以 mask_url 提交，绕开 selected_area 单矩形限制并天然支持多框多笔迹并集。点「擦除」进入擦除编辑态：源图卡上方浮出擦除工具条（清除文字/画笔/框选/橡皮擦/笔刷大小/撤销重做），下方跟随条仅含「本期免费」与发送钮；待擦除区域以棋盘格标示；框落笔即固化进遮罩，修改靠橡皮擦与撤销重做，撤销只作用于未发送的遮罩编辑；视角不自动调整；发送前退出（X、Esc、点其他卡、点画布空白）丢弃遮罩不留痕迹。进入编辑态不建卡，点发送才创建擦除结果卡并拉纯视觉连线（区别于高清放大的草稿卡先行），发送即退出编辑态，结果卡生成中到成品、失败可重试，同步接口不支持取消。源图超过 2560×1440、超过 10MB 或为 webp/gif 格式（接口输入仅支持 png/jpg/jpeg/heic）时「擦除」菜单项置灰并悬停说明，图片真实尺寸缺失时同 ADR-0092 口径不拦。输出格式选 png 而非接口默认 webp，使结果卡可再次擦除、扩图、高清放大。本期不显示积分预估也不实际扣费（网关配零价，同 ADR-0092 口径）。

## Considered Options

- 全屏图标擦除与指定文字内容擦除（standard_erase_text）：图标擦除场景窄，指定文字依赖 OCR 识别准确度、体验不稳定，本期否决，接口与菜单结构留扩展位。
- 单矩形时走 selected_area 参数、多笔画才走 mask_url 双路径：两条链路行为分叉、测试面翻倍，且 selected_area 只支持一个矩形，用户多框与框笔混用仍须遮罩路径，否决；统一遮罩单路径。
- 框选保持可选中拖动调大小的「活框」：与统一栅格化遮罩的编辑模型冲突，需额外一套选中态交互，否决；框落笔固化，修改靠橡皮擦与撤销。
- 进入编辑态自动缩放居中源图卡：拍摄板时被认为会打断用户既有的画布视角记忆，否决；视角不动，用户自行滚轮缩放。
- 输出用接口默认 webp：接口输入不支持 webp，webp 结果卡无法二次擦除，否决；输出 png。
- 进入编辑态即建草稿卡加连线（高清放大形态）：发送前没有可落卡的产物，会留下空草稿，否决；发送时建卡，同 ADR-0093。
- 编辑态底部保留参考截图的 PRO/比例/2K/张数参数栏：接口无对应参数，做没有功能的 UI 与 ADR-0093 口径相悖，否决。
- 我们后端直连火山 MediaKit：同 ADR-0092 结论，自管凭证、绕开网关计费护栏、与既有链路分裂，否决。

## Consequences

- 上线前置条件在网关侧：网关新增 erase-image 同步工具（对客模型名建议 mediakit-erase-image），本期 model_price 配 0，复用已配置的 MediaKit 渠道与 API Key；网关未配置时调用以 400 失败，产品侧呈现为任务失败。网关配置单另行建立（对标高清放大的 IKGOKL）。
- 遮罩图必须与源图同分辨率，前端须按源图自然分辨率而非卡片显示尺寸栅格化；遮罩复用资产上传链路会产生一张中间素材，其归属与清理由实现工单明确。
- 结果图 URL 仅 24 小时有效，执行侧必须在响应后立即下载并落入对象存储（同 ADR-0092）。
- 计费粒度限制同 ADR-0092：网关按模型名按次计费，后续计费工单需先解决分工具计价。
- 涂抹编辑设施（画笔/框选/橡皮/棋盘格/撤销重做）仓内无任何先例，为本需求最大工作量项，需自研；扩图模式的自研拖拽框（ADR-0093）是模式化交互的参考而非可复用组件。
