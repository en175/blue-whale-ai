# 画布卡片工具栏撤除生成类按钮：派生统一走连线，原地重跑统一走点卡片

画布卡片工具栏上的「重新编辑」「生成图片」「生成视频」三个入口全部撤除（2026-09-20，两轮 8 问拍板）。三条路径各自都已存在等价入口，且等价入口更贴合画布心智。其一，视频卡「生成视频」与「重新编辑」在成品卡上调用同一个函数 `openVideoDraftDialog(原卡)`，判定门也相同（有生成记录的成品卡），代码注释自认「与『重新编辑』一致」，而该按钮在视频卡上的悬停文案「带入图片，打开视频对话框」与行为不符。其二，图像卡「生成图片」「生成视频」与拖线落空白后弹出的「连线类型菜单」共用同一套原语（`createXxxDraftCard` + `addCanvasEdge` + `openXxxDraftDialog`），按钮只是替用户完成拖线这一下，面板回填的参数同源。其三，「重新编辑」与点卡片开面板同为 `openMediaDraftDialog`：选中成品卡时 `onNodeClick` 自动打开绑定生成面板并带回历史提示词、参数与参考，关掉后再点同一张卡照常重开。撤除后的终态：图像卡成品卡为「高清 ▾ / 详情 / 下载 / @」，视频卡成品卡为「HD 高清（待实施，见 [ADR-0105](0105-video-hd-enhance-minimal-panel.md)）/ 智能去字幕 ▾ / 音视频分离 / 详情 / 下载 / @」，音频卡为「详情 / 下载」；上传素材卡本就不出「重新编辑」，其「生成图片」「生成视频」同样撤除。生成入口收口到连线，是为了让「以某张卡为参考新建生成目标」在界面上只有一个含义：拉一条线（连线即参考关系，[IKDMQR 契约](../specs/2026-09-07-ikdmqr-image-media-reference-contract.md)）。

## Considered Options

- 图像卡两个生成按钮合并为一个「继续生成 ▾」下拉（形态对齐「高清 ▾」「智能去字幕 ▾」家族）：只减一个按钮位，仍是同一动作的第二条路径，与「一个动作一个入口」的减法目标不合，否决。
- 给卡片两侧的「+」补一句悬停提示（如「拖出连线：连到别的卡片，或拖到空白新建生成卡」）补偿可发现性：画布交互自明，「+」本身就是钩子，产品拍板不补，否决。
- 保留「重新编辑」按钮：与点卡片调用同一函数，且只在单选时出现，重复，否决。
- 反向处理，删「重新编辑」保留视频卡「生成视频」：与图片卡、音频卡、高清卡的语义不对称（那三处都靠「重新编辑」回面板），且该按钮名字与视频卡上的实际行为不符，否决。
- 「高清 ▾」菜单的高清项同为派生却保留按钮形态：它有专属参数面板与链式放大语义，拖线无法表达，保留（本次范围外）。

## Consequences

- 「重新编辑」从按钮名转为行为概念名，指「选中成品卡自动打开绑定生成面板」；CONTEXT.md 各词条的位置与入口描述随之改写。ADR-0092、0101、0105 中的历史表述不改，术语延续。
- [ADR-0105](0105-video-hd-enhance-minimal-panel.md) 中「HD 入口排位在重新编辑之后、智能去字幕 ▾ 之前」的表述由本 ADR 取代：HD 高清成为视频卡工具栏首位。
- 「以某张卡为参考派生新卡」只剩连线一条常规路径（生成面板附件操作条的「+ 参考」为兜底，用于在已开面板内补参考）。拖线落空白建卡全链路的集成测试覆盖缺口由可选变为高优先，现存草稿测试只覆盖侧栏入口建卡路径。
- 画布三卡（图像、视频、音频）生成入口口径统一：工具栏只承载「处理本卡」的工具类操作与「详情 / 下载 / @」通用操作；派生走连线，原地重跑走点卡片。
