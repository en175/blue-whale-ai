# AgentChatPanel 全高覆盖式抽屉与拖拽调宽

AgentChatPanel（Canvas 右侧 Agent 对话面板）从悬浮卡片改为覆盖 Canvas 之上的全高非模态抽屉：打开时隐藏 CanvasHeader 的 Agent 入口（沿用面板打开即隐藏缩放控件的同款先例），仅面板内关闭按钮可关闭——无遮罩、不支持点击画布或 Esc 关闭、不锁定焦点。宽度默认 468px，User 可拖拽抽屉左缘在 400px ~ min(720px, 50vw) 间实时调宽，双击手柄复位默认宽；宽度按 User 持久化（localStorage，全局一份不按 Project 分），展开状态不持久化（进入 Canvas 与切换 Project 默认收起）。极窄视口（50vw < 400px）时下限让位于可用宽度（视口宽 − 左侧工具栏约 60px）。交互经一次性原型三变体评审后选定「隐形热区」方案：6px 隐形热区、悬停显示 2px 高亮线、ew-resize 光标。

## Considered Options

- **推开式抽屉（画布变窄）**：否决——画布重排会干扰创作中的视口与节点定位；现有停靠卡片本就是覆盖关系，改抽屉只改形态不改布局关系。
- **模态抽屉（遮罩 + Esc + 点击外部关闭）**：否决——画布是常态交互工作区，点击是高频操作，误触关闭成本高；非模态也意味着不做焦点锁定。
- **入口按钮保持 toggle**：否决——面板打开时入口图标冗余（面板内已有关闭按钮）；隐藏与既有「面板打开即隐藏缩放控件」行为一致。
- **显性握把 / 宽度档位（原型变体 B/C）**：否决——握把常驻产生视觉噪音；档位按钮占头部高度，自由拖拽已覆盖宽度需求。
- **移除浮动模式**：否决——超出本次范围；浮动模式（拖 header 移动位置、360px 宽）原样保留，拖拽调宽只作用于抽屉形态。

## Consequences

- 交互基准为一次性原型：路由 `/prototype/agent-drawer`，分支 `feature/面板抽屉化交互原型`；正式实现落地后删除原型代码，主分支只保留验证后的决策。
- 抽屉容器与拖拽手柄为新增模式（仓内无 antd/Tailwind，也无既有 Drawer/resize 先例），样式走 CSS Modules + 全局 CSS 变量。
- 宽度持久化是新增纯前端本地状态，与服务端无关。
