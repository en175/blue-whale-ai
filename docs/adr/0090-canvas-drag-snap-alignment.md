# 画布卡片拖拽对齐吸附：拖拽中实时修正，阈值按屏幕像素

画布卡片拖拽的对齐吸附（六种中心/边缘对齐关系 + 对齐线）在拖拽过程中实时修正位置，而非松手时贴合；吸附触发距离按屏幕像素定义（8px），换算为画布坐标时除以当前缩放，保证任何缩放级别手感一致。对齐参考物为未被拖动的卡片与组框外边缘，但组框把手拖整组自身不吸附（组框拖拽是独立交互路径，首版不覆盖）；非拖拽的自动落位（V 键落卡、粘贴、复制偏移）不吸附；吸附只是本次拖拽的位置修正，不产生独立的撤销步骤。启停通道有两条：左下角吸附开关（默认开、跨会话记忆）与按住修饰键单次拖拽临时跳过。

## Considered Options

- 松手时贴合最近对齐线：实现更简单，但拖拽中无反馈，与「所见即所得」的磁吸预期不符，否决。
- 阈值按画布坐标定义：缩放后触发距离随之变化（放大时吸不住、缩小时吸得太远），手感不一致，否决。
- 网格吸附（snapToGrid）：画布无背景网格且卡片尺寸不一，网格对齐意义弱，否决。
- 对齐线只画两块投影的重叠区间（两端小外延）：两卡错开时缩成间隙内的短线段，指向性差、远看不显（09-17 人工回归反馈，否决）；改为贯穿主拖卡与对齐参考物投影联合跨度的长线，两端贴合两块外侧边缘。
