# 图片裁切为「高清 ▾」菜单前端本地执行工具：模式化裁框、五比例锁定加自由、确认即建成品卡、产出跟随源图格式

画布图片素材卡工具条「高清 ▾」下拉菜单新增「裁切」项，位于「扩图」与「擦除」之间，无置灰门槛（裁切无 AI 参与，webp、gif 也可裁，生成中、草稿、失败卡不显示该工具栏）。裁切在浏览器端用离屏 canvas 按原图自然分辨率执行，产物经既有资产上传链路入库：不新增任务类型、不进 worker、无网关配置、零 API 成本，即时出图。点「裁切」进入裁切模式：原图卡上出现只许向内收的裁切框（4 边+4 角，始终完整落在内容区内，框内拖动整体平移并钳制），裁切面板跟随浮出，进入时默认自由比例、框为全幅，同时关闭五个生成面板（同擦除口径）。面板含六个比例选项（1:1、4:3、3:4、16:9、9:16、自由）与确认、取消；选中默认比例即锁定该比例，初始框为内容区内最大内接该比例矩形、居中，边手柄禁用并视觉弱化，角手柄以对角为锚等比缩放；自由比例下拖边单边、拖角自由、按住 Shift 临时锁比例（同扩图手势）。结果短边不小于自然分辨率 64 像素。点确认后立即在源卡右侧创建「裁切」成品卡（无草稿、无生成中过渡）并拉纯视觉来源连线，源卡保留、新卡不抢选中；产出格式跟随源图（JPEG 源出 JPEG 质量约 0.92、PNG 源出 PNG、判不出时 PNG 兜底）。确认、取消、Esc、点画布空白或框外暗区四路退出，确认前退出不留任何痕迹；编辑期间允许画布缩放平移（裁切框渲染期跟随内容区，同扩图扩展框机制），点其他卡等同点外退出。

## Considered Options

- 走后端任务链路（同高清、擦除、扩图家族，新增任务类型与 worker 处理器）：为无 AI 的确定性像素操作多付一轮排队、服务器成本与网关配置，且网关计费语义无从谈起，否决；前端本地执行。
- 产出恒 PNG（与擦除遮罩上传链路完全同构、代码最省）：照片类 JPEG 重编码为 PNG 会膨胀数倍，拖慢上传并占用资产存储，否决；改为跟随源图格式，仅判不出格式时 PNG 兜底。
- 直接替换原图卡内容（更轻的「就地裁切」）：破坏原素材、不可逆，与家族「源卡保留+结果卡+来源线」统一模式分裂，否决；新建裁切卡。
- 裁切框固定不可平移（同扩图框永远包住原图的定式）：裁切的本质是选区域，无平移则只能从边角收，无法把框挪到目标区域，否决；框内拖动平移。
- 锁定比例下拖边联动对边保持比例：联动方向有歧义（拖左右边时上下哪边动），业界裁切工具通行做法是禁用边手柄，否决联动。

## Consequences

- 裁切是「高清 ▾」家族中唯一不经任务链路的工具：无网关前置条件、无计费语义、无错误码契约，工单可纯前端交付，改动严格限定 `web/**`。
- 菜单项数组与扩图（IKGOQ0 整包，已完成未发布）存在一处合并点：裁切基于当前 release 开工，扩图发布时对 `ImageQualityMenu` 宿主数组机械合并，组件本身不动。
- 输出为 canvas 重编码：JPEG 有一代编码损失（质量约 0.92），PNG 无损但体积可能大于源文件；多次连环裁切同格式时损失逐代累积，属可接受边界。
- 64 像素下限以原图自然分辨率为口径，与画布缩放和显示尺寸无关；裁切结果分辨率只由源图与框决定，恒不放大。
- 裁切卡是成品卡，可再次进入裁切、擦除、扩图、高清放大，家族工具在结果侧闭环。
