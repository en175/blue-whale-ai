# 样片卡与成片卡：角标归位画面内右上角，链式动作最终口径

IKIZPZ 实施把样片/成片角标落在了卡外标题行（浅蓝/浅紫胶囊），与 IKIZBV 评审原型定稿（`df70f9aa2`：视频画面内右上角深色玻璃胶囊）不符；过期样片卡标题行的「重新生成样片」按钮与「重新编辑面板重发」路径重复。2026-09-29 四轮讨论拍板并经 v3 高保真原型（12 场景）验收：角标归位画面内、样片卡只留「生成 1080P 成片」一个链式动作、成片失败卡的重试与普通失败卡完全同形（2026-09-29，grill-with-docs 四轮 + 原型验收确认）。

**样片卡**。角标还原原型定稿：视频画面内右上角深色玻璃胶囊，成功态「样片 480P · 截止 MM-DD HH:mm」（信息蓝点缀），过期转警告橙「样片 480P · 已过期」；仅成功态显示（生成中靠自动命名「样片生成中」识别，失败卡不挂角标）；「已用 N 积分」不进角标（历史记录与详情已有）。标题行右侧的「生成 1080P 成片」是卡上唯一链式动作；移除「重新生成样片」按钮（与重新编辑面板重发重复），过期或缺可信截止时间后卡上不再提供任何动作——置灰的「生成 1080P 成片」一并隐藏，死按钮没有行动价值，过期信息由角标表达；恢复靠点卡重新编辑后从面板重发（两阶段重新编辑新建卡）。

**成片卡**。除画面内右上角深色玻璃角标「成片 1080P」（紫色文字点缀）外保持 100% 普通视频卡，不挂任何功能专属动作。生成失败时失败区提供与普通失败卡完全同形的「重试」按钮（不带积分，报价经悬停提示传达），但行为不是重发成片——同一张样片不可再次发起成片（`uk_generation_jobs__source_sample_job_id` 裸唯一索引连失败终态行一起占位、金标 G08、父规格用户故事 21 不复用未证实 Draft ID，失败那一刻上游状态不可信，重发有重复计费与双花风险）——而是按原输入新建样片卡，悬停提示说明「样片完成后再单独发起成片（另行计费）」。

**计费口径**。维持现状：成片失败的预扣全额退回，恢复路径的新样片按提交时现价独立报价计费。「成片失败补偿策略」（失败后重试样片是否免费/减价）是独立的商业策略题，另立工单评估，不在本次范围。

## Considered Options

- **保留标题行「重新生成样片」（v2.2 动作归属原案）**：链式动作全挂样片卡标题行（样片卡=控制面）。验收认定其与面板重发是重复设计；正常态本不显示、仅过期态出现的入口，用户也可经重新编辑达成，否决。
- **成片失败复用标准重试行为（重发同一样片的成片）**：撞裸唯一索引（1057 finalize_already_attempted），且违反金标 G08「一张样片首版至多一次已发往上游的成片尝试」与用户故事 21，否决。
- **「重试 = 新样片 + 自动接续成片」一键全链**：违反样片模式核心规则（成片须用户显式发起、两阶段独立报价确认），单次点击承诺两笔扣费不可接受，否决。
- **重试按钮带积分（「重试 · N 积分」）**：曾拍板采用，原型验收时改判——普通失败卡的重试不显示积分，成片失败卡应对齐同形；报价由悬停提示承担，否决（本 ADR 记录的是最终口径）。
- **过期态保留置灰「生成 1080P 成片」**：靠 tooltip 传达「期限已过」，但它是永久死按钮，过期信息角标已表达，否决。
- **重新生成成片按钮（v2 原型有、实现未做）**：成片到达终态后样片卡不再显示任何按钮为既有实现口径，本次确认不补；如未来需要另开决策。

## Consequences

- IKIZBV 原型（`df70f9aa2`）头注 v2.2「动作归属」条被本 ADR 部分取代：链式动作不再包含标题行「重新生成样片」；成片失败重试保留在失败卡上但形态与普通失败卡统一、行为维持「新建样片」不变。角标的「画面内右上角深色玻璃」定稿（v2.1）经本次还原重新生效。
- [CONTEXT.md](../CONTEXT.md) 新增「样片卡」「成片卡」两条词汇，固化卡形态与动作归属；「样片」「成片」「两阶段重新编辑新建卡」等既有词条不变。
- v3 确认原型为本次决策的原始依据：单文件 12 场景，归档于一次性分支 `prototype/IKIZPZ-样片卡修复确认`（`web/prototypes/seedance-sample-card-v3.prototype.html`），不入主线。
- 实现影响面：MediaNode 的样片/成片徽标从标题行迁入内容卡画面内（新增画面内角标渲染，可参照透明背景卡的 `.transparentTag` 先例）、标题行 regenerate CTA 整段移除、过期/缺截止 phase 的 finalize CTA 不再渲染、成片失败区按钮文案与悬停提示调整；样片/成片徽标与 regenerate CTA 相关单测改写。后端零改动（报价与提交接口保留：失败卡重试仍走重新生成样片链路）。
- 缺可信截止时间的降级展示视同过期（角标无法显示截止时按「已过期」口径处理），不新增第三态。
