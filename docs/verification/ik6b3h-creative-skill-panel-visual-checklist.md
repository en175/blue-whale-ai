## 通用项（各断点均需核对）

### 面板框架与层级

- [ ] 面板接近全屏，外围约保留 32px 边距，无固定 1440×920 上限感（US2）
- [ ] 顶部三页签「我的技能 / 技能库 / 创建技能」齐全，顺序正确（US3）
- [ ] 默认进入「技能库」页签（US1）
- [ ] 固定头部 + 面板内滚动，滚动时头部不跟随内容滚动
- [ ] 遮罩层级正确：面板高于页面背景，背景不可交互

### 卡片视觉（技能库）

- [ ] 卡片样式（封面、圆角、阴影、密度）整体协调、无破版
- [ ] 卡片间距（行列 gap）均匀一致
- [ ] 作者固定显示「@Blue Whale」（US17）
- [ ] 官方卡片不可点击、无省略号菜单（US18）
- [ ] 简介截断时悬停提示完整公开简介（US19）
- [ ] 卡片操作仅「直接使用」「添加 / 已添加」两类（US20）
- [ ] 「已添加」为不可点击态，视觉与「添加」可区分（US22）
- [ ] 分类「全部 / 影视 / 营销 / 其他」与排序「精选 / 最多使用 / 最新发布」控件齐全（US9、US10）
- [ ] 使用量数字展示位置与样式清晰可读（US12）

### 我的技能

- [ ] 「官方 / 个人」来源标记可见且可区分（US26）
- [ ] 无搜索、筛选、排序控件（US27）
- [ ] 个人技能封面为名称驱动的稳定渐变与图标（US49）

### 创建技能

- [ ] 「编写 SKILL.md / 上传 SKILL.md」模式切换控件清晰可见（US41）
