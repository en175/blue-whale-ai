# Prompt 预览与文本节点重构决策记录

## 时间

2026-09-06

## 背景与状态

关联工单：IKDL9U「生成卡设计反馈澄清报告：当前形态不可用，需全面梳理与重构」。
本记录随 grill-with-docs 讨论更新；主链路与 Q4–Q14 已逐项获得用户确认，待最后核对整体共同理解，不是实施授权。
目标是将 Agent 方案收敛为 Prompt 文本，让用户通过 Canvas 连线组织创作。

## 已确认的主链路

1. 用户在 Agent 面板用自然语言表达需求，Agent 根据资料、回复与上下文整理最终 Prompt，并展示预览。
2. 不满意时继续让 Agent 修改；满意后由用户手动点击“应用”。
3. 应用将 Prompt 创建为 Canvas 中的普通文本节点，不自动生成媒体。
4. 用户自行连至生图或生视频节点；连接的文本作为文本附件提供生成上下文。

## 已确认的行为决定

### Q4：附件与目标提示词

- 文本附件提供背景，目标节点提示词表达本次任务，两者共同生效；附件不覆盖目标提示词。
- 目标未填写提示词时，允许仅使用文本附件生成，不要求用户重复填写 Agent 已整理的 Prompt。
- “文本附件”是产品输入语义，具体如何传给模型留待技术设计确定。

### Q5：编辑与生成快照

- 每次生成读取文本节点的当前正文，并保存本次使用的文本快照。
- 同一文本节点可供不同生成节点使用；后续生成读取修改后的正文。
- 已完成的生成结果及其快照保持原样；修改文本不会自动重新生成。

### Q6：预览应用与版本

- 新版 Prompt 预览应用时新增文本节点，保留旧节点及其连线。
- 同一预览重复点击“应用”，定位首次创建的节点，不重复创建。
- Agent 后续修改预览不自动更新已应用的文本节点。

### Q7：多个文本附件

- 一个生图或生视频节点可以接收多个文本附件。
- 目标节点展示附件列表，默认按连入顺序排列，用户可以调整顺序。
- 同一文本节点对同一目标不重复添加。

### Q8：素材独立输入

- Agent 写 Prompt 时参考过的图片，不随 Prompt 文本节点自动进入生成输入。
- 文本连线仅提供文本；需要图片参与生成时，用户将图片节点直接连接至目标生成节点。
- 画布连线应能表达实际输入，避免文本节点隐式携带图片素材。

### Q9：断开、删除与重新应用

- 断开连线或删除文本节点后，下一次生成不再使用该文本附件。
- 已提交任务与历史结果继续保留原文本快照。
- 删除已应用的文本节点后，再次应用同一预览会重新创建节点，不恢复旧连线。

### Q10：旧画布生成卡迁移

- 旧画布生成卡转换为普通文本节点，正文采用实际参与生成的“提示词”，保留标题与位置。
- 旧“画面描述”保留在可查阅的历史记录中，包含用户的编辑，避免迁移丢失内容。
- 新文本节点不再同时展示两份可编辑正文。

### Q11：文本编辑

- 文本节点保留标题和一份可直接编辑的正文，支持换行、复制与粘贴，不再拆分画面和提示词。
- 长内容可以折叠预览、展开编辑。
- 超出限制时明确提示，不得静默截断；具体限制数值在技术设计中根据端到端能力确定。

### Q12：再次交给 Agent

- 统一使用“添加到对话”入口，向 Agent 提供操作当时文本节点的正文快照。
- 不再仅发送原始卡片版本指针而遗漏画布上的编辑。
- Agent 修改后产出新的 Prompt 预览；用户再次应用才创建新节点，不自动覆盖原节点。

### Q13：生成操作

- 用户选中目标生图或生视频节点，在对应生成面板中查看附件、填写补充提示词、设置模型参数。
- 用户点击“生成”才执行；建立连线和修改文本都不自动执行。
- 本轮以单个目标节点为执行单位，不引入整条创作流程的自动执行。

### Q14：多个 Prompt 的应用

- Agent 一次产出多个 Prompt 时，每条独立预览、独立应用，各自成为一个文本节点。
- 本轮不增加“整组应用”；用户决定应用哪些 Prompt，以及后续如何连接。

## 已确认行为的验收场景（待实现后验证）

1. Agent 修改预览后，用户应用得到对应文本节点；同一预览重复应用定位原节点，新预览应用创建新节点。
2. 多个文本节点连到同一生图或生视频目标后，附件可排序且按来源节点去重；仅有附件时也能提交生成，未直接连入的图片不被自动加入。
3. 修改文本只影响后续生成；生成任务冻结当次正文，断开或删除节点不改写已提交任务与历史结果。
4. 画布编辑后的文本添加到对话时，Agent 收到当前正文快照；修改结果仍走新预览与手动应用，长文本不被静默截断。
5. 旧卡转换后标题、位置与提示词正文得到保留，旧画面描述及用户编辑可在历史记录中查阅。

## 技术设计待落实（不改变上述产品决定）

- 预览身份、应用记录与节点删除后的重新应用契约。
- 连线及附件顺序的持久化、当前正文读取与提交快照的一致性。
- 文本附件与目标提示词的供应商请求适配、长度限制与明确错误反馈。
- 旧画布卡和历史预览的兼容迁移，以及历史画面描述的查阅入口。
- Agent 服务与本仓前后端的接口边界、实施拆分与上述验收覆盖。
