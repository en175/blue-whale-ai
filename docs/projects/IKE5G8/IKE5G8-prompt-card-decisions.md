# Prompt 方案卡画布承接讨论记录

## 时间

2026-09-10

## 背景与目标

关联需求：[IKE5G8《【Agent】生成卡应用画布承接与dock引用》](https://e.gitee.com/hangzhou-xuanfu_1/projects/883843/requirements/table?issue=IKE5G8)。

用户描述的流程为：在右侧 Agent 对话中提供素材参考，获得 Prompt 方案，手动应用为 Canvas 富文本节点，再通过连线或 Dock 附件参与媒体生成。本记录只保存本次讨论已确认的决定与待讨论边界，不代表完整规格已确认或产品已实现。

## 已确认决定

### D1：应用方案时补入引用素材卡

用户已确认：当 Agent 方案引用属于当前用户、但尚未出现在当前画布的素材时，点击应用方案应同时将这些素材放入画布，创建对应素材卡。素材已经在当前画布上时复用已有素材卡，不重复创建。

场景：方案引用素材 A、B，当前画布已有 A、没有 B。应用后保留并复用 A 的素材卡，同时创建 B 的素材卡，使后续创作可使用画布上可见的素材。

### D2：应用准备内容，引用时建立生成输入连线

用户已确认：应用方案时创建方案卡、补齐素材卡，正文标签显式绑定素材；此时不创建生成目标。用户把方案卡连到生成目标，或在该目标的 Dock 中引用方案卡时，将绑定素材分别连到同一目标并同步参考清单，已有连线不重复创建。只有用户点击生成才执行。

场景：方案绑定 A、B。应用后画布具备方案卡与 A、B 素材卡；用户将方案卡用于目标 T 时，形成方案卡到 T、A 到 T、B 到 T 的输入关系。

## 待讨论边界

- 方案卡已经用于生成目标后，正文和素材绑定修改如何影响目标当前草稿；已提交任务保持其历史输入。
- 移除方案附件时，随方案加入且可能被其他输入共用的素材连线如何处理。
- 同一素材在当前画布已有多张卡时的复用选择规则。
- 素材已删除或无法访问时的应用失败与恢复行为。

## 关联与验证

- IKE5G8 V1.1 要求富文本正文与显式素材绑定完整保留；本次 D1 补充其未明确的“素材尚未进入当前画布”场景。
- IKDL9U 的普通文本附件不隐式携带媒体。D2 中方案素材以正文显式绑定表达，并在用于目标时形成直接媒体输入连线；不据此恢复旧 SceneCard 或第二份可写正文。
- 后续验收应覆盖：未上画布的素材被补入、已有素材卡被复用、连线与 Dock 引用产生一致的完整输入、已有连线不重复、应用与连接不触发生成。本次仅记录产品决定，未执行产品测试。
