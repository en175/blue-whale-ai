## 操作指南

1. **采用电影化视角**：以视觉叙事、信息缺口和持续不安感为重点编写剧本。避免通用散文式描述。
2. **构建悬疑结构**：
   - 以**正常开场**开始：将角色置于熟悉场景（如宿舍、办公室、电梯）。
   - 引入**异常细节**：使用微妙线索（如延迟的倒影、不可能的消息、画面中的多余人物）。
   - **升级紧张感**：迫使角色尝试逻辑解释，然后系统性地推翻这些解释。
   - **运用误导**：确保真相在最终逻辑反转前被隐藏。
   - **呈现余韵结局**：不要过度解释；以最后一个令人不安的线索或画面收尾。
3. **格式要求**：
   - 根据用户要求，使用提供的结构编写故事概念、制作剧本或故事板剧本。
   - 剧本需定义：镜头、视觉、动作、镜头语言、音效和AI视频提示。
4. **设计规则**：
   - **氛围**：使用关键词如"弱光"、"冷色调照明"、"压迫性构图"、"微弱呼吸声"和"监控画面"。
   - **反转**：必须有伏笔、逻辑自洽且情感冲击力强。
   - **角色**：保持小规模阵容（2-3个角色）以维持焦点和信息缺口。

## 适用场景

- **适用场景**：创作悬疑反转、心理惊悚、密室谜题、都市传说、规则类恐怖或单一场景高压情境。
- **不适用场景**：生成血腥画面、仅依赖跳吓的内容、非电影化散文小说，或涉及外部网页浏览及实时数据获取的内容。

## 示例

**示例触发词**："创作一个关于电梯停在不存在楼层的短片惊悚剧本。"

**回复结构**：
- **概念**：定义钩子、异常现象和最终反转。
- **剧本**：遵循必填字段（视觉、音效、AI提示等），确保输出可直接用于视觉制作。
