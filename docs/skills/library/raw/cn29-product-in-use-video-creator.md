# 产品使用场景视频创作者

本技能提供了一种结构化的方法论，用于设计“产品使用场景”广告视频。它以高端科技生活方式商业广告模式为蓝本，在原生用户交互与高端美学吸引力之间取得平衡。

## 核心创作原则

### 1. 叙事结构：“微冒险与愉悦”框架
避免枯燥的功能演示。相反，应将叙事构建为一个简短、自成一体的旅程，包含清晰的设定、探索阶段和情感回报。

*   **钩子：** 在一个有趣的环境中设定一个特定的约束或目标（例如，“我们只有一小时时间，你能帮我们规划一次游览吗？”）。这立即为产品的使用提供了合理性。
*   **探索：** 实时展示产品如何促进行动。用户保持活跃——行走、观察和互动——而产品则提供即时的情境价值。
*   **趣味回报：** 包含一个 relatable 的人类时刻，例如产品温和地纠正一个轻微误解或错误。这能建立情感联系，并展示实用性，而不会显得说教。
*   **高端结尾：** 以一个干净的产品镜头、一个生活方式标签和一个清晰的品牌信息作为结尾，总结产品的身份（例如，“一个真正的人工智能伴侣”）。

### 2. 视觉风格与摄影机规格
实现高端、柔和、超清晰的商业美学：
*   **A机规格：** **ARRI Alexa Mini LF** 搭配 **Cooke S7/i 全画幅定焦镜头**。这种组合能呈现自然的肤色、平滑的高光过渡以及突出产品细节的柔和背景。
*   **色彩配置：** Rec.709 基础，搭配自定义生活方式 LUT。温暖、诱人的中间色调，与科技屏幕冷峻、干净的白色相平衡。低对比度，色彩饱和度高且真实。

### 3. 电影摄影
*   **摄影机运动：** 使用广角跟拍镜头跟随角色穿越空间。利用低角度视角，使建筑和产品都显得宏伟。
*   **灯光：** 使用漫射、柔和的定向主光来模拟自然建筑环境光。微妙的轮廓光将角色和设备与黑暗背景区分开来。

### 4. 剪辑节奏与视听同步
剪辑节奏应与角色的对话节奏以及产品界面的自然速度相匹配。

*   **对话驱动剪辑：** 使视频转场与对话中的自然停顿或过渡同步。
*   **动作匹配剪辑：** 在剪辑点保持连续的运动（例如，从中景行走镜头切换到设备特写镜头，同时保持向前的动势一致）。
*   **动态UI叠加同步：** 在用户触摸设备或语音助手说话时，精确渲染UI交互或屏幕叠加，以增强技术的响应感。

### 5. 对话式文案与画外音
对话必须听起来自然、随意，以建立信任和真实感。

*   **自然的人类措辞：** 使用口语化的缩略形式和随意的句子结构（例如，“所以我们只有……”、“我们开始吧”、“是不是很迷人？”）。在口语对话中避免正式的技术术语。
*   **主动式助手角色：** 如果演示AI或智能助手，赋予其冷静、清晰、乐于助人的语气。助手应根据视觉或空间上下文预测用户需求，使互动感觉像是协作而非纯粹的交易。

### 脚本示例

| 结构 | 视觉 | 对话/声音 |
|---|---|---|
| **微冒险设定。** | 两位游客进入一个现代博物馆庭院，距离闭馆仅剩一小时。其中一人举起一个智能助手设备对准一座雕塑。 | 游客A：“我们只有一小时。你能让这个地方变得有意义吗？” **背景音乐：轻快、好奇的律动。** |
| **产品激活。** | 过肩特写镜头显示助手识别艺术品并构建步行路线。 | 助手声音：“从北翼开始。它将艺术家的早期素描与你面前的最终作品联系起来。” |
| **探索。** | 低角度跟拍他们穿过几何形状的走廊。设备识别细节，翻译墙上的标签，并建议下一个展厅，而无需他们停下脚步。 | 游客B：“所以它就像一个握在手里的导游。” 助手声音：“而且不会走得太慢。” |
| **趣味回报。** | 游客A自信地误认一座雕塑为鸟。助手温和地叠加文字“鲸鱼椎骨研究”。两人大笑并凑近观看。 | 助手声音：“接近了。实际上它的灵感来自鲸鱼。” 游客A：“我在精神上很接近。” |
| **高端结尾。** | 咖啡馆桌上，产品干净地置于门票和咖啡旁。博物馆的灯光反射在屏幕上。 | **背景音乐柔和收尾。** 行动号召：“LumaGo。一个真正的人工智能伴侣，陪伴你好奇心的每一次旅程。” |
