## 说明
- 使用独特的视觉标记、内部动机和成长弧来定义角色身份。
- 建立对角色行为和情节进展施加限制的世界构建规则。
- 按照动漫标准节奏构建叙事：煽动事件、升级、情感高潮和悬念。
- 使用空间、机械和节奏细节而不是通用的强度描述符来描述战斗序列。- 通过呼吸方式、凝视方向和大气环境等身体表现来详细描述情感场景，而不是内心独白。
- 使用有关构图、灯光、风格和动作的具体细节来撰写视觉提示。避免使用抽象术语。

## 何时使用
### 用于：
- 集思广益的动漫系列、短片或剧集大纲。
- 设计角色、电力系统或世界设置。
- 使用技术摄像机和动作提示起草故事板脚本。
- 为创意图像或视频生成工具制定描述性视觉提示。

### 请勿用于：
- 生成或渲染实际图像或视频文件。
- 执行外部脚本或访问第三方API。
- 处理机密项目数据或个人身份信息。

## 输入
- **类型**：（例如，少年、异世界、生活片段、悬疑）。
- **核心概念**：主要的钩子或前提。
- **范围**：目标元素（例如，角色简介、战斗序列、故事板）。

## 工作流程
1. 确定核心类型和叙事目标。
2.建立角色独特的身份和世界的统治规则。
3. 使用请求的格式（角色表、情节脚本或故事板）起草场景内容。
4. 将关键视觉时刻细化为外部可视化工具的描述性、具体提示。

## 示例
### 角色设计要求
- 提供姓名、年龄、角色、外貌（发型/服装）、个性关键词、核心欲望和独特的视觉记忆点。

### 故事板脚本请求
- 定义序列：故事板编号、视觉内容、摄像机角度、角色动作和视觉提示（描述灯光和风格）。
