## 说明
1. 保持严格的第一人称视角 (POV)，其中摄像机代表主角的眼睛。
2. 将可见的身体元素限制为手、武器、工具、车辆控制装置和直接环境交互点。请勿描绘主角的全身或面部。
3. 将物理反馈融入到每个关键动作中，例如撞击造成的相机抖动、运动模糊和生理压力的视觉指标。
4. 在主角与关键物体（出口、武器、工具）互动之前确定它们的空间存在。5. 将提示结构组织为五个节拍：【开场】、【触发】、【互动】、【升级】、【收益】。
6. 通过对目标的明确确认来结束序列，例如成功逃脱、区域清理或撤离。

## 何时使用
- **适用：** 为第一人称动作序列、怪物追逐、战斗、垂直袭击或生存逃脱创建提示。
- **不适用：** 第三人称电影镜头、全身角色展示、对话驱动的戏剧、产品或时尚展示，以及没有身体互动的静态氛围场景。

## 输入
- **核心行动：** 描述主要目标或场景（例如，“逃离燃烧的建筑物”）。
- **持续时间：** 指定预期的运行时间或请求灵活的一次性节奏。

## 输出要求
- **标题和持续时间：** 提供描述性标题和预计运行时间。
- **五拍脚本：** 以规定的结构呈现序列。
- **镜头语言：** 指定第一人称、一次性的技术方法。
- **感官细节：** 明确描述身体感觉，例如“手握着冰冷的金属”或“有节奏、沉重的呼吸”。

## 示例
**示例1：地铁怪物大战**
- **开场：** 当怪物通过连接门进入时，视角在地铁地板上苏醒。
- **互动：** POV 双手砸碎消防斧柜，抓住斧头。
- **回报：** 主角清除威胁并对车厢进行最终扫描。

**示例 2：电梯井逃生**
- **开场：** 跑过走廊，身后有一个看不见的追击者。
- **互动：** 双手撬开电梯门并跳入竖井。
- **回报：** 滑下电缆并向上看，因为追赶者仍位于顶部。
