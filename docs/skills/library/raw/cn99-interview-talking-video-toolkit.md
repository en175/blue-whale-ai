## 说明
1. 在选择模块之前定义 IP 角色和内容语气（正式、温暖或深沉）。
2.施加强制负面约束：“僵化的表演、背诵状态、僵硬的目光接触、假笑、脸部修饰过度、画面抖动、背景凌乱、色彩过饱和、细节模糊”。
3. 设置摄像机角度和移动（模块 2）以优先考虑稳定、自然的通信。
4. 设计场景/灯光（模块 3）以匹配所选的 IP 氛围，同时确保扬声器仍然是主要焦点。5. 调整表情和手势（模块 4）以反映对话的预期情绪状态。
6. 选择不遮挡演讲者面部的文本/字幕布局（模块 5）。

## 何时使用
- 用于：规划个人品牌访谈或问答内容的创意方向、视觉语言和氛围一致性。
- 请勿用于：直接执行视频编辑、应用实时滤镜或自动化相机硬件/软件控制。

## 工作流程
1. **选择角色：** 从知识（极简）、生活（温馨）或精英（商务）风格中选择。
2. **对齐视觉效果：** 选择相应的灯光、透视和背景元素。
3. **协调节奏：** 确保摄像机移动（例如缓慢变焦、微妙的浮动）与语音节奏相辅相成，而不会分散注意力。
4. **最终审查：** 验证计划是否避免了约束中定义的所有禁止的反模式。

## 示例
### 示例 1：日常休闲采访
计划一次轻松的室内面试。使用温暖的家庭环境、自然柔和的光线和固定的眼睛水平摄像头。注重自然的聊天表情和互动反馈。避免字幕。

### 示例2：专业专家访谈
计划一次正式的行业采访。使用简约的背景、中性/稳定的灯光以及与眼睛齐平的固定摄像头。确保语气严谨，回答状态真诚、稳重。
