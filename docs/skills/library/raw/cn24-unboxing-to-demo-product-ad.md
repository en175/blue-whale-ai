## 说明

遵循以下指南，为开箱到演示的产品视频起草以转化为目标的脚本。

1. 使用统一的电商脚本格式：按时间分段的章节，包含定义的镜头（镜头类型、屏幕动作、对话/画外音/文字）。
2. 遵循节奏要求：开场（0-3秒）、中间（3-18秒）和结尾（18-25秒）。
3. 应用转化结构：包装展示 -> 包含价值证明 -> 首次触感印象 -> 即时使用 -> 结果收尾。
4. 确保中间部分突出产品使用，不要仅聚焦于包装。
5. 对结尾部分的所有元素（对话、画外音、文字、字幕、音效）应用结尾约束。

## 使用时机

### 适用场景
- 具有吸引人触感材料、配件或套装组件的产品。
- 需要演示设置或即时实用性的产品。
- 创建第一印象或“你得到什么”的内容。

### 不适用场景
- 纯数字产品。
- 大型机械或没有“盒内”开箱体验的物品。
- 目标是与物理产品实用性无关的品牌故事讲述的项目。

## 创意方向

- **钩子：** 从动作中间开始（撕开、打开、展开）。避免缓慢的徽标介绍。
- **触感焦点：** 使用特写镜头展示纹理、机制和表面（撕开、咔哒声、卡扣）。
- **自然主义：** 优先考虑真实反应和从开箱到使用的无缝过渡。
- **证明：** 在视频中点之前，在真实场景中展示产品。

## 结尾约束

- 不要使用平台操作的行动号召短语（例如，“立即点击”、“链接在简介中”、“上滑”、“立即购买”）。
- 结尾必须由品牌主导、产品主导或情感主导（例如，标语、利益总结或美感镜头）。

## 脚本框架

**第1节 - 开场（0:00 - 0:03）**
- 镜头1：开箱中的钩子。动作：双手已经在打开包装；产品/关键配件立即出现。

**第2节 - 中间（0:03 - 0:18）**
- 镜头2：包含价值布局。动作：俯视视角展示产品及所有包含物品。文字：以利益为重点的总结。
- 镜头3：触感印象。动作：材料或机制的特写。聚焦感官细节（声音/纹理）。
- 镜头4：即时演示。动作：产品在预期的真实场景中使用。

**第3节 - 结尾（0:18 - 0:25）**
- 镜头5：结果。动作：最终设置/完整状态。画外音/文字：有抱负的品牌或利益陈述。
