# 面无表情的广告制作技巧

这项技能为设计广告提供了创意原则，拒绝传统的高能量、大量行话营销，转而支持极简主义、冷漠幽默和高端电影风格。

## 1.叙事结构：荒诞极简主义
* **拒绝复杂的价值主张：** 避免列出百分比、奖励或技术术语。专注于一个极其简单的事实。
* **尴尬的互动：** 围绕有限空间（例如更衣室、候诊室）中的角色之间简单且略显奇怪的情况进行叙述。
* **重复作为钩子：** 以零情绪差异重复传达核心信息。幽默源自角色的严肃态度与产品的平凡本质之间的对比。

## 2. 相机语言和取景
* **静态、对称构图：** 使用锁定的宽主镜头，强调环境几何形状和角色间距。 
* **突然的关卡变化：** 通过让角色在静态框架内意外出现（例如，从障碍物后面突然出现），在视觉上引入幽默。
* **突然的特写镜头：** 直接从广角镜头剪切到人物脸部或产品本身的平面、极端特写镜头，以强调面无表情的交付。

## 3. 摄影、灯光和纹理
* **模拟复古调色板：** 采用温暖、低饱和度的木板、柔和的大地色调（棕褐色、赭石色）和单色装饰（例如青色储物柜、栗色夹克）。
* **喜怒无常、低调的照明：** 避免明亮的企业平面照明。使用柔和的定向光源（如台灯或单个顶灯）来创建电影深度和阴影。
* **高端材质质感：** 突出触觉元素——衣服的质感、哑光塑料卡片饰面和金属表面。

## 4. 编辑节奏：“反节奏”
* **在沉默中徘徊：** 在剪辑之前让尴尬的沉默产生紧张感。这样可以保留瞬间并让反应得以喘息。
* **节奏剪辑：** 在广角镜头和特写镜头之间按预期交替。避免快速或疯狂的削减；保持缓慢、有节奏的心跳。

## 5.文案写作和配音
* **极其简单：** 编写故意明显且缺乏营销废话的对话（例如，“这是一张信用卡”）。
* **平淡的台词：** 指导演员平淡地台词，不带兴奋或紧迫感。 
* **极简画外音：** 在最后使用平静、低音的画外音来温和地强化简单的信息。

# 广告脚本模板

始终按照以下结构输出脚本。

## 整体风格和视觉方向（必填）
以一段文字开头，说明广告类型和整体风格方向，内容包括：总时长、长宽比、视觉质感、调色板、灯光风格、拍摄设备/CGI水平、情感氛围和节奏。

## 逐个镜头时间线（必需，核心）
按时间段分解镜头。每个镜头都遵循以下结构：

`开始-结束秒|阶段标签（例如，设置/构建/重复/解决/Coda）`
 描述：镜头尺寸和摄像机角度（锁定广角主镜头/突然的极端特写——平面、正面；没有古怪的角度或鱼眼）+摄像机运动（仅静态保持——没有推入、平移、喜剧变焦或快速平移）+有限空间舞台和环境几何（更衣室、候诊室、电梯等——温暖的复古调色板、木板、柔和的土色调、单色口音）+触觉产品/纹理细节（哑光卡）饰面、织物编织、金属表面）+场景演变和过渡方法（广角和特写之间的节奏剪辑；保持对话后的沉默）+才艺表演（种族、外表、空白的严肃表���、平淡的严肃表达、零情感差异——严肃态度与平凡产品/情况的幽默）+对话/画外音（如果有的话——故意明显，没有营销术语；用相同的平淡语气重复核心信息）。

建议的拍摄阶段遵循**荒诞极简主义**和**反节奏**节奏——缓慢、刻意的节奏与尴尬的沉默；永远不要用镜头前的致谢或高能量的节拍来打破面无表情：
- **0–X |设置/挂钩**：在有限的空间内锁定、对称的宽主镜头。建立环境几何、角色间距和复古电影纹理（低饱和度温暖等级、喜怒无常的定向照明）。引入一个有点怪异但又接地气的场景——没有危机视觉特效，没有奇观；注意力来自于构图和安静的荒诞。
- **构建/扭曲**：突然剪切为脸部或产品的平面极端特写，以强调交付。角色可能会意外地出现在静态宽框架内（例如，从障碍物后面突然出现）。对话陈述了一种高度简化的产品事实，情感差异为零。
- **重复/音高**：宽主和突然特写之间的节奏交替。核心信息逐字或近乎逐字地重复——同样平淡的表达，同样严肃的表达。产品自然地出现在手中或框架中；绝不是英雄飞溅、慢动作爆发或功能列表。- **解决/释放**：返回宽主；对话结束后保持几秒钟——在剪辑之前让尴尬的沉默产生。最后平静、低沉的画外音轻轻地强化了单一的简单信息；品牌标志和可选口号锁定。语气保持优质和克制——没有喜剧刺痛、能量峰值或百分比/奖励声明。
- **尾声/最后**：最后一个突然的产品特写或不变的严肃表情；可选平单衬里。短暂保持沉默，然后切到黑色或结束卡。

## 音频/SFX/BGM（根据需要）
如果广告依赖于声音，请注意关键环境 SFX（例如，远处的 HVAC 嗡嗡声、储物柜锁、纸张拖曳、柔和的脚步声）和 BGM 风格（例如，最小的环境背景音乐、稀疏的复古合成器或没有音乐 - 最好是安静）。去掉喜剧的嘘声、刺痛和高能量的曲目；现实和安静使这片面无表情的土地。
