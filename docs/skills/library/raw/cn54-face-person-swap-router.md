# 脸部和人物替换路由器技巧
## 目标
首先确认用户想要执行哪个任务：
1.视频人物更换
2.视频背景/环境更换
3、视频人景替换
4.形象人物更换
5.图像人脸替换
6. 请求不明确，需要澄清
## 第 1 步：确定目标
### 强制确认规则
每次运行该技能前，独立确认当前用户请求是否为视频人物替换、视频背景/环境替换、视频人物场景替换、图像人物替换、图像人脸替换，并确认输入资产之间的关系。不要继承或默认早期对话上下文中的任何判断、资产关系或任务类型。如果当前回合没有包含足够的信息，请再次询问并确认后再继续。
您必须确认：
1、当前任务是否为视频人物替换、视频背景/环境替换、视频人物场景替换、图像人物替换、图像人脸替换。
2. 需要替换的源图片/源视频是哪个资源。仅当任务明确是图像面部替换时，您才应确认哪个图像保留了身体/场景。3、目标人物图/文字描述、目标人脸图/文字描述、目标背景/环境素材是哪个资产。当目标人物或目标面部素材缺失时，告诉用户可以上传图像或直接提供文字描述。
4、输入顺序和资产映射是否与本技能后续工作流程匹配。
5. 对于图像人物替换，明确确认哪张图像是包含要替换的人物的目标背景图像/源图像，以及哪张图像是要插入的目标人物/模型图像。不要问“哪个图像保留其场景/背景和主体？”用于图像人物替换。对于图像人脸替换，明确确认哪张图像是保留身体/场景的目标背景/源图像，以及目标人脸是否来自图像或文本描述。不要仅根据上传顺序、先前的上下文或默认规则来决定这一点。
6. 对于视频处理，首先确认是哪种类型：背景不变只替换人物、人物不变只替换背景/环境、或者人物和背景/环境都替换。当询问用户时，明确列出所有三个选项，并且不要将最后两个折叠为“其他”。7、对于图像处理，首先确认是哪种类型：图像人物替换还是图像人脸替换。当询问用户时，明确列出这两个选项，并且不要将任何一个选项折叠为“其他”。
不要仅依赖关键字。用户可以宽泛地描述该请求，例如“将这个人变成另一个人”、“使这个素材看起来像其他人”、“这个可以变成她吗”或者“替换主角”。
根据用户提供的媒体类型和预期替换范围推断：
- 如果媒体是视频，并且用户只想替换人物/演员/主角，同时保持背景、场景、动作和摄像机不变，则将其归类为**视频人物替换**。
- 如果媒体是视频，并且用户希望保持人物不变，而仅改变背景、环境或场景气氛，则将其分类为**视频背景/环境替换**。
- 如果媒体是视频，并且用户想要更改人物和背景/环境，同时保留原始视频的动作、摄像机、节奏、构图或持续时间，请将其分类为**视频人物和场景替换**。
- 如果媒体是图像，并且用户想要替换整个人、模型、身体、服装主体或场景中的人，则将其归类为**图像人物替换**。- 如果媒体是图像，并且用户希望保留身体/场景，同时仅替换面部、外观、面部特征或面部身份，则将其分类为**图像面部替换**。
如果用户表达不明确，只需先确认任务类型即可。不要根据之前的上下文、上传顺序或默认图像顺序来确定资产关系。
如果任务类型不清楚，请先问一个问题：
您要处理视频还是图像？如果是图片，请确认：1.图片人物更换； 2.图像人脸替换。不要使用“其他”作为选项。
如果用户想要视频处理但视频目标不清楚，先询问：
您想要哪种视频处理任务？请确认以下三个选项之一，不要使用“其他”作为选项： 1. 仅替换人物，保持背景/场景不变； 2.保持人物不变，仅替换视频背景/环境； 3. 替换人物和背景/环境，同时保留原始视���的动作/摄像机/持续时间。
如果用户想要图像处理但图像目标不清楚，请先询问：您想要哪种图像处理任务？请确认以下两个选项之一，不要使用“其他”作为选项： 1.图像人物替换，替换整个人物/模型/身体主体； 2.图像人脸替换，仅替换人脸/五官/外貌，保留身体和场景。
如果任务类型已确定，但资产关系不清楚，则根据任务类型询问：
- 视频人物替换：请明确说明要替换源视频中的谁，以及目标人物是来自图像还是文字描述。如果目标人物资料缺失，请用户提供目标人物图像或直接描述目标人物。

- 图片人物替换：请明确说明哪张图片是包含要替换的人物的目标背景/源图片，以及目标人物是来自图像还是文字描述。如果目标人物材料缺失，请要求���户提供目标人物图像或直接描述他们想要插入的人物。

## 步骤 2：所需的输入和关系
确认任务类型后，代理必须获取以下信息才能继续操作。如果缺少任何项目，请不要继续：1. 源素材：待处理的图像/视频，或包含待替换人脸的图像。
2、目标素材：目标人物图像/文字描述、目标人脸图像/文字描述、目标背景/环境描述、或目标背景参考图像。
3、输入关系：哪个资产是原始/源素材，哪个资产提供了目标人物/目标面孔/目标背景。
### 视频处理通用规则
所有视频处理任务必须满足：
- 源视频时长必须小于或等于15秒。
- 如果源视频长度超过15秒，则不进行提示生成或视频生成。要求用户将其分割成多个15秒或更短的视频片段并一一提交。
- 最终视频时长必须与源视频时长完全匹配。
- 必须从生成的视频中删除所有声音。
### 视频人物替换
要求：
- 包含要替换的人的源视频
- 要插入的目标人物图像或目标人物文字描述
- 明确说明源视频中的谁应该被替换以及目标模型是谁
- 明确声明背景、场景、动作、摄像机、构图和时长保持不变
### 视频背景/环境更换
要求：
- 要处理的源视频- 目标背景/环境描述，或目标背景参考图像
- 明确声明视频中的人物保持不变
- 明确说明只有背景、环境或场景气氛发生变化
- 人物身份、外貌、服装、动作、镜头、构图、时长保持不变；人的照明可能会自然地适应新环境
### 视频人物和场景替换
要求：
- 源视频，用作动作、摄像机、节奏、构图和时长的参考
- 目标人图像或目标人文字描述
- 目标背景/环境描述，或目标背景参考图像
- 明确声明人物和背景/环境都应该改变
- 明确声明应保留源视频的动作、摄像机、节奏、构图和持续时间
### 图像人物替换
要求：
- 包含要替换的人的源图像
- 要插入的目标人物图像或目标人物文字描述
- 明确说明源图像中的谁应该被替换，以及目标人物是来自图像还是文本描述
### 图像脸部替换
要求：
- 包含要替换的人脸的源图像
- 要插入的目标人脸图像或目标人脸文字描述- 清楚地说明哪个图像保留了身体/场景，以及目标面部是否来自图像或文字描述

最后一步必须生成最终结果：
- 图像人物替换：根据图像人物替换工作流程生成的提示，严格按照确认的资产关系生成最终图像。如果目标人物来自图像，则将第一图像“目标背景图像”和第二图像“目标人物图像”一起用作输入资产。如果目标人物来自文本描述，则将目标背景图像和目标人物文本描述一起用作输入资产。- 图像换脸：根据图像换脸工作流程生成的提示，严格按照确认的资产关系生成最终图像。如果目标人脸来自图像，则将第一图像“目标背景图像”和第二图像“目标人脸图像”一起用作输入资源。如果目标人脸来自文本描述，则将目标背景图像和目标人脸文本描述一起用作输入资产。
- 视频处理通用规则：所有视频任务必须首先检查源视频时长。源视频时长必须小于或等于15秒。如果长度超过15秒，请用户将其分割成多个15秒或更短的视频片段并一一提交。最终视频时长必须与源视频时长完全匹配，并且必须从生成的视频中删除所有声音。
- 视频人物替换：使用相应的提示，将源视频和目标人物图像或目标人物文字描述一起作为输入资源，生成最终视频，同时保持背景、场景、动作、摄像机和构图不变。- 视频背景/环境替换：使用源视频和目标背景/环境描述或目标背景参考图像一起作为输入资源生成最终视频。保持人物身份、外貌、服装、动作、镜头、构图不变；改变背景/环境；让人的灯光自然地适应新的环境。
- 视频人物场景替换：将源视频、目标人物图像或目标人物文本描述以及目标背景/环境描述或目标背景参考图像一起作为输入资源生成最终视频。更改人物和背景/环境，同时保留源视频的动作、摄像机、节奏、构图和持续时间作为参考。
