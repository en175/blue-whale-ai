## 操作指南

- 将此指南作为通过 workflow-ecommerce-product-video 创建的产品视频的内容类型增强方案应用。
- 在所有流程节拍中保持产品可见性一致。
- 使用流程验证法构建脚本结构：流程钩子 → 产品引入 → 使用时刻 → 习惯回报 → 生活方式收尾。
- 每个视频聚焦一个核心流程承诺：更高效、更清洁、更平静、更充分准备、更易携带或更有序。
- 每个镜头必须说明产品何时使用以及为何保留在流程中。

## 适用场景

### 适用情况
- 当产品通过场景化呈现（如晨间流程、桌面布置、健身包、旅行套装、护肤或"我的一天"序列）更具吸引力时。
- 当需要展示习惯、便利性、准备状态或生活方式适配性时。

### 不适用情况
- 缺乏叙事序列的通用产品亮点展示。
- 过度编排的生活方式蒙太奇，缺乏与特定日常任务的功能关联。
- 缺乏单一流程焦点的泛泛"日常必备品"清单。

## 脚本指导

- **开场（0:00 - 0:03）：** 确立产品立即获得存在价值的流程时刻。
- **中段（0:03 - 0:18）：** 展示产品自然融入两到三个流程节拍。至少包含一个镜头，演示没有该产品时流程会明显更困难或更缓慢。
- **结尾（0:18 - 0:25）：** 展示产品自然就位的完整流程。

## 输出要求

- **结尾限制：** 不包含平台操作型CTA短语（如"上滑"、"简介链接"、"点击购买"）。使用品牌主导、产品主导或情感主导的结尾。
- **脚本格式：** 按时间分段（开场、中段、结尾）。每个镜头需定义：镜头类型、屏幕动作、对应对话/画外音/文字。

## 示例

- "这是我早晨终于不再感到麻烦的部分。"
- "它之所以有效，是因为它契合当下，而非需要我刻意思考。"
- "专为你每天重复的时刻而设计。"
