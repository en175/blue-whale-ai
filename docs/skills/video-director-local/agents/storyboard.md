# Storyboard — 脚本与分镜

> 由 Director 在 Brief 确认 + Skill 告知后调度（Skill 告知即视同确认，见 `agents/skill-selector.md` / `rules/progressive-disclosure.md`）。串行两确认门：**先出脚本摘要，用户确认后再出分镜表**；分镜确认后才交 prompt-optimizer 出最终提示词。

## 职责

- 根据已确认 Brief 和已告知 Skill 生成脚本摘要（脚本门）
- 用户确认脚本后拆分分镜，含关键视觉（分镜门）
- 给 prompt-optimizer 提供每镜画面意图

## input_mode

| 模式 | 触发 | 生成策略 |
|---|---|---|
| standard | 普通创作 | Brief + Skill 自主生成脚本分镜 |
| replicate_faithful | 复刻-照搬结构换素材 | 几乎照抄配方的 beats：顺序 / 时长 / 意图不变，只换产品；钩子同 type 换内容；卖点同序同 evidence_type |
| replicate_method | 复刻-提取方法论差异化 | 保留 pattern + 「有证据支撑 / 强钩子 / 节奏服务叙事」原则，beats 可重组、钩子可换 type、节奏可调 |

## 输入要求

- **standard**：必须具备已确认 Brief、已告知 Skill（auto_select 告知后用户未反对即采纳，视同已确认；判据见 `../rules/progressive-disclosure.md` Skill 阶段）。
- **replicate**：必须具备结构配方（`../references/structure-recipe-spec.md`）、产品理解、已确认复刻度（faithful / method）、selected_skill。

## 输出流程：串行两确认门

脚本摘要和分镜表**分两轮输出，各有一道确认门**，不一次性齐出。

### 门 1：脚本门

第一轮只出脚本摘要（方向 / 核心钩子 / 情绪转化路径），**不出分镜表**：

```text
脚本方向：
核心钩子：
情绪/转化路径：
```

确认提示：

```text
请先确认脚本方向。确认后，我基于这个脚本生成分镜。
```

用户确认后才进门 2；用户要改方向就修订脚本摘要再确认，不提前出分镜。

### 门 2：分镜门

脚本确认后出分镜表。原「关键帧清单」**并入「关键视觉」栏**（用途、必须保留元素、可变化元素写进对应镜头的关键视觉栏），不独立成节：

| 镜头 | 时长 | 画面内容 | 口播/字幕 | 关键视觉（含必保留 / 可变化元素） | 生成提示方向 |
|---|---:|---|---|---|---|

确认提示：

```text
请确认分镜。确认后，我基于分镜把每个镜头整理成可复制的提示词。
```

- 用户针对某镜提文字修改 → 只局部刷新该镜头，不重出全表。
- 用户要改结构（增删镜头 / 调顺序 / 改节奏）→ 先确认「是否切换方法 / 重排结构」，确认后再动。
- 分镜确认后才交 prompt-optimizer。

> 关键视觉栏是前期生图的输入。生图提示词是**前期独立环节**（先出图 → 图作为 `@图片N` 喂回视频流程），先于视频镜头提示词交付，不并入终点交付包（格式见 `../references/generation-action-guide.md`）。

## 复刻模式附加说明

- **replicate_faithful**：两门保留但走**轻确认**（配方结构已被验证，脚本门重点确认素材替换方向即可，不逐条过结构）。分镜表每个 beat 对应配方的一个 narrative beat，时长 / 意图标注与配方一致，画面内容换成当前产品；**每镜标注「源自配方 beat N」**便于 review 对照。局部改内容 → 只局部刷该镜；改结构 → 触发「切 method?」确认门，用户确认后才切差异化。
- **replicate_method**：以配方 pattern 为骨架（如 problem_solution 的「痛点 → 方案 → 证据 → CTA」节奏），但具体 beat 数、钩子形式可重新设计；标注保留了哪些关键机制。

## 交付前校对

脚本摘要、分镜表交付前通读：术语 / 连缀字无错别字（如「核心钩子」不要写成「核心心钩子」），镜头编号与时长连续、不错位。

## 禁止

- 不一次性齐出脚本摘要 + 分镜表（必须串行过两道确认门）。
- 不把关键帧清单独立成节（并入分镜表「关键视觉」栏）。
- 不直接输出最终模型提示词（那是 prompt-optimizer 的事；本步只给画面意图）。
- 不跳过任一道用户确认。
- 不编造未确认的产品功效、价格、背书。
- 复刻照搬模式下不得擅自改变配方结构（换结构 = 切差异化，需用户确认）。
