# Skill 与生成优先级

本规则处理「用户选择的创作 Skill」和「生成模型提示词规则」之间的关系。

## 一句话规则

**Skill 决定创意；生成模型规则决定语法。** 两者不冲突，不能互相替代。

## 分层优先级

| 层级 | 决定什么 | 例子 |
|---|---|---|
| 用户需求 | 最终目标 | 做一个保温杯 UGC 广告 |
| 创作 Skill | 内容结构和表现形式 | UGC、TVC、短剧、测评、产品展示 |
| Workflow | 阶段顺序和确认节奏 | Brief → Skill → 分镜 → 提示词 |
| 生成模型规则 | 生成提示词语法 | `@图片1`、`<主体1>`、一镜一运镜、稳定约束 |

## 不冲突的原因

创作 Skill 回答：这个视频应该怎么讲、怎么卖、用什么内容结构？

生成模型规则回答：把已确认的内容结构翻译成模型更容易执行的提示词，应该怎么写？

所以 Seedance 等模型规则不是另一个创作 Skill，它是生成阶段的「模型适配层」。

## Skill 来源与选择

从本地 `library/_index.md` 查询 Creative Skill 库（108 个，引用本地 `library/raw/`）：

- 用户明确指定某 Skill → 优先使用用户指定的。
- 用户未指定 → 按 Brief 与上下文匹配度推荐最合适的一个；置信度低时反问用户，不擅自选、不默认兜底。
- 复刻场景下的 Skill 选择见 `workflows/video-decode-replicate.md`。

## 冲突处理

### 情况 1：Skill 风格和生成模型默认词冲突

例如用户选择 UGC，但模型默认补了「电影质感」。保留 UGC 的手机原生、自然光、不完美构图；模型规则只补稳定性表达；不把画面改成高端 TVC。

### 情况 2：Skill 要多镜头，简单路径不够

保留 Skill 的多镜头结构，使用每镜独立完整块表达（见 `references/seedance-prompt-optimizer.md`）。

### 情况 3：Skill 需要真实社交感，但约束要求稳定

真实感保留在场景、动作和画面语气里；稳定约束只用于防止人物变形、Logo、水印、字幕和重复人物。

### 情况 4：用户选择 Skill 后又上传素材

Skill 仍决定创作结构；素材按生成模型规则映射成 `@图片N` / `<主体N>`；不能因为素材风格不同就自动换 Skill，除非用户确认。

## 生成阶段必须遵守

1. 不改变已确认 Brief。
2. 不改变已确认 Skill。
3. 不改变已确认脚本和分镜。
4. 只做模型语法级优化。
5. 关键歧义必须回到用户确认。

## 禁止

- 禁止把生成模型参考当成创意路线。
- 禁止用模型默认风格覆盖用户选择的 Skill。
- 禁止为了提示词稳定性删除用户确认过的核心卖点。
- 禁止在用户未确认时从 UGC 切换到 TVC、从产品广告切换到短剧。
