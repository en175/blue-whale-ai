# 提示词交付包（Prompt Delivery Guide）

本地版**不调用生成 API、不创建 GenerationJob**。生成阶段的产物是**可直接复制到即梦 / Seedance / 生图工具的提示词**。本文件定义两类产物的格式：

1. **生图提示词卡**（前期独立环节）：关键帧 / 产品图 / 风格图的生图提示词。先出图 → 图作为 `@图片N` 喂回视频流程，**不并入交付包**。
2. **提示词交付包**（视频镜头终点产物）：分镜表 + 每镜视频镜头提示词 + 使用指引。**不含生图提示词正文**，只引用「生图提示词见生图卡」。

## 生图提示词卡（前期，独立）

如需关键帧 / 产品图 / 风格图，**先独立交付生图提示词卡**，等用户出完图（作为 `@图片N` 喂回）再进视频镜头提示词。

- 按 `image-prompt-contract.md` 七字段（主体 / 场景 / 构图 / 光影 / 风格 / 必须保留 / 必须避免）。
- **按图编号**，每张图标注类型 +「将用于：镜头N」。

模板：

```markdown
## 🖼️ 生图提示词（前期关键帧/产品图）
**图1** ｜产品图 ｜将用于：镜头1、镜头3
> 主体：… / 场景：… / 构图：… / 光影：… / 风格：… / 必须保留：… / 必须避免：…
**图2** ｜关键帧 ｜将用于：镜头5
> …
👉 拿去生图工具出图，出完发我，我接进分镜（@图片N）。
```

## 交付包结构（视频镜头）

每次完成分镜 + 提示词优化后，按本结构交付，共 5 区：顶参数行 + 素材索引 + 分镜表（多段分组）+ 每镜视频提示词 + 使用指引。

### 0. 顶部默认参数行

卡顶一行：

```markdown
> 默认参数：9:16 · 写实 · 720p（每镜时长见各镜块）
```

复刻链路在参数行前加模式条：`> 🔄 复刻模式 · 按 faithful/method 配方生成`。

### 1. 素材索引区（分镜表前）

```markdown
### 📎 素材索引
- @图片1 = XX 护肤精华（蓝色玻璃瓶）· 产品图
- @图片2 = 咖啡店场景 · 场景图
```

`@图片N` = 用户提供的第 N 张图（按上传顺序；含前期生图产物）。

### 2. 分镜脚本（5 列 markdown 表，多段分组）

按叙事段落（钩子 / 展开 / CTA）分多张表，每段顶标段落名 + 镜号范围：

```markdown
#### 第1段·钩子（镜头1-3）
| 镜头 | 时长 | 画面内容 | 口播/字幕 | 关键视觉 |
|---|---:|---|---|---|
```

不设「提示词（见下）」列——每镜提示词就在下方独立块，表里不重复引用。

### 3. 每镜视频提示词（独立完整块，可复制）

每镜一块，**扁平按镜号列**（不按段落分组，复制时按镜号直找）：

```markdown
**镜头1** ｜2s ｜Seedance ｜引用 @图片1
> <完整模型语法版提示词正文>
```

- 字段：镜号 + 时长 + 目标工具（Seedance / 即梦）+ 引用 `@图片N` + 提示词正文。
- **独立完整**：主体绑定（`<主体N>@图片N`）和约束包（画质 / 稳定 / 水印 Logo 兜底等）全融进每镜正文，单镜可独立贴去生成工具，不依赖首段 / 末段。

### 4. 使用指引

一句话告诉用户：视频镜头提示词复制到 Seedance / 即梦；`@图片N` 见上方素材索引；关键帧 / 产品图生图提示词见「生图提示词卡」；要改某镜直接说。

## 参数默认（提示词里需明确的）

- **时长**：短视频 5s，用户指定则用用户的；复刻场景从源视频推断。
- **画幅**：短视频 9:16，横屏广告 16:9。
- **风格**：写实默认，用户指定则用用户的。
- **分辨率**：720p 默认（若目标工具需要填）。

## 不做的事

- 不调用生成 API（本地版止于提示词）。
- 不虚构用户没说的约束。
- 不把内部优化过程暴露给用户（只给最终提示词 + 一句简述保留了什么创意约束）。
- 不把生图提示词正文写进交付包（生图独立成卡，交付包只引用）。
