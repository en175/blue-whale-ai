# 提示词交付包（Prompt Delivery Guide）

本地版**不调用生成 API、不创建 GenerationJob**。生成阶段的产物是**可直接复制到即梦 / Seedance / 生图工具的提示词交付包**。本文件定义交付包格式。

## 交付包结构

每次完成分镜 + 提示词优化后，按本结构交付：

### 1. 分镜脚本（markdown 表）

| 镜头 | 时长 | 画面内容 | 口播/字幕 | 关键视觉 | 提示词（见下） |
|---|---:|---|---|---|---|

### 2. 每镜提示词（独立成段，可复制）

每个镜头单独给一段优化后的提示词，标注：

- 镜头编号
- 类型：视频镜头（Seedance/即梦）/ 关键帧生图
- 引用素材：`@图片N`（用户提供的图，按顺序编号）
- 提示词正文（模型语法版，可直接复制）

### 3. 生图提示词（如需关键帧 / 产品图）

按 `image-prompt-contract.md` 格式给生图提示词（主体 / 场景 / 构图 / 光影 / 风格 / 必须保留 / 必须避免）。

### 4. 使用指引

一句话告诉用户：视频镜头提示词复制到 Seedance / 即梦；关键帧生图提示词复制到生图工具；`@图片N` 对应用户提供的第 N 张图（按上传顺序）。

## 参数默认（提示词里需明确的）

- **时长**：短视频 5s，用户指定则用用户的；复刻场景从源视频推断。
- **画幅**：短视频 9:16，横屏广告 16:9。
- **风格**：写实默认，用户指定则用用户的。
- **分辨率**：720p 默认（若目标工具需要填）。

## 不做的事

- 不调用生成 API（本地版止于提示词）。
- 不虚构用户没说的约束。
- 不把内部优化过程暴露给用户（只给最终提示词 + 一句简述保留了什么创意约束）。
