＃＃ 指示

1. 确定核心动作奇幻类型（例如超级英雄觉醒、机甲战斗、魔法试炼、Boss入口）。
2. 将输出构建为针对无限画布软件格式化的模块化卡系统。
3. 确保每个动作节拍集中于一个不同的任务（例如“闪避”、“激活”、“显示”），以保持视觉清晰度。
4. 设计清晰的空间路线，定义每个序列的起点、目标点和环境障碍物。
5.应用“动作幻想引擎”：
   - 危机开启
   - 强制行动
   - 敌人显露出来
   - 第一次反击
   - 空间追逐- 升级
   - 视觉高潮
   - 临时结果/更大的威胁。
6. 使用质量检查框架来验证是否存在明确的主角目标、敌人压力和逻辑空间关系。

## 输入

- **核心理念：** 一个简单的前提（例如，“一个男孩在一座废墟城市中觉醒了力量”）。
- **用户限制：** 首选类型、主角类型、敌人类型或视觉强度级别。

## 何时使用

- **适用：** 为剧本、故事板、游戏设计或视觉概念艺术创建动作结构；为故事架构构建模块化卡。
- **不适用：** 生成完整的散文脚本、纯散文叙述或技术代码。

## 输出要求

按顺序制作以下模块：
1. **故事定位与核心前提**
2. **世界卡、主角卡、敌人卡、路线卡**
3. **冲突引擎**
4. **画布动作节拍卡（8节拍结构）**
5. **动作、视觉、视觉特效和音效方向**
6. **扩展选项**
7. **质量检查清单**

## 示例

**输入：** “一个女孩在怪物爆发期间在一所废弃的医院中醒来。”

- **第 1 拍（危机开始）：** 从女孩因红色警报醒来开始；描述废墟中的医院翼楼。
- **节拍 2（强制行动）：** 她听到走廊里传来沉重的金属拖拉声，必须识别出潜在的武器。
- **第 3 节（敌人暴露）：** 她透过玻璃门观察到变异的肢体。
- **剩余节拍：** 使用动作幻想引擎继续序列，直到最后一个钩子。
