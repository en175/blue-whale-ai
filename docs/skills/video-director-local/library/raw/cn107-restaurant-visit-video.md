# 餐厅参观视频技巧

## 创意范围

通过以下任一不同格式创建有关一家餐厅的视频：

1. **诚实的单餐厅评论**：评估餐厅并帮助观众做出就餐决定。
2. **沉浸式餐厅参观**：让观众通过到达、氛围、服务、食物和人际互动来体验参观。

不要将这两种格式模糊成通用的食物蒙太奇。审查需要证据和判决。身临其境的参观需要空间和体验的连续性。

## 共同的创作原则

### 餐厅、食物和人类存在

从三个互补的视觉层构建视频：

- **餐厅层**：外部、标牌、入口、餐厅、菜单、柜台、厨房或可识别的装饰。
- **食物层**：菜肴概述、份量比例、准备、质地、上菜动作和细节。
- **人性层**：到达、订购、服务交互、双手、第一口、自然反应、对话或反思。

让每一层贡献不同的信息。食物特写不能取代地点证明，热情的主人也不能取代可见的食物证据。

### 真实性

- 基于可见或经过验证的信息的事实主张。区分个人反应与客观事实和餐厅的说法。
- 不得捏造价格、成分、奖项、营业时间、地址、服务质量或需求。
- 保持反应自然和具体。避免没有经验支持的夸张表达。
- 在整个视频中保留重复出现的人物、菜肴、餐桌布置和餐厅空间的可识别外观。

### 灯光和色彩真实感

- 遵循一天中的实际时间、窗户、实用装置和餐厅氛围。不要默认黄金时段、琥珀色、昏暗的电影或烛光处理。
- 保持准确的食物颜色和足够的曝光度，以检查质地、熟度、成分和份量。
- 保留高光和阴影细节；避免橙色皮肤、黄白色、压碎的黑色和人造食品发光。
- 保留自然混合照明，并在同一空间内保持一致的光线方向、白平衡和曝光。- 仅当明显受位置支持或有意属于概念时才使用风格化照明。

### 感官讲故事

使用可观察到的证据，例如真正的蒸汽、炭、气泡、脆边、横截面、份量比例、切割、浸渍、搅拌、咬、嘶嘶声、嘎吱声、器具接触和房间音调。

将感官语言与可见证据联系起来。比起一般的赞美，更喜欢“边缘酥脆，中心柔软”。除非菜肴和动作自然产生，否则请勿添加光泽、蒸汽、融化、滴落或拉伸。

### 物理现实主义

食物互动在感觉壮观之前应该先感觉实用。

- 保持服务规模、食物结构、配料顺序和质地合理且连续。
- 使握力与尺寸、重量、温度、柔软度和重心相匹配。从两侧和下方支撑大型或堆叠的食物。
- 请勿捏住汉堡的顶部面包、从上方按压或从一侧提起。仅显示自然的手指压缩。
- 保持酱汁量和粘度可信：轻微的水珠或边缘挤压是可以接受的；喷涌、长股和大水坑则不然。- 仅当实际食物明显有弹性时才使用奶酪或配料拉伸剂。保持其短、薄、重力响应且易于分离。
- 在食物进入口中之前将其完全分开。适度咬合、自然闭嘴咀嚼，并在说话前稍作停顿。
- 保持面包屑、酱汁、馅料、咬痕、餐具和盘子位置微妙且连续。
- 保持自然速度的吃、倒、滴、分离动作。避免慢动作，以免放大拉伸、液体流动、碎屑或口腔运动。- 喜欢小的、受控的互动，而不是夸张的挤压、拉动、倾倒、滴落或泼溅。

## 格式一：诚实的单餐厅评论

### 核心目的

回答一个实际问题：是否来访、要点什么、价格或宣传是否合理，或者这家餐厅适合谁。审稿人充当可信的评估者并得出受支持的结论。

### 故事设计

#### 回顾前提

以具体的前提开始，例如测试病毒菜肴、评估价值、挑战声誉或根据可见标准进行审查。立即呈现最强烈的形象、问题、矛盾或结果。

当产生好奇心时，使用简短、自然的品尝反应作为钩子，但要快速将其与餐厅和评论问题联系起来。没有证据支持的反应不是审查。

#### 证据结构

使用灵活的证据链：

`审查前提 -> 餐厅证明 -> 订单和价格证明 -> 菜肴评估 -> 经验证据 -> 权衡 -> 结论`

省略不相关的阶段，但保留足够的证据，让判决感到理所应当。

#### 评估标准

仅选择相关标准，例如风味、质地、温度、份量、价值、清洁度、等待、服务、舒适度或一致性。通过观察解释评级。

#### 菜肴进展

将每道特色菜肴视为一个紧凑的评论单元：

`菜肴识别 -> 视觉细节 -> 品尝动作 -> 具体反应 -> 迷你结论`

给影响判决的菜肴更多的放映时间。仅当多个菜肴支持同一前提时才使用紧凑的蒙太奇；不要把评论变成多餐厅合辑。

#### 结束

最后做出一个有用的决定：点什么或跳过什么、花费或等待是否合理、是否返回以及应该拜访谁。

### 视觉设计

#### 相机语言

- 通过直接对着镜头传递、自然的画外音、观点或可见的品尝来建立可信度。
- 具有近距离食物证据的替代中景主人镜头。
- 使用桌子水平或手持角度以获得真实的参观感觉，并使用手、餐具或餐厅来进行缩放。
- 仅当价值重要时才显示菜单或收据详细信息。
- 将相机放置在靠近感官活动的地方，不要扭曲食物或夸大相互作用。

#### 视觉证据

将每个声明与图像匹配：

- 清洁度要求 -> 桌子、地板、柜台或餐具；
- 服务索赔->订购或员工互动；
- 份量要求 -> 放在手或用餐者旁边的盘子；
- 纹理声明 -> 切割、自然分离、咬合或横截面；
- 价值主张 -> 菜单、收据、总计或完整的餐桌布置。

#### 屏幕文本

使用简洁的叠加层来显示餐厅或菜肴名称、经过验证的价格、标准、感官观察或最终推荐。将文字放在食物的次要位置。

### 声音和表演

- 使用自信但对话式的审稿人声音。
- 让情感自然地回应每一刻。
- 在得出结论之前陈述具体的观察结果。
- 包括相关的弱点；持续的赞扬会削弱可信度。
- 避免使用促销语言，除非内容明确呈现为促销。

### 编辑节奏

- 在背景细节之前先确定前提。
- 快速完成到货和订购，除非它们影响判决。
- 在单个菜肴周围建立重复的微弧。
- 以正常速度保持稍长的时间，以获得第一口、显露的质地或意想不到的结果。
- 在结尾之前引入对比或权衡，以防止序列平淡。
- 为最终判决提供足够的视觉和语言空间来记录。

## 形式二：沉浸式餐厅参观

### 核心目的

让观众感受走进餐厅分享美食的感觉。客人充当体验向导，而不是正式的法官。

回报是氛围、感官存在和情感参与。可能会出现推荐，但不需要评分。

### 故事设计

#### 体验弧

使用空间和情感进展：

`感官预览 -> 邻里 -> 外部身份 -> 进入 -> 定向 -> 订购或服务 -> 预期 -> 食物到达 -> 共享体验 -> 情感解决 -> 位置关闭`

保持清晰的位置感和进展感。

#### 入学和迎新

利用一两个简洁的时刻来建立邻里关系、可识别的外观、室内的过渡、就餐位置和独特的氛围。无需将视频变成房产参观即可创建方向。

#### 体验节拍

围绕有意义的行动：进入、就座、点餐、观看准备、接收食物、与员工互动、品尝、分享和离开。使用行动而不是解释每个可见的细节。

#### 情绪进展

让客人的情绪发生变化：

`好奇心 -> 期待 -> 发现 -> 享受或惊喜 -> 反思`

不要在每次拍摄中都强行做出戏剧性的反应。安静的注意力、目光接触、交谈和停顿比持续的表演更能让人身临其境。

#### 结束

以最喜欢的时刻、合适的场合、安静的餐桌图像、员工告别或将体验与地点重新联系起来的外观来解决。

### 视觉设计

#### 相机语言

- 通过视角、过肩镜头或近距离观察镜头跟随客人。
- 使用较宽的框架来放置，使用较近的框架来处理感官细节。
- 保持入口、餐桌、服务和食物之间的方向连续性。
- 更喜欢自然互动而不是演示。使用前景物体和其他用餐者来增加深度。
- 让客人自然地坐着、浏览、接受食物、喝水、说话或观察。
- 重复一些位置提示，例如标志、颜色、装饰或包装，而不���建徽标蒙太奇。

#### 镜头关系

通过动作和空间线索连接镜头：

- 伸手去开门 -> 内部展示；
- 菜单关闭 -> 厨房或服务准备；
- 服务器进场->板块登陆；
-器皿入盘->质感特写；
- 支撑手或器皿抬起 -> 客人反应；
- 最后一口 -> 房间或外部结束图像。

＃＃＃＃ 气氛

通过街道环境、装饰、员工活动、人群流动、间距和服务行为来定义餐厅。让人们沉浸在体验中；不要仅依赖浅焦食物镜头。

### 语音和声音

- 当图像清晰时，喜欢轻松的旁白、简短的对话或沉默。
- 保持房间音调、脚步声、门、烹饪、倒水、餐具和谈话。
- 使用音乐和声音来表达情绪或背景，而无需消除房间声音或描述明显的内容。

### 编辑节奏

- 从感官或情感的承诺开始，然后确定到达。
- 遵循自然的参观顺序，同时消除重复的等待。
- 不同的环境、服务、食物和客人反应。
- 使用紧凑的观察插入物而不失去空间连续性。
- 通过发现和准备更快地削减；在到达、初尝和解决时保留更长时间。
- 避免将体验编辑成一系列不相关的有吸引力的菜肴。
