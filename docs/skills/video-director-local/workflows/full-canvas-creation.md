# 完整创作编排（Full Canvas Creation Workflow）

目标：把用户一句自然语言视频需求，编排成分镜 + 可复制提示词。适用于 UGC 广告、短剧、品牌片等需要分镜的复杂创作。**本地版止于分镜脚本 + 提示词**，不生成视频。

## 适用判断（Director 自主）

- 需要完整广告策略或多阶段分镜
- 用户明确要求使用某个复杂 Skill
- 需要品牌 campaign 或多版本

不适用于（→ `direct-generation.md`）：单一图 / 单镜头、无营销策略。

## 阶段总览

| 阶段 | 名称 | 主要 agent | 产物 | 确认节奏 |
|---|---|---|---|---|
| 1 | Brief 收集 | brief | 创作 Brief | 自然确认（方向歧义追问） |
| 2 | Skill 匹配 | skill-selector | 创作套路 / Skill | 告知 + 可改（不出确认卡；仅分歧大多轮追问） |
| 3 | 脚本分镜 | storyboard | 脚本摘要、分镜表 | 串行两确认门（脚本门 → 分镜门） |
| 4 | 提示词优化 + 交付 | prompt-optimizer | 提示词交付包 | 自然确认（提示词方向对齐） |
| 5 | 自检 | review | 审核摘要 | 交用户判断 |

> 确认节奏遵循 `../references/natural-confirmation.md`：低成本推进直接继续；不可逆覆盖前先对齐。本地版无生成成本，主要管「不可逆覆盖」和「版权提示」。

> **阶段衔接（自动续跑）**：阶段 1→4 按各自确认门推进；**阶段 4 提示词交付包产出后，直接自动进阶段 5 自检，不要停在交付包等用户下达指令**。自检摘要产出后再交用户判断是否修改。

## 阶段 1：Brief 收集

brief agent 收集启动必须的信息（视频目标 / 主体 / 平台时长 / 是否有素材 / 核心卖点）。缺失只问最关键 1-3 个。展示 Brief 摘要让用户确认。

## 阶段 2：Skill 匹配

skill-selector 读 `library/_index.md` 选最适合的创作套路，告诉用户推荐 Skill 和理由，允许改选。

## 阶段 3：脚本分镜

storyboard agent 串行过两道确认门：先出脚本摘要（方向 / 核心钩子 / 情绪转化路径），用户确认后再生成分镜表（关键帧要素并入「关键视觉」栏，不独立成节），分镜确认后才进提示词。只改局部时只重写对应镜头；方向不对回到阶段 1 或 2。

## 阶段 4：提示词优化 + 交付

prompt-optimizer 把分镜转成目标模型（Seedance / 即梦）可执行的提示词，按交付包格式（`../references/generation-action-guide.md`）输出：默认参数行 + 素材索引 + 分镜表（5 列多段分组）+ 每镜视频提示词（独立完整块）+ 使用指引。**本地版到此为止**，不生成视频。交付包产出即自动进阶段 5 自检，不等用户指令。

如果有关键帧 / 产品图需要先生图，**生图提示词是前期独立环节**：先按生图提示词卡交付（按图编号，标注「将用于：镜头N」），用户到生图工具出完图喂回（作为 `@图片N`），再进视频镜头提示词。生图提示词正文不进交付包，交付包使用指引只引用「生图提示词见生图卡」。

## 阶段 5：自检

review agent 检查提示词是否符合 Brief、是否符合 Skill、交付完整性、是否有风险。输出审核摘要 + 修改建议。

## 全局禁止

- 不从 Brief 直接跳到提示词（跳过脚本分镜）。
- 不在没有脚本 / 分镜确认时出整条视频提示词。
- 不调用生成 API（本地版止于分镜 + 提示词）。
- 不让生成模型语法覆盖已确认的创意 Skill。
