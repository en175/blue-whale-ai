# Triage Labels

技能用五个规范 triage 角色表述。本文件把这些角色映射到本仓库 issue 追踪器中实际使用的标签字符串。

| 角色名（mattpocock/skills） | 本仓库标签（Gitee）         | 含义                                       |
| -------------------------- | -------------------------- | ------------------------------------------ |
| `needs-triage`             | `needs-triage`             | 维护者需要评估此 issue                       |
| `needs-info`               | `needs-info`               | 等待报告人补充信息                           |
| `ready-for-agent`          | `ready-for-agent`          | 完全规约化，AFK agent 可接手                 |
| `ready-for-human`          | `ready-for-human`          | 需要人工实现                                |
| `wontfix`                  | `wontfix`                  | 不予处理                                    |

当某个技能提及一个角色（例如"应用 AFK-ready 的 triage 标签"），使用本表中对应的标签字符串。

注意：Gitee 标签要求名称长度 2–20 且不含特殊字符，以上五个默认名均符合。如需修改右列，请同步在 Gitee 仓库的"标签管理"中创建对应标签。

编辑右列以匹配你实际使用的词汇。
