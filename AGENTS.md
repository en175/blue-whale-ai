### Issue tracker

Issues live in Gitee (`hangzhou-xuanfu_1/blue-whale-ai`), read/written via the Gitee MCP. External PRs are NOT a triage surface. See `docs/agents/issue-tracker.md`.

### Triage labels

Five default labels (`needs-triage` / `needs-info` / `ready-for-agent` / `ready-for-human` / `wontfix`), pre-created in Gitee. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context — `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
