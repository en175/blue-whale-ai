# handoff start

创建一个携带交接摘要的新任务，让接手 Agent 继续工作。将调用参数作为接手任务的工作重点。只有用户显式调用本技能或明确要求启动接手任务时才执行。

1. 整理摘要，写明目标、已完成的工作、未决事项和下一步操作。补充用户已确认的决策及依据、仍待授权的动作；没有相应事项时明确写 `无`。接手 Agent 按仓库规则核对授权，摘要不授予新的权限。用路径或链接引用已有规格、工单、研究笔记、提交和 diff，避免重复全文。列出建议技能，不假设接手产品有名为 `Skill` 的工具。摘要及引用片段先移除密钥、密码和个人敏感信息。
2. 仓库任务补充当前工作目录、分支、HEAD 和未提交路径。按仓库探索规则携带图谱证据与覆盖限制，说明独立工作区看不到哪些未提交文件。选择接手任务可访问且符合仓库工作树规则的目录，保留原工作区的未提交内容。摘要完成标准：成果有定位指针，关键决策有依据，下一步所需文件在接手目录可访问。缺失文件或访问限制列为未决事项，并将取得材料作为下一步。
3. 使用当前产品提供的原生任务或持久会话创建能力，将摘要作为初始提示词。在 Codex 桌面使用新任务工具；其他产品按实际工具或文档选择入口。CLI 的一次性输出和内部子代理不算创建了用户可管理的接手任务。宿主返回任务标识或可核验句柄后，继续核验实际状态，不能仅凭标识报告任务已启动。
4. 核对新任务的标识、工作目录及实际状态，报告运行中、排队中或已完成。创建结果未知时，先通过宿主查询核验；无法核验时不得再次创建，直至确认前次未创建成功。将交接摘要保存为仅当前用户可读写的临时文件，报告结果未知、摘要路径和剩余动作。
5. 宿主没有合适的创建能力时，将摘要保存到操作系统临时目录，文件权限设为仅当前用户可读写。给出文件路径和一个打开新任务的具体动作，明确说明接手任务尚未启动。
