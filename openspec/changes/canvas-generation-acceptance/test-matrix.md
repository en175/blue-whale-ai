# 测试矩阵：Canvas 生成全链路验收

| 层级 | 场景 | 测试/证据 | 是否付费 | 状态判定 |
| --- | --- | --- | ---: | --- |
| New API | 登录与用量 | 鉴权请求、脱敏响应 | 否 | 只有返回 2xx 且用量结构正确才是“完整” |
| 模型能力 | 图片/视频模型列表 | Next 列表与已验证能力源一致 | 否 | 不一致为“接线缺失” |
| 上传 | 图片/视频/音频预签名 -> PUT -> 完成确认 | 网络请求 + HEAD/公网 URL + 数据库素材 | 否 | 必须得到可访问的 TOS 公网 URL |
| 路由处理器 | 图片任务持久化配方/任务输入 | 聚焦 Vitest RED/GREEN | 否 | 显式断言输入字段 |
| 路由处理器 | 视频首尾帧 ID 独立持久化 | 聚焦 Vitest RED/GREEN | 否 | 不得扁平化 |
| Worker | BullMQ 提交/轮询/重新入队 | Worker 日志 + Redis 队列 + 数据库状态迁移 | 视频 | 轮询前必须持久化供应商任务 ID |
| 供应商适配 | 首尾帧请求语义 | 脱敏请求体或网关证据 | 视频 | 不支持时为“后端能力缺失” |
| 浏览器 | 文生图 | Canvas 节点、任务、素材、刷新 | 图片 | 刷新后仍成功展示 |
| 浏览器 | 参考图生图 | 素材 ID 进入任务和供应商输入 | 图片 | 不允许只传 URL 的旁路 |
| 浏览器 | 文生视频 | BullMQ Worker + New API + TOS + 播放 | 视频 | 串行执行 |
| 浏览器 | 单首帧生视频 | 保留首帧角色 | 视频 | 串行执行 |
| 浏览器 | 首帧 + 尾帧生视频 | 同时保留两种角色，或返回能力错误 | 视频 | 串行执行 |
| 浏览器 | 跨模态回填后生视频 | 源素材 ID 进入任务和供应商输入 | 视频 | 串行执行 |
| 恢复 | 处理中刷新 | 配方/任务 ID 水合并恢复轮询 | 无额外调用 | 所有节点彼此独立 |
| 恢复 | 成功后刷新 | 快照素材 URL 仍然可见 | 无额外调用 | 节点不能变灰或变黑 |
| 并发 | 10 个图片任务 | 独立任务/节点映射 | 图片 | 受控批次 |
| 音频 | 上传/播放/生成 | 真实 TOS 上传；生成固定为假实现 | 否 | “仅假实现” |
